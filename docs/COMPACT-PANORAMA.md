# 全景空间与耀斑修正

2026-09-24，本地待用户验收，未发布。对应总规划 M0.2 / M2.3 的局部修正。

## 白色半球是什么

此前综合全景用一个半径 0.12 的高亮球体表示耀斑，放在展示半径 0.34 的太阳边缘，并在示意进度 0.32 处暂停。它与太阳遮挡后呈白色半球，容易被误认为真实天体。这是显示设计问题，不是新天体、太阳卫星或第二颗太阳。

耀斑是辐射突然增强，CME 是等离子体与磁场的抛射；两者不等同。参考 [NASA 太阳耀斑说明](https://science.nasa.gov/blogs/solar-cycle-25/2022/06/10/solar-flares-faqs/)。

本轮将高亮球体替换为贴合太阳表面的柔和发光区域，强度由已有示意进度控制。全景与独立太阳活动页共用同一效果；保留表面遮挡、阶段开关及进度控制，补上表示含义。颜色、位置、大小仍为说明性选择，不模拟观测波段或当日活动。日冕与 CME 仍为原有示意，不改变轨道、天体数量、真实半径或日期。

## 顶部空间怎样调整

- 原标题、范围、取景、观察路径四层合并为两行。桌面首行保留标题、范围与返回；第二行保留取景、历史前进后退和当前位置。
- 尘埃、太阳活动、近地空间、阶段导览及星点与环说明在“更多工具”内。
- 观察步骤、位置提示和返回规则在“观察指南”内；浮动覆盖而非继续压缩画布。点选、点击外部、Esc 可收起；Esc 优先收起浮层，再关闭全景。
- 窄窗口折行，保留工具文字与触达能力。当前范围切换、图层和时间行为不变。

## 本地验证与用户验收

构建通过，保留已有 JS 包体积提醒。观察历史、现象阶段门控、太阳活动进度的 3 个相关测试文件共 11 项通过。

1440×900 浏览器实测：常驻顶部 98 px，三维画布高 759 px。打开工具和指南不改变画布高度；1024、700、390 px 宽工具栏无横向溢出。定位太阳活动、指南进入地球、历史前进后退、宇宙范围切换和 Esc 浮层关闭通过；浏览器未报告运行异常。已检查全景、太阳近景与窄窗口截图。

验收入口：主页 → 综合全景。先比较主画面空间；展开更多工具 / 观察指南，再收起；定位太阳活动，拖动旋转或侧视，确认太阳旁不再有白色实体球。右栏太阳活动条目说明亮斑、日冕、CME 的区别。独立太阳活动详解也使用表面亮斑。
