初版已通过提交 `9aef9ea` 推送；[该次部署](https://github.com/yydshly/0922_codexgpt6_project/actions/runs/36293911107)成功。下述三步完善为本次独立交付，不属于初版提交；功能与技术检查完成，待用户集中验收。发布结果以[本次提交对应的部署记录](https://github.com/yydshly/0922_codexgpt6_project/actions/workflows/deploy-pages.yml)为准。原 r09.12 认知版的验收记录保持不变。

### 第一步的新增操作

- **地球**：在“蓝色地平线”内切换“完整球体 / 大气边缘”。沿原观察方向平滑拉远或靠近，切换取景不跳转日期；云层、大气分别开关，切换取景保留开关。关闭云层时同步取消云影。
- **土星**：按由内向外的 C 环、B 环、卡西尼分界、A 环选择。使用与三维环几何相同的资料边界，选区显示虚线与轻度高亮，选中说明列出距土星中心的范围；分界只有虚线，不填充假实体。标记投影由环面上的锚点计算，随镜头移动，并隐藏球体遮挡或视野外的标记。再次点击选中项取消指认，纯画面隐藏高亮与标记。
- **太阳**：“整体 / 光球 / 日珥 / 日冕”实际改变显示。光球只留球面，日珥保留球面和示意拱环，日冕保留球面和外层辉光，各自配有说明。仅解释这三类，不声称太阳全部结构已经重建。
- **距离**：常驻显示虚拟镜头距天体中心的公里数与平均半径倍数，拖动、缩放和预设过渡时更新。数值不是飞船状态。
- **科学依据**：环分区边界复用 `rings.ts` 中的 NASA/NSSDCA 数据；太阳与地球说明沿用下方 NASA 来源。高亮线是教学标记，开关用于比较外观，并非修改物理世界。

第一步验证：346 项自动检查通过、生产构建通过；浏览器复验环分区数值与随动标记、纯画面、地球两种取景与外观开关保持、太阳三种分层效果和 390×844 窄屏。未发现脚本或着色器错误。构建仍有原主页包体较大的提示。

### 第二步的新增操作

入口：**太阳系全景 → 沉浸观景 → 底部「天体关系 · 同景」**。

- **地月之间**：同景只显示地球与月球，不混入金星等不属于地月系统的对象。地月中心的距离不压缩，两者用同一比例尺；真实同景中球体较小属于正常结果。可以点名称或左侧「靠近」单独观察，再点「返回地月同景」。
- **土星与它的卫星**：显示土星、主环及土卫二（Enceladus）、土卫五（Rhea）、土卫六（Titan）三颗代表卫星。不是全部土星卫星名录，也没有把未加载的卫星随机放置。
- **真实比例 / 卫星放大**：进入同景和切换家族默认真实比例。辅助模式仅把月球半径放大 2 倍，或三颗土星卫星半径各放大 16 倍；母星、环、所有中心距离、参数不变。同景切换比例不移动镜头；单体近景会按展示半径重新取景。常驻比例说明在纯画面中也保留，卫星标签同时显示倍数。
- **可理解的参数**：同景列出各卫星距母星中心的当前公里数；靠近后显示半径、距母星中心的距离、相对母星速度与参考公转周期。右上角单独显示虚拟镜头距当前取景天体中心的距离，明确区分镜头参数和卫星参数。
- **距离连线与定位点**：可关闭的虚线只连接当前天体中心，不是完整轨道或运动轨迹。仅在家族同景显示，靠近单体或纯画面时隐藏。名称旁小圆点用于定位，不代表天体大小；名称随三维镜头投影移动，隐藏视野外及被其他球体遮挡的名称。
- **操作**：取景、拖动、滚轮、方向键、加减键都围绕当前目标；手动操作停止自动镜头环绕。桌面和窄屏分别根据操作区空白范围取景，镜头避免进入展示球体或土星主环包围区。

### 第二步的数据边界

1. 地月直接对同一个主页定格状态中的月球、地球位置和速度作差。土星卫星通过现有 `useSatellites` / `ephemeris/satellites` 读取同一时刻的土星中心几何历表；运行时访问网站同源的 `data/satellites/` 月度数据包，不临时查询外部 JPL 服务。
2. 原始坐标为 ECLIPJ2000，位置 km、速度 km/s；时间使用 TDB。转换为场景 `(x, z, -y)`，以母星平均半径为单位，不施加全景距离压缩。
3. 太阳光方向从各天体未放大的真实中心计算。母星与月球沿用参考姿态及静态贴图；三颗土星卫星用已有的程序化外观；第 3 步加入朝向母星的同步自转参考，仍不声称是实测表面经度或精确潮汐姿态。相互掩食尚未计算。
4. 半径和参考周期复用现有资料；土星卫星半径为 NASA/NAIF 三轴半径的体积等效值，球体不表现真实扁率。详情提供 [NASA 月球](https://science.nasa.gov/moon/facts/)、[NASA 土星卫星](https://science.nasa.gov/saturn/moons/)、[NAIF 半径资料](https://naif.jpl.nasa.gov/pub/naif/generic_kernels/pck/pck00011.tpc)、[JPL 卫星参考轨道参数](https://ssd.jpl.nasa.gov/sats/elem/)及本地历表清单入口。
5. 数据未就绪时只展示已知母星，并常驻等待/失败说明。失败可原地重试，成功后以同一日期重新收入家族同景。不会把缺少卫星的画面宣称为完整加载。
6. 进入时默认暂停。第 3 步已接入历表播放；“播放天体运动”推进共同日期，“镜头环绕”只改变观察位置。

第二步验证：351 项自动检查通过、生产构建通过。新增检查覆盖地月相对状态、坐标转换、平移不变性、成员过滤、缺数据、真实/放大半径、三维对象中心不移动、标签遮挡及 1600×960 / 1024×640 / 390×844 的取景边界。浏览器检查地月/土星两种同景、比例切换、靠近与返回、随镜头移动的标记、键盘缩放、纯画面说明和窄屏；原有四个近景操作也已回归。故意阻断土星月度历表后确认没有虚构卫星，解除阻断并重试后恢复三颗卫星，期间无运行时异常。构建仍保留原主页包体提示。

### 第三步：入口与运动衔接

- **承接当前对象**：全景中的太阳进入「恒星之缘」，地球进入「蓝色地平线」，土星进入环近景；地月和土星家族进入对应同景。选中的月球、土卫二、土卫五、土卫六会直接靠近该卫星。当前对象没有沉浸预设时，明确说明后打开土星环示例，不将示例冒充所选对象。
- **两个独立控制**：「播放 / 暂停天体运动」控制历表时间，提供实时、1 小时/秒、6 小时/秒、1 天/秒；「镜头环绕」只移动镜头。自转与公转共享日期，不能把其中一项偷偷停止后仍标称同一真实时刻。镜头运动默认关闭，拖动和缩放会停止镜头环绕，保留天体运动状态。
- **共同日期**：上方始终显示当前有效北京时间。底部「日期」可输入时间、返回现在或进入时刻；应用后暂停。日期草稿不影响画面，超出范围有提示；到末端自动暂停，不外推。纯画面仍保留日期、状态和运行时的暂停按钮。
- **空间连续**：同一取景内只更新已有三维对象的位置、参考姿态、光照和参数，不按时间帧销毁重建渲染器。靠近卫星后镜头随其平移，保留用户观察角度和相对距离。播放家族同景时预留当前轨道平面内的环绕空间；这是取景范围，不是额外画出的轨道。暂停后可点「复位视角」恢复当下更紧凑的构图。
- **返回全景**：带回沉浸观景的最后有效日期，保留全景镜头、原选择、图层、倍率，恢复进入前的播放/暂停状态。在沉浸内切换预设不会悄悄改选全景对象。组件加载失败时的关闭仍回到进入时刻。
- **完整数据再发布**：母星及当前可见卫星都完成同一时刻的取样后，才一次性更新画面。月包读取中保留上次完整状态，不累计加载等待时间；失败暂停并提供重试。快速改日期、切家族、暂停或关闭后，过期响应不能覆盖新状态。标签页隐藏期间不累计时间；三维连接中断时暂停天体运动和镜头环绕。
- **自转边界**：太阳、行星和月球按现有 IAU 线性参考模型随时间更新；月球未重建精确天平动与贴图经度。三颗土星卫星用轨道位置/速度构造“同一参考面朝向母星”的同步自转近似，不模拟天平动和内部潮汐形变，也不把程序化纹理当作实测地貌。自转/公转参考见 [NASA/NSSDCA 土星卫星参数表](https://nssdc.gsfc.nasa.gov/planetary/factsheet/saturniansatfact.html)。日珥、日冕、云图仍是外观示意，不因播放时间就成为实时活动或天气。

第三步验证：**358 项自动检查通过，生产构建通过**；新增检查覆盖 15/30/60 帧率的共同时间推进、暂停、倍率、范围、同帧数据发布、读取失败与重试、过期请求、关闭、北京时间换算、入口映射及卫星三维对象更新和同步参考面。浏览器核对地球表面随日期转动、地月与土星卫星位置随时间变化、卫星跟随、渲染器不随时间重建、时间与镜头独立、窄屏日期面板、进入当前对象、返回日期/选择/播放状态。故意阻断跨月数据，确认保留最后完整帧、恢复后保持暂停；历表末端自动停止。另模拟三维连接丢失，确认运动暂停、重建画面后保留日期。正常流程无脚本或着色器错误；构建仍有原主页包体提示。

## 四个近景与两个同景

| 入口 | 要观察的内容 | 取景方式 |
| --- | --- | --- |
| 环上掠影 | 土星球面、环面遮挡、卡西尼分界与球体投影 | 相对赤道面约 24°，斜向构图 |
| 贴近环面 | 同一组环从侧面怎样变薄 | 相对赤道面约 4°，镜头仍在主环外 |
| 蓝色地平线 | 地球曲率、静态云层与薄蓝色大气 | 昼夜交界方向的大幅近景，能自由拖动缩放 |
| 恒星之缘 | 太阳轮廓、表面与外层辉光 | 虚拟近景；日珥与日冕为增强示意 |
| 地月之间 | 地球、月球的真实大小与中心距离 | 同一空间与比例尺；支持靠近及返回同景 |
| 土星与它的卫星 | 母星、主环与三颗代表卫星 | 同一空间与比例尺；读取同源本地卫星历表 |

拖动旋转、滚轮缩放；画面获得焦点后方向键可旋转，加减键可缩放。镜头环绕只改变观察位置，手动操作会停止镜头环绕。复位恢复当前预设。纯画面收起说明和底部选择，保留返回、显示界面、时间及运行时的暂停入口；家族比例说明也保留。Escape 优先收起日期面板，再恢复纯画面界面、关闭说明，最后返回全景。

## 数据、尺度和外观的边界

- 进入时复制主页最后有效历表状态，并暂停主页时间。返回时带回沉浸观景的最后有效日期，保留全景镜头、选择与图层，恢复进入前的播放状态。
- 局部坐标以目标平均半径为单位；使用同一时刻的太阳减目标向量，并按 ECLIPJ2000 → 场景轴转换计算光照。太阳、行星和月球姿态复用现有 IAU 参考模型；三颗土星卫星用前述同步参考。暂停时间时不额外旋转天体。
- 取景位置是为观察设计的虚拟位置，详情中的镜头距天体中心由局部半径换算。四个近景对不同目标独立取景，视大小不能用于比较真实大小；两个家族同景共享距离尺度，辅助放大另行标注。这不是任何航天器的实测位置，也没有连续跨行星飞行。
- 土星主环复用 C/B/A 三段边界和静态环图；球体遮挡环、环对球面投影采用简化几何。球体为平均半径球，未重建扁率、环厚度、颗粒和细小结构；分界区域简化为空隙，不代表完全真空。
- 地球云层使用已入库静态云图；大气散射、海面反光与云影为显示近似，不是实时天气。
- 太阳橙色表面、日珥与日冕为增强示意，不代表肉眼颜色或实时活动。没有把普通化学火焰或未知云海添加到真空。
- 背景星点是可关闭的氛围示意，未接入全景实测星表；暗面辅助补光可关闭。亮天体与背景星点同屏不是相机曝光模拟。
- 科学内容来源：[NASA 土星环](https://science.nasa.gov/mission/cassini/science/rings/)、[卡西尼环外影像参考](https://science.nasa.gov/resource/saturn-bright-through-rings/)、[NASA 地球](https://science.nasa.gov/earth/facts/)、[NASA 太阳](https://science.nasa.gov/sun/facts/)。位置与速度沿用 [JPL Horizons](https://ssd.jpl.nasa.gov/horizons/)。贴图署名和授权沿用 `public/textures/sources.json`，没有引入外部实时图像服务。

## 本轮集中验收（有限四项）

1. **近景**：在全景定位地球后进入沉浸观景，切「完整球体」，用 1 小时/秒播放；应看到大陆与云图随参考自转移动。暂停天体运动再开镜头环绕，日期应保持不变。再检查两个土星环视角和太阳分层。
2. **同景**：查看地月与土星三颗代表卫星；确认真实比例、辅助放大标注、距离与参数。用 6 小时/秒播放，选择一颗卫星靠近，镜头应持续跟随，仍可拖动。
3. **日期与返回**：应用不同月份的日期、返回进入时刻；确认暂停和日期一致。返回全景后保留刚才的日期、全景原选择与图层，恢复进入前的播放状态。
4. **界面与边界**：检查纯画面、日期面板、窄屏、来源与放大说明；未接入对象应明确提示，不能错误显示为对应对象。真实比例下远景小、背景星点为示意、外观非实时都属于已声明的边界。

技术检查与发布成功不等同于用户验收。接下来按上述四项集中检查；发现问题则记录复现步骤并只修复本轮范围内的问题；用户确认通过后，记录验收结论和对应发布提交，将沉浸观景阶段归档。不追加无期限的优化轮次。

归档后再从[后续产品方向](POST-ACCEPTANCE-PLAN.md)中选择一个有明确目标的分支，例如有来源的真实卫星/探测器观察，或可控的飞掠与飞船任务。这些方向需要各自的数据、规则与验收范围，不属于本轮待完成事项，也不会因本次发布自动启动。
