## 首版补项与延期边界

下列是跨类别子项，不新增顶层天体计数；规划补正不代表实现完成。

### S01 · 小天体形状与多体系统 / 首版必补

不规则形状、双小行星、小天体卫星；接触形状与绕转双体分别说明。
本版标准：至少一个有依据的不规则形状和一个双体/小天体卫星系统，可共用对象。
延期：全量精密形状、接触演化与碎石堆物理延期。
归属：R01 / R03 / R04；E03 / E06。
- [科学依据 1](https://science.nasa.gov/solar-system/asteroids/facts/)

### S02 · 共轨与远缘群体分类 / 首版必补

准卫星、共轨关系，以及经典/共振/散射/离散群体。
本版标准：一个共轨或准卫星案例可比较参照系；经典和共振成员各有代表，已有样本可复用。
延期：不要求重建每个共振族群和长期混沌演化。
归属：R01 / R02 / R06；E07 / E08 / E10 / E11 / E17。
- [科学依据 1](https://science.nasa.gov/solar-system/kuiper-belt/facts/)
- [科学依据 2](https://www.jpl.nasa.gov/news/small-asteroid-is-earths-constant-companion/)

### S03 · 太阳分层与活动类型 / 首版必补

光球、色球、日冕、黑子、日珥与已有耀斑/CME 的区别。
本版标准：每层/类有说明和来源；一个分层视图与可选择的活动示例，不标称当日实况。
延期：实时太阳监测和完整磁流体计算延期。
归属：R04 / R05；E01。
- [科学依据 1](https://science.nasa.gov/sun/facts/)

### S04 · 表面活动与内部结构 / 首版必补

地质活动、喷流、内部海洋及物质向环系补给的代表性关系。
本版标准：至少一个代表有近景、剖面或原理解释；土卫二可作候选，观测与内部推断分开。
延期：所有天体内部结构、全球地形和连续地质演化延期。
归属：R04 / R05；E02 / E03 / E14。
- [科学依据 1](https://science.nasa.gov/mission/cassini/science/enceladus/)

### S05 · 不可见的场与粒子环境 / 首版必补

行星际磁场、电流片、光与粒子辐射、中性粒子。
本版标准：每项有来源和视觉含义；场结构与粒子示意可分开开关，不要求逐粒子模拟。
延期：实时通量、精密辐射剂量和空间天气预报延期。
归属：R05；E14 / E15 / E16。
- [科学依据 1](https://science.nasa.gov/learn/heat/resource/components-of-the-heliosphere/)
- [科学依据 2](https://www.nasa.gov/image-article/heliospheric-current-sheet/)
- [科学依据 3](https://science.nasa.gov/learn/basics-of-space-flight/chapter1-1/)

### S06 · 人类探索与人造实体 / 接入待定

探测器、人造卫星、空间碎片；真实轨迹展示与可操控飞船分开。
本版标准：本版明确列出边界；轨迹对象、数据期和样本名单另行确定。
延期：遵循此前待定决定，不加入自然太阳系认知版完成门槛。
归属：范围边界，不新增执行批次；不计作内部自然成员。

### S07 · 太阳系形成与演化 / 知识总图 / 深化延期

形成历史、长期轨道变化和演化专题。
本版标准：总图有位置及范围说明，独立于当前日期观测。
延期：历史演化动画、数值重建及完整形成模型延期。
归属：范围边界，不新增执行批次；不计作内部自然成员。

### S08 · 更广泛宇宙专题 / 后续分支

星云、黑洞、恒星演化、星系团等，对应 U1。
本版标准：与第八批有限宇宙背景区分，不计入太阳系内部成员覆盖。
延期：专题观察和演化模型独立立项。
归属：范围边界，不新增执行批次；不计作内部自然成员。
