## 二、哪些是真实数据，哪些是示意

- **位置与速度**：原十体及谷神星、冥王星、卡戎采用 JPL Horizons 几何状态；19 颗扩展行星卫星来自 NASA/NAIF SPK。离线整理后按月份加载，在统一时刻插值。来源、版本、坐标、单位和覆盖范围见[数据流程](DATA-PIPELINE.md)、[卫星数据](SATELLITE-DATA.md)与[扩展天体数据](DWARF-DATA.md)。
- **视觉呈现**：空间观测会压缩距离或放大球体；真实比例可恢复科学长度关系。球面纹理、云图、大气、日冕和背景星空不是实时影像。地月空间观测保留真实半径比，但缩短地月间距。
- **宏观点云与边界**：表示区域和结构，不是每颗真实天体的精确位置；奥尔特云明确为推测结构。参考[宏观结构说明](MACRO-STRUCTURE.md)。
- **轨道线**：瞬时二体参考轨道不是未来完整真实路径；已经播放的路径另行标示。卫星视图不显示已播放路径。
- **物理验证**：独立的十体简化模型，不是全部 32 个天体共同积分。插值差异、积分误差、模型与历表的差异分别报告，不能混为精度承诺。参考[验证报告](VALIDATION.md)。

## 三、当前还没有完成什么

- 从宏观区域到具体对象的完整学习路径；现有尺度导航与导览已有基础，尚需把上下文说明和逐步观察串成一个过程。
- 跨层级的精确镜头历史恢复。当前层级按钮可以切换视图，不等于记录并恢复每次拖动后的镜头位置。
- 与画面同步的分步运动讲解。已有“观看地月公转”等加速入口，尚未形成包含观察目标、步骤、暂停说明和退出恢复的完整课程。
- 更多对象的动态历表、真实星表背景、实时气象及精密表面姿态。
- 参数编辑、增删天体、碰撞、飞船、角色与游戏任务；“扩展路线”中的这些内容仍是规划。

## 四、怎样验收当前版本

建议在桌面浏览器按以下步骤操作；勾选项留给使用者，不预先记为通过。

- [ ] 打开全景，待数据加载完成确认动态成员为 32；修改日期后无持续加载或错误提示。
- [ ] 选择地球，通过“观察尺度”进入内行星区域、地月系统及单体近景；查看地月距离与比例说明。
- [ ] 点击“观看地月公转”，确认时间加速并能暂停；切换真实比例，理解两球距离变远的原因。
- [ ] 进入地球近景，分别开关云层与大气；进入土星系统，查看环及已接入卫星。
- [ ] 进入“冥王星—卡戎”，点击“观看卡戎公转”，观察两体位置随时间变化；从目录进入谷神星。
- [ ] 打开“宏观结构”“星点与环”“数据与实现”，能区分历表、示意点与来源；返回观测后日期和选择行为符合预期。
- [ ] 在图鉴查看 67P，确认外观预览与宏观页真实运动入口说明分别标注。
- [ ] 进入物理验证，确认说明为十体模型；报告区分不同误差，返回观测可继续使用已有对象。

## 五、后移计划：地月分步学习（待实施）

优先级已调整：先补全宏观全景，见 [宏观第一批本地验收](MACRO-EXPANSION.md)。以下地月计划保留为后续阶段。

后续范围：以“太阳系 → 地球所在区域 → 地月系统 → 月球近景”为唯一完整范例。复用已有场景、历表、尺度导航与公转按钮，暂不增加天体或修改引力模型。

| 顺序 | 做法 | 验收标准 |
| --- | --- | --- |
| 1. 统一观察上下文 | 整理当前区域、目标、视图、比例、时间和播放状态；把宏观入口与观测导航对应起来。尚无动态数据的区域只进入说明 | 切换入口后目标、标题和选中状态一致；不把奥尔特云点云当作可跟随的实测对象 |
| 2. 增加可返回的观察路径 | 保存进入下一层前的镜头位置、朝向、观察目标与比例；“返回上一步”恢复这些状态。普通导航继续沿用同一时间轴 | 全景进入地月再返回时，视角不意外跳回默认；快速连续操作不会恢复错误目标 |
| 3. 增加地月分步讲解 | 按“辨认两球 → 看真实距离 → 加速看公转 → 解释自转与潮汐锁定”组织内容；每步说明画面、时间倍率与来源。涉及新科学表述时核对 NASA/JPL 原文 | 每一步都有明确观察目标，可暂停、重看、退出；自转示意与精确姿态的边界可见 |
| 4. 统一退出行为 | 启动课程前保存观测快照；退出课程恢复启动前的日期、播放、倍率、比例、选择和镜头。用户主动跳转其他目标时退出课程，执行其新选择 | 课程不覆盖原实验；暂停、日期边界和中途跳转有明确结果 |
| 5. 本地验收再交付 | 对状态切换与返回增加必要回归检查；本地检查桌面及窄窗口的遮挡、键盘退出和加载异常。先提供本地验收地址与步骤，使用者确认后再推送功能变更 | 来源可查、说明与画面一致、已有 32 个动态天体和十体验证不回退 |

下一轮要交付的是一条可亲自走完的学习路径，不是再次增加几个并列入口。地月范例验收后，再复用到木星卫星、土星与冥王星系统；更多天体及游戏能力仍按[长期路线](ROADMAP.md)另行推进。
