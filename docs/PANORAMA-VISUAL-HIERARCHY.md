# 第一批：全景视觉整理

## 问题与效果

远景同时堆叠区域、行星本体、系统家族和现象入口，会让宏观画面难读；各模块先后读取上一帧的标签又可能产生位置跳动。近景中放大后的太阳或其他行星也可能抢占目标画面。

本轮不新增目录或控制按钮，整理既有显示策略：

- 未定位对象的远景优先区域说明，保留太阳名称作为中心参照；靠近后再展开行星、家族与现象入口。天体几何本身仍保留，目录和定位按钮不变。
- 每帧先清除所有旧标签与引线，再依次布局本体、区域成员、现象、家族和双体。后续模块避让同一帧的已放置标签，避免旧位置互相挤占。
- 本体标签沿用天体颜色，与绿色现象入口区分；新增短引线，起点移至球体轮廓之外。土星本体及系统名称预留环外缘空间。
- 太阳 / 行星本体与卫星系统近景暂时隐藏其他太阳与行星球体，收起参考平面和高度线；目标的环和卫星遵守原控制开关。返回时恢复，勾选值不被修改。背景区域与线条沿用已有淡化策略。
- 示意星空跟随镜头平移，不跟随镜头转动，不造成星点就在太阳系附近的假视差；星空不参与近景环境淡化。它仍非真实星表，亮度也不代表实测星等。

## 实现边界

远景标签阈值沿用既有场景距离 42（渲染单位，不是 AU）；`macroVisualHierarchy.ts` 只决定表现层状态。球体隐藏使用稳定 ID，光源仍保留在太阳位置，未改变日夜照明方向。隐藏太阳从球体点击候选中移除，避免看不见的球体拦截选择。

`macroPrimaryLabels.ts`、`macroFamilyScene.ts` 的预留半径仅用于标签排版，不改变网格半径、参数或环尺寸。空间不足时标签暂不绘制，用户仍可从内容目录定位；远景不会删除任何已加载目标。用户主动隐藏标注时，各类标签和引线都清除。

没有改变历表、天体数量、时间轴、引力模型、距离映射或轨道倾角；没有为立体感人为撑高行星轨道。家族与本体的临时隐藏在画面说明和参数区明示。轨道线与小天体区域仍可保留为上下文，不属于完全孤立的天体预览。

## 验收

1. 打开综合全景，远景不堆叠行星与家族入口，区域名称仍可辨认。
2. 点「总览行星轨道」，名称随近景展开；暂停日期后标签布局保持稳定。
3. 定位水星、土星：放大的背景太阳不占画面，名称不横穿球面、土星名称避开环。查看参数或切换日期仍有效。
4. 从土星进入卫星系统，母星、卫星与环可继续观察，无关主行星球体收起；返回原视角恢复。
5. 定位哈雷、冥王星—卡戎，标签仍可使用；彗星视角不混入其他现象定位标签。
6. 隐藏 / 显示标注，复核日期与图层勾选不变；700px 窄窗口可操作。

36 个测试文件、152 项检查通过。新增显示策略测试覆盖远近、显式定位与本体隔离 / 恢复。浏览器检测跨模块标签无重叠、暂停布局稳定、原画布和时间不变、图层保持、返回及窄窗口，无运行时异常。桌面、土星家族和窄窗口截图复核完成。生产构建通过，保留主包体积提示。
