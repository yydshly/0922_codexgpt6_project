## 本地验收路径

1. 综合全景 → 场景清单 → 爱神星不规则形状 → 定位 / 控制。原画布靠近，周围天体仍在场。
2. 关闭“显示资料形状”看同体积球，再恢复并打开三角网格；位置和日期不变。
3. 用底部日期/倍率推进；暂停后形状姿态不再自行推进。拖动观察是转动镜头。
4. 对照分离双体，后退恢复爱神星形状设置；阶段 03 关闭时场景不再绘制爱神星。
5. 形状文件加载失败时说明退回球形位置标记，提供重试；恢复后同一画布出现模型。

## 第二部分 · 太阳大气分层与活动区别

2026-09-25 本地更新。综合全景 → 场景清单 → 太阳活动 → 定位 / 控制 → 五步分层。太阳光球本体始终保留，按顺序叠加色球、过渡区、日冕，再查看黑子与日珥；对照耀斑与 CME 使用原有独立示意进度。所有新增图形属于同一主场景，受阶段 07 与太阳活动总开关控制。没有新增天体数量。

分层来自 [NASA 层次说明](https://science.nasa.gov/blogs/the-sun-spot/2023/09/26/layers-of-the-sun/)，[黑子](https://science.nasa.gov/sun/sunspots/)、[日珥](https://www.nasa.gov/image-article/what-solar-prominence/)、[耀斑与 CME](https://science.nasa.gov/blogs/solar-cycle-25/2022/06/10/solar-flares-faqs/)分别标出处。public/data/solar-atmosphere/manifest.json 是人工整理的来源与示意参数登记，不冒称原始实测数据。

半透明大气使用显示半径 0.34 / 0.38 / 0.415 / 0.62，单位是场景单位；这些比值没有真实物理厚度含义，空间间隔特意扩大。过渡区不是均匀壳，日冕没有模型外沿所代表的硬边界。黑子是表面暗斑，日珥为两脚贴合太阳表面的程序拱环；角度、位置、数量、纹理均不关联当天活动。未计算磁场、自转漂移或爆发形成过程，也未增加太阳内部剖面。

观察顺序只调整太阳分项，其他环境选择保留。按钮定位太阳活动锚点，右侧分层引导保持原位；活动对照改用较宽镜头。移除主太阳额外的重复光晕，避免关闭日冕仍留下同形光晕。

验证：53 个测试文件 / 211 项通过，覆盖层次顺序、独立开关、实际场景显隐、日珥脚点和其他环境选项保持。浏览器通过五步实际几何数量、同画布与日期保持、右侧引导不跳走、耀斑/CME 对照、浏览后退恢复、阶段 07 隐藏/恢复、来源登记访问和 390px 窄屏检查。桌面与窄屏截图已查看，未见运行异常；构建通过，已有大包提醒保留。

## 第三部分 · 土卫二喷流与内部示意

2026-09-25 本地实现，未提交部署。综合全景 → 场景清单 → 土卫二喷流与内部结构 → 定位 / 控制。先看表面与喷流，再打开内部，逐层开关冰壳、海洋与岩核；返回土星家族保留周边天体。选择土卫二时镜头跟随它的历表锚点，不再只跟随母星；数据缺失时隐藏本体及附属现象，不用旧位置。

来源分别是 [NASA 土卫二概览](https://science.nasa.gov/saturn/moons/enceladus/)、[2015 年全球海洋摆动证据](https://www.nasa.gov/news-release/cassini-finds-global-ocean-in-saturns-moon-enceladus/)、[喷流与 E 环关系](https://science.nasa.gov/missions/cassini/the-moon-with-the-plume/)。本地 public/data/enceladus-interior/manifest.json 登记来源、版本和限制，不是新的观测包。

喷流存在及成分有卡西尼直接观测，内部全球海洋由摆动、重力等证据支持，不能把剖面当透视照片。三个显示半径 1 / 0.84 / 0.61 是无量纲教学比例，不代表真实层厚。剖面开口、颜色与姿态为解释设计，局部 -Y 为示意南极；不代表当日实测极轴。640 个静态点表达羽流形态，不是实测粒子数或喷发速率。不模拟地质流体、潮汐加热或环粒子补给，也不宣称生命探测。表面仍是示意材质，真实地形、虎纹裂隙未重建。

## 第四部分 · 核心外观与参数一致性核对

### 范围与结果（2026-09-25）

29 个核心对象：太阳、八大行星、月球，以及现有 19 颗母星中心 SPK 卫星（火卫一/二，木卫一至四，土卫一/二/三/四/五/六/八，天卫一至五，海卫一）。其他 7 颗已接入卫星沿用 R03 记录，不在这里承诺新增高精度外观。

- 全景太阳原来是静止贴图，现按观测时刻使用与精细观测相同的参考姿态。不是随画面帧数累加；暂停日期不会继续自转。黑子、日珥等独立静态示意不作为当日活动。
- 全景月球原来是颜色球，现复用已有月球静态纹理与参考姿态。不虚构新的纹理精度、经度配准或天平动能力。加载失败保留颜色球；离开场景销毁贴图，晚到回调丢弃纹理。
- 统一三个视图的基础姿态算法，避免两份公式漂移；保留原有 J2000 固定极轴 + 线性 W 模型及火星 IAU 2009 例外。
- 参数卡分别报告资料自转周期与渲染模型周期，尤其海王星不能将两者混为同一数值；逆行保留有符号 W，不重复叠加倾角。月球 6.68° 参照月球轨道法线，太阳 7.25° 参照黄道法线，行星参照各自轨道法线。
- 增加右侧“外观与参数核对”，按恒星 → 行星 → 核心卫星查阅；不另开画布，不改变日期。下载记录、物理来源、贴图许可可直接打开。
