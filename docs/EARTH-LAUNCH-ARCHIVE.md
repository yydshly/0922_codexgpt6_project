# 地球出发教学版 · 阶段归档

归档日期：2026-09-28。版本：`2026.09.28-earth-launch-r1`。对应 Git 标签：`earth-launch-2026.09.28`。

用户决定：“先归档，提交。操控航天器的能力可以做个记录，后期实现。”本次冻结已有教学范围，汇总此前尚未提交的功能、说明与验证证据；航天器操控只登记为后续候选，不在本版开发。

这是用户授权的阶段归档，不新增“所有功能逐项验收通过”的记录，也不将教学流程连通解释为完整工程级航天模拟。既有太阳系认知版和沉浸观景的确认记录继续独立保留。

## 归档包含什么

| 范围 | 已有能力 | 必须保留的解释 |
| --- | --- | --- |
| E1–E6 地球出发 | 基地、组装、检查点火、上升分级、入轨关机与实际滑行一圈验证、开舱释放卫星 | 有限部件配置、简化大气和辅助制导；不是实际型号的飞控或遥测 |
| 沿途现象与读数 | 点火时序、烟羽、低压喷流、空气密度与阻力、三维受力、动压与上升记录 | 视觉示意、受力读数、热流和温度分别说明；动压不是温度 |
| P1 分离分析 | 同一初态的滑行/侧向机动对照、有限点火、15 分钟距离与轨迹分析 | 理想指向与教学节流；不提供长期避碰保证 |
| P2 二级离轨 | 有限反向点火、轨道变化、推进剂/压力/电能账目、简化钝化 | 降低近地点不等于已经再入或落地 |
| P3 再入教学 | 从 P2 继续下降、120 km 检查点、密度/阻力/减速/驻点热流，到 20 km 停止 | 20 km 是计算边界；没有悬停、烧蚀解体、残骸存活或落区结论 |
| P4 卫星工作 | 理想对日定向、日照与地影充放电、240 MB 观测数据、教学地面站窗口下传 | 简化姿态和通信条件；进入此段后二级只保留带独立时刻的历史记录 |
| P5 无推进卫星 | 一圈能源维护、保留工作或结束任务、窗口指令、电能收尾、退役后短时观察 | E01 无推进器；退役表示业务结束，仍在轨道上，未完成空间处置 |
| 任务结果与存档 | 分对象结果、未执行路线、摘要下载、飞行保存与校验恢复、旧档导出、失败会话副本 | 摘要不能恢复任务；打开存档先暂停，当前飞行和已保存时刻分开显示 |
| 火箭外观 | 共用完整箭体、原创涂装、级间结构、曲面喷管、管路、载荷适配器和整流罩细节 | 外观优化不更改动力参数；仍是原创教学载具，不是某个真实型号复刻 |

路线关系：E1–E6 → P1；二级路线 P1 → P2 → P3，卫星路线 P1 → P4 → P5。也可从 P3 接续 P4。工作包编号不代表所有对象始终同时推进，更不代表用户已执行全部路线。

- 本版以 `earth-launch-2026.09.28` 标签对应的提交为准，包含功能、文档、测试与可公开的截图证据；不会提交浏览器个人存档、缓存或本机构建目录。
