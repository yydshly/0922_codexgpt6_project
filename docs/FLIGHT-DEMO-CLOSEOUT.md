## 1. 说明和参数对应当前对象

- E02 通用参数读取卫星的 200 N 发动机与比冲计算耗油率，不读取运载二级发动机的质量流率。
- E02 的运行状态、环境温度、马赫数和热流读取当前卫星离轨模型。卫星工作阶段不会误取二级冻结的热流记录；未求解的表面温度保留为空。
- 沿途现象区分当前对象、早先的上升曲线和当前阶段的大气模型。上升图层说明放入「回顾」，不会把再入状态标成正在发射穿云。

## 2. 回看和比较

入口：**地球出发 → 选择演示方案 → 从头到尾演示**。

演示操作区新增：

1. **章节回看**：仅开放本方案已经实际到达的章节。点击后在独立计算线程重放该章之前的实际命令，核对状态，再暂停于章首。点击「继续全程演示」从那里继续。未到达章节保持禁用，不能伪造前提或跳过失败。
2. **对比 E01 / E02**：先列出发射质量、推进能力、退役流程和终点边界；下方单独列出实际跑完的结果，包括卫星终止时刻、高度、交付数据、点火耗油、残余推进剂、电量及二级历史记录的时刻与高度。未跑完的方案显示「尚未完成」。

两种方案的结束时刻不同，因此结果不是同一时刻的位置对照。章节快照和比较结果仅保留在本次演示会话；退出恢复原手动任务并保持暂停，不覆盖浏览器存档。刷新不会保留临时演示进度；正式任务仍使用原飞行存档入口。
