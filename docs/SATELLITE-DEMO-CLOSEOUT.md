## 本轮检查发现与修正

1. 返回观测近景原先会把 40° 视场重置成 20°。现在重新取景保留用户角度与辅助线选择；首次进入演示环节仍使用明确的默认配置。
2. 地表近景原先亮起「轨道全景」。现在有独立「地表观测近景」按钮，三个视角互斥选中；按钮操作与实际取景一致。
3. 能源参数标题原先只按日照判断，背向或低发电时仍可能写成正在充电。现在按同一功率和电量账本区分地影、背向、发电不足、收支平衡、充电、电池已满与电池耗尽。
4. E02 数据交付后的说明残留 E01 无推进文字。现在按本次卫星设备显示对应后续路线，参数页也同步解释两个方案。

5. 验收栏原先只有文字清单，且直接打开 Markdown 时响应未声明字符编码，部分浏览器会显示乱码。现改为网页内中文阅读，关联说明与检查截图也在正文内打开；提供带 UTF-8 标记的原文下载。验收栏增加当前卫星画面定位、已到达的第 6 章回看和结束后的结果入口，未到达时解释需先完成发射与部署。

6. 展开验收清单时原先仍在播放，阅读会错过关键画面。现统一暂停章节、方案对比和资料阅读；收起不会自行继续，另有明确的返回并继续按钮。定位、回看与方案切换会收起阅读区并展示当前章节与播放操作；资料可用收起按钮或 Esc 返回，迟到的加载结果不再抢焦点。

7. 检查点原先只写「即将自动继续」，难以判断是暂停还是自动等待。现把演示状态放到播放按钮下方，显示讲解剩余时间与接下来的动作；与自动演示共用同一动作和时长安排。暂停同时冻结任务时间与讲解计时，进入实际运动后清除讲解计时；等待通信窗口不提供未经计算的预计秒数。E01/E02 交付后的下一步按真实配置分别显示，失败与完成状态不再提示自动继续。

8. 后台计算意外中断时，旧演示可能仍标为运行，恢复指令仍发给已停止的计算器。现关闭旧连接并拦截迟到消息，主画面与侧栏显示停止，移除无法执行的继续与章节回看。恢复会重新启动计算：选择新的地面任务，或读取已有存档并重算；失败仍可重试。不能保存冻结帧覆盖正式存档，也不承诺未保存进度仍可继续。启动失败、发送异常与结果读取异常共用此流程。

上述修改不改变正式轨道积分、能源积分、任务指令、存档版本或任务结果。

截图可以确认布局、选中状态、可见箭头和说明；动力学与账本靠自动检查核对。没有声称读屏软件或全站无障碍合规已验收。

## 用户验收：固定三组

入口：**地球出发 → 从头到尾演示**。第六章不需另勾选功能；可暂停，已到达章节可回看。展开下方说明会自动暂停；收起后仍保持暂停，可点击「返回画面并继续演示」或顶部的「继续全程演示」。

1. **定向与供电**：蓝色发电面的箭头逐渐与黄色太阳方向一致，夹角接近 0°；地影中仍为 0 W。打开工作参数，供电说明与功率一致。
2. **观测到交付**：地表近景有橙色几何范围；选择「宽 40°」后拖动并点击返回近景，仍保留 40°。点击轨道全景，选中状态随之改变。下传时机上数据减少，地面已收增加；交付结束再进入末期路线。
3. **结尾与恢复**：分别运行 E01/E02，核对仍在轨与动力离轨参考终点的区别。暂停、章节回看、退出均正常，退出后原任务与保存记录保留。
