# R01–R09 交付归属与首版收尾

当前规划版本 2026.09.25-r09.4；能力基线 r09.3 已上线。本轮只整理台账和验收范围，没有新增天体。用户总验收未完成。

接下来的顺序固定为 [C01–C05 五步收尾](FIRST-RELEASE-CLOSEOUT.md)，不重新从 R01 开发。R01–R09 保留内容和原验收标准，主页九批图层开关是另一套显示控制。

## R01 · 行星区域内的小天体

当前：代表已上线；数据/入口有核验记录，待用户验收。

归属：M1.1 / M1.2 / M1.3 / M3.1；主题：E06、E07、E08、E09。

前置：现有主带、成员目录和历表供数可复用；先核对候选数据、许可、有效期与资源预算。

### 原定必须内容

- 近地小行星至少一例、木星 L4/L5 各一例、半人马族至少一例。
- 冻结对象身份、父系统、坐标、时间、采样误差与来源；可共用已有样本，避免重复计数。
- 为后续批次登记不规则形状、双小行星、小天体卫星和共轨样本候选。

### 验收标准

- 各类通过准入的代表均有全景、定位、运动、参数及来源入口。
- 独立检查点验证通过，误差预算与轨道本身的不确定性分别记录。

边界：候选数据不可靠时明确阻塞或记录替代方案；不以虚构坐标凑齐类别。

## R02 · 远缘成员与跨区域对象

当前：远缘成员与历史访客已上线；待用户验收。

归属：M3.1 / M2.2；主题：E10、E11、E12、E13、E20。

前置：使用第一批的数据准入规则；复用柯伊伯带、彗星及远缘成员入口。

### 原定必须内容

- 区分经典、共振、散射和离散轨道群体，补离散轨道代表。
- 接入至少一个长周期彗星代表及一个可靠的星际访客案例。
- 把远缘成员与奥尔特云来源解释连接起来，保留模型推断边界。

### 验收标准

- 至少一个经典与一个共振成员可对照；已有对象符合条件时直接复用。
- 案例有可追溯轨道、有效日期及区域关系说明；独立历史窗口有明确切换和返回。

边界：不虚构奥尔特云逐体坐标；跨时段案例不强行放进 2026—2027 年窗口。

## R03 · 卫星家族、双体与环

当前：约定家族、双体与环代表已上线；待用户验收。

归属：M3.2；主题：E03、E04、E05、E06。

前置：已接入卫星、冥王星—卡戎和四大巨行星环可复用。

### 原定必须内容

- 补冥王星余下四颗卫星，以及至少一个其他矮行星卫星系统。
- 接入至少一个双小行星或小天体卫星系统；同一真实系统可兼顾两个认识目标。
- 核对巨行星代表环段，加入至少一个小天体环的有来源说明或示意。

### 验收标准

- 父子关系、系统质心与相对运动说明一致，质量不在物理模型中重复计入。
- 局部尺度、实际尺寸、环宽增强与轨道参考线分别标明。

边界：无可靠相对历表的候选不能标称真实动态双体；说明性模型独立标注。

## R04 · 天体外观、结构与表面

当前：基础外观、形状和结构示意已上线；高精度深化不在本批完成声明内。

归属：M3.3 / M2.3；主题：E01、E02、E03、E05、E06。

前置：复用已有球体、纹理、云层和光照；按核心名单逐体核对。

### 原定必须内容

- 核对太阳、八大行星及核心卫星的半径、自转、轴倾角、昼夜、大气与静态云图。
- 增加至少一个有依据的不规则小天体形状；讲解双体与接触形状的区别。
- 补太阳光球、色球、日冕及黑子、日珥的分层说明；补一个地质活动或内部结构代表，如土卫二喷流与地下海洋。

### 验收标准

- 核心对象外观与参数卡一致；未知表面和程序形状不标作实测。
- 表面、内部剖面、观测证据和内部结构推断分开，至少一个代表有可操作解释。

边界：首版采用代表性近景、剖面或说明；不要求全表面高精度地形和流体求解。

## R05 · 空间物质、场与环境联系

当前：四类教学联系共 21 步已上线；待用户验收。

归属：M4.3 / M2.2；主题：E01、E13、E14、E15、E16。

前置：复用太阳活动、地球环境、尘埃和日球层演示。

### 原定必须内容

- 串联太阳活动→太阳风→地球磁层与极光，并增加木星环境对照。
- 串联彗星/碎屑→流星雨、尘埃→黄道光、卫星喷流→环物质。
- 把行星际磁场、电流片、光与粒子辐射、中性粒子列为明确解释层；完善日球层与奥尔特云边界差异。

### 验收标准

- 物质、场和可见现象分开显示；不可见环境采用可关闭的解释层并标注其含义。
- 三条主要联系可暂停、分步或重播；空间环境进度不更改观测日期。

边界：没有实时通量和天气数据时不提供当日实况或辐射预测；场线不是物质轨道。

## R06 · 运动关系与天象

当前：14 节运动课与三例事件已上线；误差与科学边界已记录，待用户验收。

归属：M4.1 / M4.2；主题：E17、E07、E08、E10。

前置：使用已验证对象；已有速度和周期比较继续复用。

### 原定必须内容

- 完成自转/公转、月相/季节、潮汐锁定、共振四组课程。
- 补共轨与准卫星案例，明确相对视角和实际绕日轨道。
- 验证至少一个日食、一个月食和一个卫星遮掩案例。

### 验收标准

- 课程有视角说明、暂停重播和来源；至少一个共轨案例可切换参照视角。
- 事件关键时刻有资料对照与偏差记录，地面可见性注明地点和时间。

边界：不凭动画速度冒充潮汐演化；空间几何对齐不能直接等同地面可见。

归属：M2.2 / M2.3 / M5.3；主题：E01、E02、E03、E04、E05、E06、E07、E08、E09、E10、E11、E12、E13、E14、E15、E16、E17、E20。

前置：每批新增时即接入共享目录；本批集中检查一致性，不另造独立演示孤岛。

### 原定必须内容

- 统一新增内容的全景、图层、标记、参数、知识说明与返回路径。
- 完成整体边界、地月、巨行星、小天体、太阳风与地球五条 3–5 步专题路线。

### 验收标准

## R08 · 真实星空与宇宙定位

当前：独立星表、32 个邻星样本与第六路线已上线；主全景星表背景标准差距 F01 未关闭。

归属：M2.1 / M5.1 / M5.2 / M5.3；主题：E18、E19。

前置：太阳系内部覆盖优先完成；星表技术核查可提前，交付排在此批。

### 原定必须内容

- 导入质量筛选后的恒星目录子集，按星位、星等绘制并查询来源。
- 建立至少 20 个有可信距离的邻近恒星/系统样本。
- 衔接银河系与邻近星系尺度，完成第六条“太阳系在宇宙中的位置”专题路线。

### 验收标准

- 星位和坐标转换经独立样本核对；二维天球背景与可信三维样本分开。
- 六条专题路线全部走通，银河模型不冒充全星表实测重建。

边界：邻星与星系是宇宙背景，不计作太阳系内部新成员；无可靠距离不伪造纵深。

## R09 · 科学、体验与版本总验收

当前：科学报告、异常恢复与参考环境检查已上线；资源预算、实机和用户总验收未完成。

归属：M0.1 / M0.2 / M0.3 / M6.1 / M6.2 / M6.3；主题：E01、E02、E03、E04、E05、E06、E07、E08、E09、E10、E11、E12、E13、E14、E15、E16、E17、E18、E19、E20。

前置：各批持续验证，最后统一核验；已有发布不自动等于用户验收。

### 原定必须内容

- 复核来源、版本、单位、坐标、时间、插值、案例及科学解释，更新物理验证报告。
- 检查加载失败恢复、连续切换、日期边界和冻结参考设备上的性能。
- 交付代码、数据、报告、说明、已知限制与发布记录，并完成用户验收。

### 验收标准

- 20 类主题和首版必补子项都有证据，六条专题路线可走通，无关键阻断。
- 参考桌面典型全景目标 ≥30 fps；20 次连续跨模块切换检查资源趋势，未达标先降载复测。

边界：完成的是约定的主要构成与代表体验，不是所有对象、地形和历史事件；工期在数据与资源核查后估算。

## 五项必补与后置范围

### S01 · 小天体形状与多体系统

层级：首版必补；状态：爱神星 PDS 形状、Patroclus–Menoetius 双体已上线；待用户验收。

范围：不规则形状、双小行星、小天体卫星；接触形状与绕转双体分别说明。

验收：至少一个有依据的不规则形状和一个双体/小天体卫星系统，可共用对象。

延期：全量精密形状、接触演化与碎石堆物理延期。

[来源 1](https://science.nasa.gov/solar-system/asteroids/facts/)

### S02 · 共轨与远缘群体分类

层级：首版必补；状态：Kamoʻoalewa 双参照系与远缘群体分类已上线；待用户验收。

范围：准卫星、共轨关系，以及经典/共振/散射/离散群体。

验收：一个共轨或准卫星案例可比较参照系；经典和共振成员各有代表，已有样本可复用。

延期：不要求重建每个共振族群和长期混沌演化。

[来源 1](https://science.nasa.gov/solar-system/kuiper-belt/facts/)、[来源 2](https://www.jpl.nasa.gov/news/small-asteroid-is-earths-constant-companion/)

### S03 · 太阳分层与活动类型

层级：首版必补；状态：太阳分层与活动区别、太阳—地球环境联系已上线；待用户验收。

范围：光球、色球、日冕、黑子、日珥与已有耀斑/CME 的区别。

验收：每层/类有说明和来源；一个分层视图与可选择的活动示例，不标称当日实况。

延期：实时太阳监测和完整磁流体计算延期。

[来源 1](https://science.nasa.gov/sun/facts/)

### S04 · 表面活动与内部结构

层级：首版必补；状态：土卫二喷流、内部剖示与 E 环补给联系示意已上线；未求解环粒子动力学，待用户验收。

范围：地质活动、喷流、内部海洋及物质向环系补给的代表性关系。

验收：至少一个代表有近景、剖面或原理解释；土卫二可作候选，观测与内部推断分开。

延期：所有天体内部结构、全球地形和连续地质演化延期。

[来源 1](https://science.nasa.gov/mission/cassini/science/enceladus/)

### S05 · 不可见的场与粒子环境

层级：首版必补；状态：行星际磁场、电流片、光、带电粒子、中性原子五类解释层已上线；待用户验收。

范围：行星际磁场、电流片、光与粒子辐射、中性粒子。

验收：每项有来源和视觉含义；场结构与粒子示意可分开开关，不要求逐粒子模拟。

延期：实时通量、精密辐射剂量和空间天气预报延期。

[来源 1](https://science.nasa.gov/learn/heat/resource/components-of-the-heliosphere/)、[来源 2](https://www.nasa.gov/image-article/heliospheric-current-sheet/)、[来源 3](https://science.nasa.gov/learn/basics-of-space-flight/chapter1-1/)
