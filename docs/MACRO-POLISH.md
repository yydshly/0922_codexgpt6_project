# 宏观场景阅读与操作优化

日期：2026-09-24。基于本地 `9a06dc7` 继续优化，待使用者验收后再推送。真实动态天体仍为 32 个，十体物理模型及历表数据未改动。

## 从实际页面发现的问题

1. 综合全景：12 行图层占满右栏首屏，区域含义与来源被挤到下方。已有区域入口和科学边界较完整，但阅读顺序不利于先认识整体。
2. 天体与轨道：纹理文字偏小，轨道标签接近其他天体，缺少明确指向；手动拖动后开关黄道面会重建场景并复位镜头。
3. 缩放与操作：勾选的局部图层在远景并不展开，却没有即时状态反馈；取景预设无选中反馈，窄窗口内图层与介绍争用有限空间。

## 已完成

- 顶部固定三种取景预设，右栏分为“认识这里”“图层”“来源”；默认展示区域介绍。
- 取景预设高亮根据当前区域与图层组合计算。自定义组合不错误高亮；再次点击预设可明确复位镜头，并退出行星高度增强。
- 图层状态区分已展开、靠近显示、已关闭和数据未就绪；随镜头距离更新。展开指按尺度启用，不保证对象位于当前视野内。
- 文字改为屏幕像素布局，带指向线；避让其他文字、球体投影及上下控制区。放不下时暂时隐藏，右栏保留相应说明；可一键隐藏全部场景标注。
- 黄道面、行星高度、图层及标注更新使用同一个场景实例，不再重建镜头。高程增强只作用于明确标注的行星区域。
- 增强点云辨识度，并为宏观小球添加球面明暗。补光属于展示效果，不代表观测亮度、真实额外光源或新的物理精度。
- 太阳风图层关闭时暂停按钮不可用，并明确显示原因。
- 测试收集范围限制为项目 `src` 和 `tests`，避免将临时浏览器缓存中的外部扩展测试误当成项目测试。

## 验证与限制

- 14 个测试文件、72 项检查通过；包含标注边界、文字间避让、天体遮挡避让、确定性和已有科学功能。
- 生产构建通过；主脚本体积提示仍存在，未将本轮称为性能拆包优化。
- 本地桌面 1440×1000、窄窗口 700×900 检查了介绍、图层、来源、预设、标注开关与布局；窄窗口页面宽度未溢出。
- 拖动后切换黄道面，画布实例和固定轨道标注位置保持；标注隐藏后可见标注数量为零；远景三个局部图层显示“靠近显示”。
- 截图与基本键盘检查不等于完整无障碍认证；未做屏幕阅读器、全部移动设备或长时间 GPU 性能测试。

## 使用者验收

1. 打开本地观测站 → 宏观结构，先看右栏“认识这里”。
2. 切“天体与轨道”，观察带指向线的名称与球面明暗；拖动镜头后开关黄道面，确认不跳回原视角。
3. 切“图层”，对比全景与靠近时的状态；关闭太阳风，确认播放控件说明正确。
4. 切“来源”，查看原始数据入口；隐藏标注，再显示；用 Esc 返回观测。
