# 六站巡视叙事与记录验证

日期：2026-09-30。范围：本地近地教学航区的叙事、阅读笔记、返回总结，以及单站训练报告到六站航程的入口。未提交或发布，不代表真实载人任务通过验证。

## 结果

- 运行相关单元测试：11 个文件、94 项通过；其中叙事 13 项、笔记 4 项。
- 浏览器操作检查：22 项通过、0 项失败，捕获到的运行异常和控制台错误为 0。完整结果见 [checks.json](checks.json)。
- 生产构建通过。沿用的大包体积提示仍存在，本次没有进行资源拆分优化。
- 浏览器使用本地生产预览、1440 × 1000 和 390 × 844 两种窗口；所有飞行通过界面正常操作完成，没有直接改写位置、推进剂、访问记录或完成状态。

## 检查覆盖

1. 默认自动起航，任务目的可直接看到；暂停中浏览岩体，不改变实际卫星目标与讲解。
2. 未抵达不能保存笔记。打开一个部件会停留，但不算读完全部介绍；全部打开仍需主动保存。
3. 保存的笔记属于实际到达的卫星，不属于正在预览的岩体；自动抵达级段仅增加访问数。
4. 不点击讲解也能按默认 12 秒继续巡游。各站显示对应观察问题；无实体的观景点不虚构部件检查。
5. 六站均实际抵达后返回，显示约 2,545 m 累计路程与约 33.24 kg 推进剂消耗（停留时长随操作略变）；两份主动保存的笔记不会被补成六份。
6. 返回卡片可以展开笔记，区分未到达、到达未保存与已保存。手动接管后暂停，文案不再宣称原自动航线仍在执行。
7. 可选启航故事明确跳过发射，进入新的单站练习；实际完成自动接近后才出现报告按钮。报告保留“未生成入轨记录”，并提供六站新航程入口。
8. 开始六站新航程后，之前的访问和笔记归零，推进剂按教学初态重新给定。没有把火箭、单站训练、六站探索描述成同一次连续实飞。

本次未重新跑完整的发射段，其动力学未修改；已有发射和故事验证见 [此前故事检查](../flight-story-2026-09-29/README.md)。单元测试另外覆盖危险优先于暂停、绕行不算访问、手动推进与转姿、重复保存、未知部件、接触状态及读取无物理副作用。
