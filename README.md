# ORBIT · 太阳系观测站

基于真实 NASA/JPL 历表的中文 3D 太阳系观测工具，已接入太阳、八大行星、二十一颗选定卫星（含月球、卡戎）及谷神星、冥王星两颗矮行星，主观测页共 32 个动态天体；宏观页额外接入哈雷、67P、灶神星、妊神星、鸟神星和阋神星，项目合计 38 个不同动态目标。这是本项目的观测范围，不代表太阳系的全部成员。真实观测与牛顿多体引力验证共用时间轴；行星卫星观测作为独立供数层扩展，经过验证的十体引力基准保持独立，为后续参数沙盒和游戏玩法提供物理基础。

建设过程与每轮优化的验收方法见 [建设记录](docs/PRODUCT-PROGRESS.md)。网页顶部的「建设记录」可直接查看已完成能力、本轮优化和提交入口。

新增 **阶段导览** 入口：按九批开关宏观补全、环系讲解、近地空间、太阳活动、尘埃流星与日球层详解，支持“前往本阶段”“只看这一批”和恢复全部阶段。四大巨行星家族内可控制环的显示与细环增强，查看参考尺度、来源及示意边界。详见 [阶段导览与环系验收](docs/STAGES-AND-RINGS.md)。第一至第九批及综合全景已发布；当前发布范围见下方「当前版本交付」。

第五批 **地球磁层与极光** 提供独立三维结构图：太阳风、弓形激波、磁层顶与磁尾、磁力线、两极极光可分别开关，支持立体 / 侧面 / 极光近景和真实地球观测入口。这是有 NASA 来源的原理示意，不对应主页日期，不是空间天气实况。详见 [空间环境来源与验收](docs/SPACE-ENVIRONMENT.md)。

第六批 **辐射带与等离子体层** 已实现：三类粒子区域可独立开关，支持剖示与完整形态，可与第五批组合观察。这是有来源的结构示意，不是实测辐射分布；第六批已提交发布。详见 [近地粒子区域来源与验收](docs/NEAR-EARTH-POPULATIONS.md)。

第七批 **太阳活动与物质抛射** 已发布：日冕、太阳风、耀斑与 CME 可独立开关，支持暂停、拖动进度与重播，并关联地球磁层及太阳近景。仅为原理演示，不是当日活动或抵达预报。详见 [太阳活动来源与验收](docs/SOLAR-ACTIVITY.md)。第七批已随 `f266de0` 部署成功：[部署记录](https://github.com/yydshly/0922_codexgpt6_project/actions/runs/35960350678)。

第八批 **行星际尘埃与流星** 已发布：分布与进入大气两个镜头，尘埃云、倾斜碎屑流、参考路径、大气与光迹可分层观察。默认暂停，提供侧视、拖动、重播和真实彗星关联入口。本批已随 `0b3d801` 部署成功。见 [来源、实现边界与验收](docs/DUST-AND-METEORS.md)。

第九批 **日球层与星际空间** 已在本地实现：六层可独立开关，支持剖示、完整轮廓、侧视和粒子演示进度，关联奥尔特云及太阳活动。轮廓是科学结构示意，不是实测球壳或引力边界。第九批已随综合全景发布。见 [来源、实现与验收](docs/HELIOSPHERE-EXPLORER.md)。

**区域成员持续跟随（已发布）：** 六个代表成员集中进入全景侧栏，定位后随日期运行，支持前后 30 天、参数与所属区域，见 [说明与验收](docs/PANORAMA-MEMBERS.md)。

**全景地球云层与大气（已发布）：** 将已有静态云图和薄层大气接入同一全景，支持独立开关与来源说明，见 [实现与验收](docs/PANORAMA-EARTH.md)。

## GitHub Pages 部署

在线体验：[太阳系观测站](https://yydshly.github.io/0922_codexgpt6_project/)。仓库的 [自动部署工作流](.github/workflows/deploy-pages.yml) 会在每次推送 `main` 时运行检查、构建并发布；发布来源已设置为 GitHub Actions。

部署构建会给页面设置仓库子路径，历表、纹理、报告和物理计算 Worker 都从该路径加载；日常本地开发仍使用根路径。
## 启动

需要 Node.js 20.19+ 或 22.12+，以及支持 WebGL2 的现代桌面浏览器。

```sh
npm install
npm run dev
```

打开终端显示的本地地址，默认是 `http://127.0.0.1:5173`。全部天体数据、贴图及验证报告已经包含在项目中，无须先执行数据采集。首次显示会按需读取对应月份的数据包。

```sh
npm run build         # 类型检查与生产构建
npm run preview       # 本地预览生产构建
npm test              # 科学数据、物理核心及调度回归检查
npm run validate:physics  # 重新生成 30 天、1 年、10 年的物理验证报告
```

## 观测与交互

**产品方向规划：** 顶部「扩展路线 → 产品方向」新增观测学习、科幻探索、仙侠星域、时空穿越与星球掌控五个候选分支，可切换查看玩法循环、首个体验、所需能力与规则边界。包括星球控制的物理干预／治理改造／神通创造三层，和“一个角色，一次地月探索”的小型试玩建议。这里只交付规划说明，未实现角色、御剑、传送、星球操控或游戏存档；真实观测能力与现有工程顺序保持独立。下载的实施规划同步包含产品方向章节。

顶部 **扩展路线** 与全景「已接入天体」面板中的路线入口，关联当前能力、六个规划阶段、候选对象、前置依赖与验收条件。路线页可返回当前天体目录、查看已有物理验证报告，并下载详细实施规划。已完成和规划中的范围分别标注；打开路线不会重置观测日期或实验。天王星五颗主要卫星及土星新增五颗卫星现已接入，全景计数与家族入口从共同目录派生；P0 的完整供数与实验接口仍需完善。谷神星、冥王星与卡戎已进入动态观测；之后继续扩展其他矮行星、小天体，按顺序推进参数沙盒、碰撞合并和飞船任务。完整工程计划见 [扩展实施路线](docs/ROADMAP.md)。

首页默认进入真实太阳系全景；点击右上角「宏观结构」打开三维总览，认识行星区域、小行星主带、柯伊伯带、散射盘、日球层与推测中的奥尔特云；再切换「天体与物质」了解卫星、矮行星、彗星等成员，或切换「恒星系统与其他星系」理解太阳系在银河系中的位置。之后进入行星观测。宏观视图使用对数距离映射；宏观结构中的太阳与八大行星位置由十体 JPL 历表驱动；主观测场景另外显示谷神星、冥王星与卡戎的 JPL 中心历表；宏观图同步谷神星与冥王星位置，卡戎可在全景中靠近冥王星双体展开。其余点云和边界是有来源的区域形态示意，不是逐体实测位置。点击场景中的「宏观结构」可随时返回。设计与科学边界见 [太阳系宏观结构](docs/MACRO-STRUCTURE.md)。

进入行星观测后，太阳系全景将已接入的 32 个动态天体汇总在同一个三维场景中，并使用同一日期与时间轴。十九颗扩展卫星在真实观测的全景与内外行星区域中，按各自相对母星的状态叠加母星中心的位置与速度；单体近景收起其他系统，以便专注观察球体。全景中的小卫星可通过名称标记寻找，也可进入行星家族近看。点击天体目录切换观察目标，拖动环绕、滚轮接近；侧向太阳光使昼夜交界和球面曲率更清楚。土星展示主环范围与纹理示意，其他三颗巨行星也提供有来源的代表环段；细环可关闭宽度增强。太阳额外呈现动态颗粒、日冕和日珥，其形态、颜色与变化速度是说明性视觉效果，不是实时太阳活动观测。

地球展示海洋反光、陆地、独立云层、云影与大气边缘。选择地球或地月系统后，可分别开关云层与大气，并通过「观察地球大气」进入近景。静态云图绘制在 `1.002 R`，大气散射示意绘制在 `1.018 R`，其中 `R` 是地球球面半径；这两个数值是图层绘制参数，不代表精确云高或大气外边界。云影是简化光照效果，云层不会提供实时气象，大气也不是精密辐射输运模型。

场景左下的 **观察尺度** 将全景、行星区域、行星系统和单体近景串成逐级路径。先在全景选择一个天体，再进入所属区域、已接入的卫星系统或近景；没有已接入卫星系统的天体可直接进入近景。点击任一已走过的层级即可返回。导航卡片持续标明当前展示比例和大致轨道尺度；地月层显示所选时刻的地月中心距。切换区域会保留已选的真实比例。真实比例远景只显示主要行星名称，小卫星仍在对应位置但需进入所属系统观察。

区域视图默认采用 **空间观测**：太阳、行星与月球使用参考自转姿态和来自真实太阳方向的照明。全景的日心方向与轨道倾角保留，径向距离通过单调函数压缩，球体使用固定的展示半径；卫星家族的距离与小球体尺寸也会作展示增强。靠近时球体会自然变大，不能由全景量取真实距离或半径比。轨迹可按需开关。**真实比例**可随时恢复同一日期的真实距离和半径。

**地月空间观测**严格采用地球与月球的真实半径比，以地球半径为 1，将平均地月间距显示为 6.5；实际距离的变化、方向与运动仍来自历表。相机对准两球整体，随系统中心平移，不抵消月球绕行。界面另列真实距离。压缩空间不显示 km/AU 标尺。

**全景立体观察**：全景、内外行星区域的空间观测默认使用低角度三维透视，可切换为俯视轨道。自动环绕是缓慢的镜头往复运动，独立于时间轴；拖动或缩放会停止，可再次打开。系统设置“减少动态效果”时默认关闭。空间模式加入冷色展示补光、柔和太阳光晕、轨道远近亮度和带区颗粒透视，真实太阳方向的主光保持不变；这些效果用于看清球面与前后关系，不代表额外天体光源，也不提高物理精度。真实比例和单体近景关闭这层补光与光晕。背景银河和星点是程序化示意，非真实星表；带区在放大的球面附近作视觉淡化，不影响任何天体状态。

**大小对比**：岩质天体、行星与月球、包含太阳三种陈列，所有天体保持同一个长度比例，按真实平均半径比较。陈列位置和统一照明为对比服务，不表示当前轨道位置。

**行星卫星**提供木星（木卫一、二、三、四）、土星（土卫一、二、三、四、五、六、八）、火星（火卫一、二）、天王星（天卫五、一、二、三、四）、海王星（海卫一）的系统全景和卫星近景；月球在地月系统中观察。所有位置使用同一时刻的几何状态，卫星以所属行星中心为参照，行星又随太阳系历表运行。点击「观看公转」会设置适合该系统的时间倍率；默认 1× 的真实时间里，公转不容易在数秒内察觉。

本次补入土卫一、三、四、五、八：可观察土卫一的快速公转，与运行较慢、轨道更远且倾斜的土卫八比较。土卫一的大撞击坑、土卫八的明暗两面等外观特征采用程序化示意，不代表精确地形或表面经度。参数与独立验证见 [土星卫星来源](docs/SATURN-SOURCES.md)。

卫星系统的空间观测压缩距离并增强小卫星尺寸，显示的运动方向和快慢仍由真实历表决定；切换真实比例恢复统一长度比例。拖动环绕、滚轮靠近，点选卫星进入近景，再返回系统全景比较不同轨道。轨道线是瞬时状态推得的二体参考线，不代表完整的未来轨迹。卫星外观是说明性三维重建，非实时影像；未模拟卫星食和完整表面姿态。

**成员汇总、图鉴与观察导览**：「已接入天体」入口显示 32 个动态成员的加载进度，可进入地球、火星、木星、土星、天王星和海王星家族，也可由「更多图鉴」查看其他成员；侧栏另有图鉴入口。图鉴共收录 27 个有 NASA 来源的扩展对象，其中十九颗行星卫星、谷神星、冥王星与卡戎已接入真实动态历表。妊神星、鸟神星、阋神星、灶神星和 67P 的真实动态位置现在由宏观页提供；图鉴中的近景仍是外观示意。程序化预览不是照片重建或真实位置，非球形天体另列尺寸与形状说明。详细来源见 [图鉴来源](docs/ATLAS-SOURCES.md)。观察导览可直接切换到地球、太阳、土星、地月、加速的内行星，以及土星七卫星的公转场景。

小行星主带和柯伊伯带使用随机点标示区域范围，不是观测统计分布。点数不代表实际天体数量，每个点也没有逐体真实轨道；它们不计入 32 个动态成员。主带示意选取约 2.2—3.2 AU 的主体区域，柯伊伯带示意选取约 30—50 AU，不表示完整小天体种群的边界。点击带区的成员入口可以查看相关图鉴资料。

- **选择与观察：** 左侧选择天体，右侧查看来源、质量、半径、自转/公转周期、轴倾以及瞬时相对状态。可选择全景、内行星、外行星、地月系统，或点击「跟随」进入选中天体近景。鼠标拖动旋转，滚轮缩放。
- **比例切换：** 区域默认空间观测，可一键改为真实比例。单体近景保持真实半径并独立取景；准确比较天体大小请用大小对比。背景恒星与带区是结构示意。
- **图层：** 工具栏切换轨迹、黄道参考平面、速度箭头、小行星带/柯伊伯带及距离标尺。瞬时二体参考轨道与已经运行的轨迹有不同标示；参考轨道不是覆盖数十年的真实历表。
- **运行知识：** 场景右上角和天体详情中的「运行知识」会随当前选中的太阳、行星或卫星变化，解释自转、公转、母星关系及轨迹图层。细线为当前状态估计的参考轨道，亮线为已播放路径；卫星视图不显示已播放路径。来源与模型边界在知识面板内标明。
- **数据与实现：** 场景右上角可查看数据从 NASA/JPL 来源、离线整理、按月加载、插值与物理推演，直到三维呈现的完整路径，并可打开版本清单和[详细说明](docs/DATA-PIPELINE.md)。
- **时间：** 底部显示北京时间（UTC+8），支持带秒的日期输入、拖动时间轴、返回现在、暂停、重置及 1 / 3,600 / 21,600 / 86,400 / 8,640,000 倍时间。空格播放/暂停，Esc 关闭指南或报告。输入日期后按 Enter 或离开输入框应用。
- **真实太阳系：** 使用权威几何状态历表进行插值。加载或失败时有明确状态，不用虚构轨道代替未加载的数据。
- **物理验证：** 从当前时刻的真实状态初始化，使用固定 300 秒步长推进。首次进入物理验证时，若原先为 1 倍速，会自动切到 1 小时/秒以便观察；仍可手动改回 1 倍速，此时需积累 5 分钟才完成一个物理步。返回真实太阳系后恢复原倍率。画面和时钟采用已完成物理状态，高倍率会显示实际推进速率。计算赶不上时降低实际倍率，避免无限积压。日期跳转重新初始化模型，「重置」返回这次实验的起点。
- **报告：** 物理验证中的「验证报告」显示独立基准实验的 30 天/1 年逐日位置与速度差异，可切换天体；它不是当前交互实验的实时误差。十年稳定性和收敛结果可展开查看。

主要适配桌面浏览器；900 像素以下的窄窗口通过顶部「天体目录」「天体参数」展开侧面板，场景与时间控制保持完整。所有运行所需数据、贴图和字体回退均可本地使用，无需访问第三方服务。

## 数据与科学约定

| 项目 | 约定 |
|---|---|
| 数据来源 | 原十体及谷神星、冥王星、卡戎使用 NASA/JPL Horizons；十九颗扩展卫星使用 NASA/NAIF SPK 几何状态；NASA/JPL 物理参数、NAIF 引力常数 |
| 时段 | UTC 2026-01-01 00:00:00 至 2028-01-01 00:00:00，后者为终端检查点 |
| 界面时间 | 北京时间 UTC+8；因此边界显示为北京时间当日 08:00 |
| 科学坐标 | ECLIPJ2000 / J2000 黄道平面；原十体以 SSB 为原点，新增卫星先相对母星中心取样，再合成全景坐标 |
| 计算时间 | J2000 后的 TDB 秒，UTC → TAI → TT → TDB；未来闰秒按当前已知 37 秒处理 |
| 单位 | km、km/s；引力参数 GM 使用 km³/s²，渲染另行缩放 |
| 光行时 | 不作光行时和恒星光行差修正，显示同一坐标时刻的几何状态 |
| 插值 | 原十体每 6 小时、新增卫星每 30 分钟—1 天采样；三次 Hermite 插值，速度取同一多项式的解析导数 |
| 展示目标 | 太阳、八大行星、月球、十九颗扩展卫星、谷神星、冥王星与卡戎的天体中心，共 32 个动态成员 |
| 推演目标 | 太阳和地月分别处理；其余行星系统采用对应系统质心及系统 GM |
| 相对状态 | 卫星对所属行星中心、行星对太阳、太阳对 SSB；所有误差比较使用一致目标 |

`public/data/manifest.json` 保存原十体数据版本、时间范围、查询参数、目标编号、文件校验值和来源。月度文件可以独立加载，`data-sources/` 保存原始资料与缓存。可使用仅依赖 Python 标准库的采集脚本复现：

```sh
python scripts/prepare-data.py
python scripts/prepare-data-assets.py
npm run validate:physics
```

已有原始缓存时可重建数据，无须联系人或网络。缓存缺失时，JPL 在线采集需提供真实维护者联系方式：`python scripts/prepare-data.py --contact "你的真实邮箱或联系页 URL"`，或设置 `SOLAR_DATA_CONTACT` 环境变量。采样验证不通过时应增加采样密度后重新生成，不应跳过精度门槛。

物理模型采用双精度牛顿点质量多体引力和 Velocity Verlet，太阳参与运动。自转轴与表面经度使用 IAU 参考近似，未建模完整章动、岁差和月球物理天平动。模型省略相对论、非球形引力及部分小天体；展示和验证均不属于航天导航级产品。

十九颗扩展卫星仅进入真实历表观测，不进入当前十体物理验证。木、土、火、天王星、海王星的物理推演仍采用系统质心及系统总 GM；若同时另加这些卫星的质量会重复计算，因此切入物理验证会退出扩展卫星视图。后续展开某个行星系统时，须一起替换中心、质量和验证基准。

新增卫星以 NASA/NAIF 的 `jup365`、`sat441`、`nep098`、`mar099s`、`ura184` SPK 内核为依据，使用 SPICE 计算各自相对行星中心的几何位置和速度，再按主星与月份拆成 120 个本地包，合计约 27.68 MB。`public/data/satellites/manifest.json` 记录版本、来源和文件校验值，`data-sources/satellites/` 保存对应时间范围的内核片段和下载溯源。它们与原十体使用相同的 ECLIPJ2000 坐标轴、TDB 时间和 UTC 覆盖边界；原点为各自的主星中心。可用 `python scripts/prepare-satellites.py` 重建，脚本依赖 `numpy`、`jplephem` 和 `spiceypy`；已有内核片段时无需联网。

## 验证结果与阅读方法

本次数据生成包含 **49,657 个未参与插值的独立中点**，最大位置插值差异 **0.07837 km（约 78 米）**，通过 1 km 门槛。这是插值与源历表的差异，不是源历表的观测不确定度。详细结果见 `public/data/interpolation-report.json` 与 `public/data/data-quality.md`。

新增卫星单独通过 **237,575 个独立 SPK 中点**验证，最大位置插值差异 **0.930193 km**。采样间距随天体运动速度自适应缩短至 30 分钟—1 天。逐卫星结果见 `public/data/satellites/interpolation-report.json`。这是相对原始 SPK 的插值差异，不表示卫星位置本身具有同等观测精度，也不属于牛顿十体模型的误差报告。

物理验证以 **2026-09-22 00:00 UTC** 为起点：

- **总差异：** 正式 300 秒推演与 JPL 历表之差。
- **数值积分误差估计：** 同一十体模型的 300 秒与 37.5 秒推演之差。
- **模型差异估计：** 37.5 秒参考与 JPL 历表之差，另以 75 秒与 37.5 秒的差异评估参考仍存在的积分余量。这些是向量差的大小，不能当作标量直接相加减。
- **步长收敛：** 300/150/75 秒实验的误差改善比约 **3.99997**，与二阶方法预期一致。
- **十年稳定性：** 每日及末端采样的最大相对能量变化约 **3.38×10⁻¹¹**，最大相对角动量变化约 **5.27×10⁻¹⁴**。十年结果只评估同一孤立模型的数值稳定性，不代表拥有十年真实历表覆盖。

可读版报告见 [科学验证报告](docs/VALIDATION.md)，完整数据见 `public/data/validation-report.json`。例如，一年内水星相对历表的最大总位置差异约 147 km，而数值积分位置差异估计约 30 km；它们反映的是不同问题。测试和验收门槛随脚本一并保留，可复现而不是只展示截图。

## 代码结构与扩展接口

- `src/data/`：天体目录、物理参数与 UTC/TDB 时间转换。
- `src/ephemeris/`：历表清单、月份缓存、同步插值与异步加载。
- `src/physics/`：独立可测试的 `NBodySystem`，以及提供初始化、推进、重置、快照的 Web Worker。
- `src/hooks/`：播放、日期跳转、并发请求失效、时间预算与边界调度。
- `src/components/`：Three.js 场景与验证报告；`spatial-layout.ts` 只处理非物理展示映射，科学数据不经过该模块；`src/App.tsx` 负责观测界面。

原十体科学状态使用 `StateFrame`：TDB 时间，加上按 `BODY_IDS` 排列的双精度位置与速度数组。原十体真实历表和物理推演都输出这一接口；物理核心不依赖 React 或 Three.js。新增卫星使用独立的父星相对状态接口，`useOverviewSatellites` 汇总五个行星系统供同一场景渲染，不改变 `BODY_IDS` 或十体积分器。谷神星、冥王星与卡戎复用独立的按月供数接口，详见 [扩展天体数据说明](docs/DWARF-DATA.md)。后续可在明确实验状态边界后接入参数修改/天体增删，再增加碰撞合并、飞船推力和任务规则。本版尚不提供这些玩法。
