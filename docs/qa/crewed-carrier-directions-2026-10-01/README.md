# 载人任务：共享火箭与方向显示修正

2026-10-01，本地预览 `http://127.0.0.1:4180/`。本轮针对火箭粗糙、倒着飞的疑问；没有提交或发布到 GitHub。

## 已确认的问题和处理

- 新载人流程曾用两个简化圆柱和方形塔架替代既有美术。现复用 `createLaunchVehicle` 的涂装、管路、紧固件、级间与喷管，复用 `createBaseScene` 的发射台、塔架、平台和场地。适配两级采用同一轴变换，二级喷管嵌入级间段，发动机出口与 8.1 m 发射台匹配。外形是原创教学设计。
- 青色速度箭头曾在地心与平台参照之间切换。现始终显示地心惯性速度，平台相对速度和共转空气相对速度另有名称、颜色和箭头；船头、热盾也有具名标记。不存在的力或相对速度不画对应箭头。
- 船体单独平滑导致外形姿态落后于真实受力状态。现直接显示同一物理姿态，镜头继续平滑。服务舱分离时立即清除已结束的主推力并建立热盾指向；理想再入热盾指向更新到同一时刻的 p/v；末段着陆沿地表法线朝上，匹配软着陆发动机。
- 高倍率曾压缩离轨转姿。现转姿与制转为 1×，姿态稳定后点火最多 10×；0.1 秒物理步长、推进剂和轨迹求解保留。

在轨朝平台观察时，船头不必等于轨道速度方向。离轨反推制动、再入热盾领先属于正确方向，不能统一改为船头朝速度。说明来源：[NASA 的减速介绍](https://www.nasa.gov/general/how-do-spacecraft-slow-down-we-asked-a-nasa-technologist-episode-22/)、[ESA 的返回说明](https://www.esa.int/Science_Exploration/Human_and_Robotic_Exploration/The_return_home)。网页右侧同步显示分阶段说明与夹角读数。

浏览器刷新本地预览后进入「载人任务 · 地球出发」，检查地面模型；完整演示到「离轨点火」暂停，右侧「船头、运动与受力方向」应显示推力接近逆速度。继续到再入，热盾与空气相对速度应接近 0°。外部跟随可拖动观察；切换镜头不改变物理状态。

这些是原创教学模型的自动/本地浏览器验证，尚需用户体验验收；没有验证真实火箭工程规格、所有显卡帧率或航天导航精度。
