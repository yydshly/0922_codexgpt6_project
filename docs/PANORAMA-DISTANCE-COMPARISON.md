# 第二批 · 尺度与距离理解

本轮解决“球体可见，但空间究竟有多空、全景缩了多少”的理解问题。新增一个目录入口，不增加动态天体、历表包或物理模型。38 个目标和九个内容阶段保持不变；全景目录增加为 17 项。

## 入口与使用

综合全景 → 内容目录 → 尺度与距离 → 打开尺度与距离比较。

1. 先看默认的地月组合：圆形为球体截面，直径与中心距共用线性尺度。
2. 切换日地、日海王星、地火，或任选太阳 / 八大行星 / 月球中的两个不同对象；可交换起点与终点。小球没有最小像素限制，虚线只提示中心。
3. 阅读中心距 km / AU 及相当于起点天体多少个参考直径。两球转到同一条横线用于量距，不表示实际方位、轨道或同一直线排列。
4. 向下看八大行星的日心距离对照：左列真实线性，右列复用全景对数映射；两列都以该快照中最远行星为右端。
5. 关闭回到原全景。改日期后重开，读取新的快照。后台原本播放则继续播放，比较窗口的数据保持固定。

在历表缺失、加载或错误时，侧栏入口不可用并说明原因；组件本身对缺失位置也提供文本降级，绝不以零或平均轨道距离冒充当日值。

## 数据从哪里来

- 现有 [本地清单](../public/data/manifest.json)：`horizons-2026-2027-v1`；2026—2027 年，SSB 原点、ECLIPJ2000、TDB 秒、km / km/s；几何位置，无光行时或恒星光行差修正。没有重新抓取或引入第三方即时报数。
- [JPL Horizons 手册](https://ssd.jpl.nasa.gov/horizons/manual.html)：几何向量与时间 / 坐标约定。
- 参考半径沿用 `catalog.ts` 的 [JPL 行星参数](https://ssd.jpl.nasa.gov/planets/phys_par.html)、[JPL 卫星参数](https://ssd.jpl.nasa.gov/sats/phys_par/)；太阳参考半径 695,700 km 与 [IAU 2015 B3 名义值](https://www.iau.org/static/resolutions/IAU2015_English.pdf)一致。

打开时复制科学状态数组与时间，防止播放推进或原数组复用改变比较快照。北京时间从快照自身 TDB 转换，不从正在推进的界面时钟读取。仅接受真实历表模式的科学状态。

## 如何处理与显示

中心距 `d = |pB − pA|`，三个坐标分量都参与；不使用两个日心半径之差。`AU = d / 149597870.7`；直径数量 `d / (2 × rA)`。这些是中心到中心几何距离，不是表面空隙、飞行路线或光行时修正后的视位置。

双体尺将半径与中心距离同乘一个因子；按完整包围范围与最大半径确定图内比例，圆无描边或最小半径。只用截面辅助量距，不模拟光照、纹理、环、大气或太阳日冕；已有三维大小比较继续用于本体外观和参考直径对照。

全景径向函数 `R(d) = 22 × log10(1 + d) / log10(100001)`，d 以 AU 计。对照图分别使用 `d / dMax` 与 `R(d) / R(dMax)`；这是归一化径向对照，不是相机透视下的像素比，也不涵盖高度增强、局部卫星展示缩放。恢复制图距离不会把实际轨道的倾角变大，或把薄盘变成球状分布。

页面同时说明综合全景、大小比较、双体尺和家族近景的适用范围。远缘区域边界存在不确定性，不混入精确天体中心距列表。

## 验证

37 个测试文件、157 项检查通过；新增五项包括三维解析距离、平移 / 旋转不变性、方向相反但日心距离相同的反例、单位换算、所有 90 个不同对象组合的共同尺寸比例和完整取景、压缩比例及缺失值处理。

本地浏览器通过：
- 默认地月、日海王星、地火组合与交换；两列八大行星；17 个目录入口。
- 极小天体不放大；相同对象不可选择；AU 保留足够有效位数。
- 开关与 Escape 仅关闭比较窗口，恢复按钮焦点，不改变原镜头、图层、日期或画布。
- 改日期后重开会更新距离；播放时快照固定，主时钟仍推进。
- 键盘焦点在窗口内循环，滚动时关闭按钮保持可见；缺失数据独立渲染验证不产生虚假数值或图表。
- 桌面、700px 和 390px 无横向溢出，截图复核；无运行时异常。

生产构建通过，仍有原主包体积提示。功能先本地提交，用户验收后再推送。
