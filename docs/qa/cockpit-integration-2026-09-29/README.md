# 座舱、窗口与环境接入检查

日期：2026-09-29；本地更新，未提交发布。

## 修正的体验

原先两个小窗仅为外观装饰，“舷窗”隐藏整船并使用船头外的镜头位置。本轮增加了真正开口的上部船壳、前窗及侧窗、驾驶座、结构窗框和三维仪表。驾驶镜头位于同一模型内，飞船模型仍参与渲染；机外可以看到对应的窗户与舱内结构。

- 「座舱驾驶」观察当前练习场，拖动环顾；「回正视线」恢复前向观察。
- 键盘和右侧按钮保持原有推进、反推、姿态和辅助减速控制。
- 舱内屏幕和中文读数读取同一个飞行状态；目标方向基于实际相对位置及船体姿态，不是固定文字。
- 主视线、船头方向、目标框具有不同含义。转动头部不修改飞行方向；松开推进仍会滑行。
- 窗框、玻璃与仪表都有实际三维位置。仪表缩小并前移，以保留环境视野。

## 验证方法

1. TypeScript、文档同步检查与生产构建。
2. 局部飞行核心 7 项回归；增加 3 项船体几何检查：平移及三个不同姿态下，从驾驶眼位朝前的射线穿过前窗，未被不透明船壳堵住。
3. 隔离 Chrome 加载本地生产页面：机外／座舱切换、环顾与回正、驾驶转向使目标移动、导航对准、惯性和燃料、暂停、环境切换、小屏显示与返回焦点。详见 [本次检查记录](checks.json)。
