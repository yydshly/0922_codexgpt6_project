# 连续探索：到站观察检查

本批于 2026-09-29 开始，2026-09-30 完成。本地生产预览：`http://127.0.0.1:4180/`。未提交或发布。

## 本次改变

- 点选地点只浏览介绍，明确点击「自动前往」才改道，浏览不会退出自动驾驶。
- 到站恢复 1× 时间并停留 12 秒，避免原来 4× 巡航把 5 个模拟秒的观察压缩到约 1.25 秒。
- 六站各有观察取景，镜头模式切换通过约 1.15 秒过渡，不移动飞船。
- 卫星、级段、平台和岩体提供三维部件标注。标注端点跟随模型变换，文字自动避开其他部件文字。
- 点选部件会停留并显示用途；「继续下一站」沿剩余行程出发，位置、时间、推进剂与到访记录保留。
- 观察中可绕看和缩放，能关闭到站自动取景。暂停冻结环境和倒计时，停留则继续环境旋转和航程时钟。

操作见 [连续探索说明](../../CONTINUOUS-EXPLORATION.md)。

## 验证结果

- 飞行模块回归：8 个文件，63 项通过。包含动力学、自动驾驶、任务与故事、飞船模型、完整巡游、预览和航线分离、停留与继续、时间倍率和镜头过渡。
- 实际页面检查：23 项通过，运行异常和控制台错误为 0，见 [checks.json](checks.json)。
- 通过页面操作跑完六站，并包含停留、暂停、浏览其他对象、切换镜头、关闭自动取景、手动继续、返回后驾驶。没有直接修改浏览器中的物理状态或跳转位置来制造到达。
- 本次完整航程截图显示累计约 2,545 m、剩余约 67.2 kg 推进剂；这是这一次操作产生的读数，不是任务固定结果。
- 桌面和 390 px 窄屏检查通过，部件文字没有相互重叠。截图已人工复核。
- 生产构建通过，保留既有主包大于 900 kB 的体积提示；源码差异空白检查通过。
