# 现象与显示核验

2026-09-25 · 本地待验收；R09 总验收未完成，未发布。

## 本轮做了什么

`npm run validate:phenomena` 先重新执行月食、日食、木卫一遮掩的模型计算，再执行 66 项一致性检查。检查报告输入文件指纹、数值有限性、完整显示时窗、接触先后顺序、共用 TDB 时间差、分类，以及 10 个核心天体的线性自转系数与模型周期闭合。IMCCE 参考 PDF 使用已归档文件核对指纹。

| 案例 | 对照定义 | 模型减参考 |
| --- | --- | ---: |
| 2026-03-03 月全食 | 几何影轴最近时刻与 NASA 食甚时刻 | +37.81 秒 |
| 2026-08-12 日全食 | 几何影轴最近时刻与 NASA 食甚时刻 | +34.94 秒 |
| 2026-01-12 木卫一遮掩 | 掩始与 IMCCE OC.D 开始时刻 | +86.98 秒 |

差异统一在 TDB 中计算。NASA 历史目录的 UT 标签使用各自 Delta T 估计，不能直接等同于项目 UTC。三例没有共同的精度门槛；通过只代表本次一致性检查，不代表事件预报精度合格。月食本影食分差约 -0.0212；遮掩的消失过程时长差 -1.04 秒，不能当作整场遮掩时长。遮掩投影插值 480 个留出点最大差 0.220 km，与 87 秒模型差异分别报告。

## 朝向与外观范围

- 太阳、八大行星和月球：核对 `pck00011` 的线性子午线常数，按固定 J2000 极轴计算日期姿态；省略长期及周期极轴变化、完整天平动。周期闭合证明本模型行为一致，没有独立测量绝对姿态误差。
- 火星特意采用档案文字保留的 IAU 2009 历史系数，不标称为当前完整 IAU 模型。
- 29 个外观登记对象包含上述 10 体及 19 颗扩展卫星，不等于 29 个完整姿态模型，也不等于全体 53 个动态目标已全部外观还原。
- 卫星家族近景以朝向母星的姿态帮助辨认，不断言这些卫星全都真实同步自转。其他扩展目标各自采用已标注的近似。
- 地球云图、巨行星云带均为静态贴图，不是指定日期的天气；金星贴图随参考本体转动，没有模拟大气超旋转。太阳不是化学燃烧的火球，光球纹理不构成等离子体流动计算。

## 环境与结构

当前控制清单有 28 个现象部件；这个数字不是太阳系天体数量。核对太阳分层、土卫二内部两个来源登记的存在与教学限制，逐项阅读环境、区域和外观说明；没有做场强、密度、流量或内部层厚的观测拟合。日冕网格不是固定外边界，耀斑/CME 教学进度与历表时间分离，土卫二绘图层半径与负 Y 方向不代表实测厚度和当时南极。

带区与奥尔特云点云是分布示意；奥尔特云仍是模型推断。全景背景星点与 R08 固定时刻星表须分开理解。独立来源链接留在各模块，并在新入口汇总关键区别。
