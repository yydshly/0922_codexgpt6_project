## 使用路径

太阳系全景 → 地球出发 → 底部「03 检查点火」。使用组装界面中**已应用**的配置，尚未应用的草稿不参与飞行。

1. 执行发射前检查，核对整箭质量、一级加注量和推重比，以及计算是否就绪。
2. 开始 10 秒倒计时。服务连接臂收回；T−3 秒开始点火，在 2 秒内建立额定推力，此时支撑锁定，火箭不移动，但已经消耗推进剂。
3. T+0 时，只有推力大于当前重量且仍有推进剂才释放支撑。之后按净受力竖直上升；高度、速度、质量、推力、阻力与剩余推进剂来自同一份计算状态。
4. 可在倒计时或点火建压阶段取消发射。关机保留已消耗的推进剂，必须重置后重试。离台后可暂停观察，不能把取消按钮当成回到地面的操作。
5. 达到约 150 m 后冻结当前状态，保留瞬时推力和尾焰。可切换跟随火箭/地面机位、拖动旋转、缩放；这是本段复查点，未模拟发动机关机，也未判定入轨。
6. 重置恢复已应用配置的初始加注量（不是强制加满所有油箱），清除本次事件并重新检查。配置存档独立保留；本次试飞轨迹不持久化，结束试飞并返回或刷新会清除试飞状态。飞行存档留在 E6。

开始倒计时后锁定基地/组装切换，避免空中编辑质量。重置后可返回组装。切到后台或图形上下文丢失时自动暂停，回到页面或重建画面后须点击「继续模拟」，不会补算离开期间的墙钟时间。

## 模型与数据

| 项目 | 实现与边界 |
| --- | --- |
| 状态与单位 | 相对发射台升高 m、向上速度 m/s、一级推进剂 kg、任务时间 s；喷口初始地面高度 8.1 m。全景距离压缩不参与飞行 |
| 参数入口 | `compileVehicle` 接收 E2 的已应用配置，统一两级干质量、两级推进剂、载荷和整流罩。E3 只消耗一级推进剂，不进行任何分离 |
| 引力 | WGS84 μ 和赤道半径，采用 μ/(R+8.1+h)² 球对称近似。地球自转、纬度重力差、非球形引力及侧向运动未纳入 E3 |
| 推力及耗油 | 一级海平面额定推力与比冲；质量流率为 F/(g₀Isp)，g₀=9.80665 m/s²；建压比例同时作用于推力和耗油。该短段不随气压调整比冲 |
| 阻力 | D=½ρCdAv\|v\|，方向反向于竖直速度；迎风面积按 4.3 m 整流罩截面计算，Cd=0.35 |
| 大气 | ρ=1.225 exp(−h/8500) kg/m³，教学指数近似；Cd、密度与标高均不是本发射场实测值。无风、无升力、无复杂可压缩流动 |
| 姿态 | 固定竖直辅助，未模拟姿态自由度或辅助转弯；不能把 E3 积分继续运行当作 E4/E5 |
| 数值 | 0.05 s 固定步长，释放后用 RK4 计算竖直位移/速度；推进剂耗尽处分段，质量不允许变负。倒计时与点火节点落在固定步点 |
| 时间 | Web Worker 独立推进，默认 1 倍；每轮最多 5 步，卡顿时降低实际推进速度，不能通过加大步长或跳跃画面追赶 |
| 表现 | 共享 E2 模型；连接臂、支撑、尾焰、烟羽由任务状态驱动。尾焰/烟羽和连接臂运动为教学表现，非流体或真实发射台机构仿真 |

原理来源核对于 2026-09-27：[NASA 火箭受力](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/four-rocket-forces/)、[NASA 推力方程](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/rocket-thrust-equation/)、[NASA 阻力方程](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/drag-equation/)。地球参数来源见[基地基准](LAUNCH-BASE.md)，载具教学设定见[组装记录](VEHICLE-ASSEMBLY.md)。这些来源支持方程原理，不代表 NASA 提供或验证了本项目火箭规格。

## 本轮验证

- 新增 11 项动力学与状态检查，完整 89 个测试文件、384 项测试通过，生产构建通过（保留既有主包体积提示）。
- 解析对照：无重力/无阻力条件下，变质量燃烧速度与火箭方程一致；耗尽时精确切分，之后不再无燃料产生推力。
- 0.05 / 0.025 / 0.0125 s 在同一 T+6 s 比较，位置与速度差均小于 0.001 m、0.001 m/s，低于 E1 的 10 m、0.1 m/s 门槛；这是数值误差，不代表真实飞行预测精度。
- 相同总推进时间下，30 / 60 / 144 次每秒的回调产生相同物理状态与事件。暂停期间时间/燃料不变，模拟恢复不补算后台时间；长延迟单轮最多推进 0.25 s。
- 浏览器检查：未检查不能倒计时、倒计时取消、点火耗油且高度为零、点火取消后燃料保留、空中参数与镜头切换一致、图形中断后重建保留状态、150 m 终点冻结、事件不重复、重置恢复初始加注量、390 px 窄屏及返回观测时日期保持。未发现运行或着色器错误。

用户验收建议：以基准配置完成一次试飞，观察 T−3 至 T+0 的“点火但不移动”；另在点火建压时取消，确认燃料不会自动恢复。组装中改为一级 50% 加注并应用后再次试飞，对比上升速度。当前受力模型只用于离台教学，不提供真实发射操作建议。
