# 一级最终去向 · 消耗型参考路线

本轮随卫星说明与辅助线完整提交远端；上线以对应部署工作流为准。上一批演示收尾已发布为 `0ac37be`。固定范围为一级分离后继续运动、下降、空气参数、主画面跟随与回看，直到地表参考终点。未开发一级回收、材料烧蚀、解体或落区安全评估。

## 入口与操作

在「地球出发」进行手动飞行或全程演示。一级实际分离后，左侧出现 **一级去向 · 跟随与回看**。

- 一级过程已结束时，点击入口默认从分离时刻自动回放，避免停在静止终点却没有播放入口。提供暂停、继续、从分离处重播、5/20/50 倍速度和进度拖动；画面与参数同步。
- 一级仍在飞行时，点击入口跟随当前一级；参数区同步显示一级时刻、高度、速度、质量、密度、阻力、动压、环境温度及限定条件下的热流。
- 主任务时间推进时一级同步计算；主任务暂停或停在检查点时一级也停止推进，需要先从原操作区继续主任务。不会提前生成未来的结局。
- 回放或拖动滑条只浏览已经计算的记录，开始回放会暂停主任务，不回滚二级或卫星任务，也不提前计算未来。点击「跟随当前一级」回到实时记录；完成后的对应入口是「查看一级终点」。
- 刚分离只有一个记录点时禁用播放并说明原因；主任务暂停可从面板直接继续，停在检查点时明确提示返回当前步骤操作。自动演示的检查点等待也支持继续演示，不误判为无可用操作。
- 地表参考段完成后保留独立标时的历史结果，主任务可继续入轨、释放和卫星工作。点击「返回主任务画面」恢复主对象。

## 数据如何接上

一级初态直接读取本次执行分离命令后的实际位置、速度、方向与干质量。来自用户配置的发动机干质量会影响结果；不硬编码另一枚火箭的轨迹，不通过重放视频假装计算。

新增独立派生记录在原计算线程内推进，与主任务共用任务时间。它不施加任何新力给二级与卫星，不改写原 FlightState、旧事件或存档校验。恢复旧存档时从实际分离命令重算一级参考记录；未分离任务没有一级结果。正式存档仍保存原配置与动作记录，派生记录不冒充原版已经计算过的再入。

历史回放使用独立的画面时钟。记录点之间按位置与速度做三次 Hermite 插值，再按回放时刻换算到地球固定坐标；环境读数在已有采样间插值，不外推记录以外的状态。回放不会重新积分飞行、改变存档或把任务推进到未来；回放到已记录末端会自动停止。切换到后台时停止播放，避免返回时跳过过程。

## 模型与显示

- 分离后一级已燃尽，无推力。地球中心引力随半径变化，大气随地球共转，阻力与相对空气速度相反；无升力和侧风。
- 0.25 秒 RK4 固定步长，下降穿越 80 km 和 0 m 时细分最后一步。80 km 以上延用原指数教学大气，以下切换项目本地标准参考大气；两段切换属于模型约定，不是现实大气分界。
- 固定 Cd=0.7，参考半径 1.85 m，质量取本次一级干质量。它们是原项目的等效教学参数，未依据真实一级外形的风洞数据标定。没有翻滚、变形或面积变化计算。
- 热流沿用项目冷壁驻点估算，采用等效半径 1.85 m；仅在参考大气段、Mach ≥5 时显示。空白不等于零，更不等于没有受热。未求解材料表面温度。
- 80 km 以下用线框定位标记表示等效质点，标记形状与尺寸不代表箭体或碎片；该阈值只是避免把完整外形误解为存活预测，**不是断裂、解体或烧毁高度的判定**。橙色包络为热流假彩色，非喷火或等离子体求解。
- 0 m 为 WGS84 椭球参考面，网格不是真实地形。结果不能认定落海、陆地撞击位置、完整一级存活、全部烧毁或回收成功。
