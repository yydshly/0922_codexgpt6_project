## 可访问性与验收限制

- 已验证说明对话框获取焦点、Escape 关闭并返回入口，视角按钮带互斥选中语义。没有进行读屏软件实测、全站键盘遍历或 WCAG 合规认证。
- 390 px 新按钮和能力卡片没有横向溢出，但展开的辅助线面板仍会覆盖部分画布，需要收起或滚动。这是保留的手机布局限制；本阶段目标为电脑浏览器，不称为手机沉浸体验已完成。
- 一次额外兼容性探测使用开发运行时生成存档再交给浏览器，严格重算校验拒绝了结果差异，并保留原任务。换为同浏览器正常生成的存档后恢复通过。本轮没有放宽校验；跨 JavaScript 引擎或版本的存档迁移仍未保证。
- 截图说明视觉与操作结果；555 项自动检查提供状态与几何证据，两者均不等于用户验收或真实航天工程认证。

## 自动停留、下一步与主画面状态

原提示只有「即将自动继续」，没有讲解余量或下一步动作。新增的状态区位于播放按钮下方，主画面也采用同一状态文字；区分恢复、模型失败、完成、暂停、自动讲解及实际运行。自动动作与提示共用检查点安排，教学计时读取实际演示进度；暂停同时冻结它和任务时间，进入运行段立即清除上一检查点的余量。讲解秒数是播放时间，未用它冒充航行时长、日照等待或通信窗口预测。

## 计算异常后的停止与恢复

收尾代码复核发现，计算器异常终止后旧演示仍可能显示运行，恢复命令也仍发送给已停止的计算器。现统一冻结任务和讲解，主画面显示最后一帧，侧栏提供「选择存档恢复」「重新开始地面任务」。旧连接被关闭，排队中的旧消息不能覆盖新任务。冻结帧不能保存成完整任务；异常终止后的未保存进度无法继续，正常退出演示保留原任务的承诺不再用于此情形。

完整回归 116 文件 / 566 项通过，涵盖连接中断、发送失败、启动失败、迟到消息和重复关闭。第一轮浏览器检查中，属性形式的结果读取异常监听未收到注入事件，末尾用例超时；改为显式事件监听后，6 项连接检查与整组浏览器验收重新通过，没有把首次超时计为成功。

浏览器验证使用独立生产预览 `/0922_codexgpt6_project/`，未操作用户标签。测试包装器只在测试页向真正的计算线程注入未捕获异常，确认浏览器发出了错误事件；另触发发送异常、启动异常及结果读取异常事件。核对：

- 中断后删除旧演示操作与讲解倒计时，阶段按钮停用，最后时刻不推进；镜头仍能拖动。
- 冻结帧保存按钮禁用，已有存档恢复和文件导入仍可用。
- 无效文件被拒绝，不替换最后画面；随后有效 E02 浏览器存档正常重算恢复并暂停，可执行「下一段：动力离轨」，出现可用的结束与离轨指令。
- 恢复成功后再次导入无效文件，保留真正的当前会话，不误报计算崩溃。
- 发送失败后可通过有效文件导入恢复；再次启动失败后仍能重试。正常演示启动和退出均可用。
- 每次恢复、导入及新任务启动后，原浏览器存档逐字保持一致；无存档时明确解释文件导入或重新开始。
- 390 px 恢复面板不横向溢出；预期注入异常之外没有浏览器错误，测试结束恢复原存储并关闭测试标签。

这些结果验证的是异常恢复交互，不代表进程完全无响应时也能自动检测，亦不提供未保存任务的自动备份。没有更改物理模型、存档格式或重算校验。
