# 第九批：日球层与星际空间

## 补充原因与入口

第一批已有日球层轮廓，但单看轮廓容易误认为固体球壳、行星轨道或整个太阳系的终点。本批展开其内外环境，并把太阳活动与遥远引力成员关联起来。

- 阶段导览 → 09 → 前往本阶段 / 只看这一批。
- 宏观结构 → 空间区域 → 日球层 → 展开日球层与星际空间。
- 模块内可对照奥尔特云位置，或回看第七批太阳活动。

第九批控制独立详解模块；关闭它不会删除第一批已有的宏观轮廓。跳转奥尔特云启用第一批，跳转太阳活动启用第七批；这些明确的关联操作不等于“只看这一批”仍保持不变。单纯返回原观测则保留原日期与播放设置。

## 已实现与显示方式

六层分别控制内部太阳风、终止激波、日鞘、日球层顶、外部星际介质和进入的中性原子示例。三维镜头支持旋转、缩放、侧视、复位；默认暂停在一个示意时刻，并移去前方四分之一轮廓及对应日鞘点，帮助看清内部。缺口不是实际开口。

太阳采用已有静态纹理并放大。两层同心球面及线框只表述内外关系，紫色点提示日鞘区域，外部蓝灰点提示星际物质。金色点仅绘制终止激波内的太阳风；绿色点示意部分中性原子可以进入。点数、密度、颜色、位置、方向和速度不来自当前观测。隐藏图形不表示物理区域消失。

进度支持播放、暂停、拖动、回到开始和结束重播；20 个显示秒完成一轮，粒子按示意相位循环。它不推进主页观测日期，也不表示太阳风穿越时间。没有按比例绘制行星，不提供 AU 标尺；球面半径不能读取为实际日鞘厚度。

## 科学边界

- 真实日球层形状受太阳风、星际介质与磁场等影响，随方向与时间变化。概念球面没有拟合实测边界，没有展示日球尾或把上游激波作为确定外形。
- 没有求解磁流体、激波、湍流、电离、电荷交换或宇宙线输运；中性原子直线路径不代表无损通过比例，也不表示所有粒子都能进入。
- 太阳风动画到绘图边缘后循环，并非被终止激波当作墙挡住。日鞘点云保持静态，不演算外部绕流。
- 网格不是实体；点不是恒星。星际介质包含不同物质成分，本图没有按比例分配各成分。
- 不新增历表和事件数据，38 个不同动态目标与十体引力模型保持独立。不用于导航、边界位置或空间天气预报。

## 验收步骤

1. 进入第九阶段，确认默认暂停和剖示说明；完整轮廓与侧视可切换。
2. 逐层开关六层，检查标签同步、镜头和画布保持不变；再次开启沿用当前进度。
3. 播放、暂停、拖动至末尾、重播与回到开始；先暂停主页，再检查日期未被演示改变。
4. 关闭第九阶段应退出模块；其他阶段仍按其开关生效。
5. 对照奥尔特云应进入该区域，日球层介绍能重新进入详解；太阳活动关联进入第七批。
6. 桌面与 700px 窄窗口检查内容、焦点、来源与 Escape 退出。

自动检查用于展示逻辑，不是科学模型精度验证。本批先本地验收，再按用户授权推送。

## 本轮验证结果

23 个测试文件、105 项检查通过，覆盖内部太阳风的绘图范围、中性原子可进入示例、剖示象限、不同帧率的进度一致性和阶段隔离。这些检查验证教学绘图逻辑，不代表等离子体模型精度。类型检查与生产构建通过，保留已有主包体积提示。

桌面及 700px 窄窗口完成操作和截图复核：六层开关与标签、画布保持、完整 / 剖示、侧视、播放暂停、拖动、重播、日期保持、关闭阶段、奥尔特云定位、太阳活动关联、键盘焦点和 Escape 均通过，未发现运行时异常。简化了边界网格，并调整相邻标签间距。
