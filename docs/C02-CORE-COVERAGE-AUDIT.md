## 发现并修复

1. **规划与全景用了不同入口处理**：E01 点击后只进入行星区域，没有定位太阳。统一复用全景内容总表的入口动作；E01–E04 分别到太阳活动、地球、地月和土星家族。日期不变，保留返回规划。
2. **家族画面提示重叠**：两个绝对定位提示覆盖同一区域。合并到当前观察提示中，近景不再重复叠加类别说明。
3. **文案与显隐行为矛盾**：行星参数页仍说周边天体保留。改为实际行为：默认暂隐其他成员，可重新显示，返回全景恢复。
4. **说明没有跟随入口**：进入代表对象后将右栏滚动、焦点移至对应说明；主带入口显示区域说明，不停在通用推荐课程。

5. **地球本体近景露出裁切的月球**：单体定位沿用了家族的卫星可见性。单体近景默认暂隐卫星；显式显示上下文或进入家族后恢复，保留行星本体的环。
