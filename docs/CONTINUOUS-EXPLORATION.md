## 六站巡视的叙事（2026-09-30）

任务名「蓝色地平线：认识身边的太空」。你是观察员，也可接管驾驶。自动驾驶负责实际接近，随航讲解解释当前动作；讲解为本地状态提示，没有语音通话或真实地面通信。进入航区仍直接开始自动巡游，不强制先读简报。

| 章节 | 为什么去 | 到站看什么 |
| --- | --- | --- |
| 01 认识一艘飞行器 | 从单个卫星辨认功能结构 | 太阳能板、载荷镜头、天线 |
| 02 运动不等于工作 | 区分翻滚与主动运行 | 级段外壳、连接端、端部框架 |
| 03 当部件组成平台 | 比较组合结构与单个卫星 | 舱段、太阳能翼、设备主体 |
| 04 把目光移向地球 | 区分自然环境与导航标记 | 云层、大气边缘、空的观景航点 |
| 05 不规则的边界 | 理解轮廓、光影与接触边界的区别 | 岩体轮廓和表面；边界仍为保守球面 |
| 06 带着航迹返回 | 回看这次航程的代价与记录 | 累计路程、用时、耗油与主动保存的笔记 |

左下随航讲解由实际状态驱动：稳定原有速度 → 起转与制转 → 主推进 → 滑行 → RCS 减速 → 停稳确认 → 到站观察。暂停、接管、受阻与接触有各自提示；浏览别处的介绍不切换讲解目标。手动偏离路线后不再假定仍在执行自动任务。

右侧「任务安排与启航前序」可查看角色、路线与进入方式。启航前序包含发射观摩、驾驶交接、单站训练和报告，报告页新增「开始六站巡视（新航程）」。这是叙事衔接；火箭、单站训练、六站探索各自初始化，未伪装成连续的实际载人发射。

### 到达记录与阅读笔记

- 抵达并停稳才计入到达记录。绕行航点、切换镜头、浏览地点均不计入。
- 到站后打开所有部件介绍，可主动「保存本站阅读笔记」。无部件的观景点与出发点，到站后即可保存说明。系统只记录用户打开和保存了介绍，不判定已经理解或实际观察充分。
- 自动巡游不会自动保存笔记，也不会等待笔记才能前进。点击部件会停留；准备好后继续下一站。未保存笔记不等于未观察。
- 六个不同地点均有到达记录且返回出发航点后，显示往返回顾和阅读笔记数。只到过出发点不会显示六站完成；报告不生成照片、通信或维修成果。
- 笔记可在本次航程回看；没有永久存档，退出、进入前序或重新开始后清空。再访已保存站点不重复累计。

验证见 [叙事与记录检查](qa/exploration-narrative-2026-09-30/README.md)。

### 错过讲解、中途接管后怎样继续

主画面「暂停读讲解」会先保留眼前这段文字，再暂停运动与到站倒计时，并打开右侧阅读区。暂停状态不会把你正在读的原讲解替换掉。右侧「讲解回看」可选择这次航程实际出现过的阶段提示，显示当时的目标与时间；回看只选择文字，不把飞船移回过去，也不改当前目的地。

相同阶段不会每帧或每秒重复记录；最多保留最近 60 条提示，较早条目会移出列表。它是阶段文字记录，不是视频回放或完整飞行数据存档。历史文字里的倒计时、建议动作与下一站属于当时；当前状态仍看主画面。关闭阅读区不会自行开船，点击「结束阅读，继续运行」或画面上的「继续」才恢复，保留原来的驾驶方式和停留状态。发生接触或显示错误时不能通过阅读按钮恢复飞行。

手动接管会退出自动巡游，位置、速度、推进剂、访问记录与笔记都保留。「继续未完成巡视」按照实际到达记录，重新接近还没到过的地点，并以出发航点收尾。浏览过介绍不算到达；手动飞近但未由自动接近确认停稳的站也不会跳过。恢复会从当前状态重新规划航线，不补油、不瞬移，也不因为点了按钮而增加到达记录。

已到过所有站但又驶离了出发航点时，入口变为「返回出发航点」。提前访问过出发点、仍有其它站未完成时，余程仍以返回出发点结束。目的地太近、没有可用路线、燃料不足或已经接触时不会宣称恢复成功；失败也不会提前丢掉待去的站点。原「从当前位置巡游全部」保留，明确用于重新走全部六站。

每站离开前的介绍使用实际下一站，因此跳过已到达站后，文字与当前路线仍相符。验证见 [讲解回看与续航检查](qa/exploration-continuation-2026-09-30/README.md)。

### 航程怎样收尾与保存记录

飞船页右上角「航程回顾」在航行中和返航后均可打开；自动恢复隐藏的导航区，并暂停运动、燃料与到站倒计时。记录取自打开时的实际状态，阅读期间不刷新；收起面板不会自行恢复运行，点击「收起回顾，继续运行」或画面「继续」才恢复原有驾驶方式与停留状态。再次打开会重新读取当前记录，既不传送飞船，也不补油。

按「卫星 → 级段 → 平台 → 地球 → 岩体 → 返回」排列六站，分别列出实际抵达次数、首次抵达时刻、打开的部件介绍及主动保存的笔记。章节下可展开观察问题与模型说明；这段说明不被当作用户已完成观察的成果。报告还按真实抵达顺序列出每个区间的时间、路程与耗油，区间包含停留、绕行和手动驾驶，不能当作最短航线或纯自动驾驶效率。

只有到齐六站、并在其它站之后再次抵达出发航点，才记录完整往返。提前访问过出发点不会提前满足返航；未到齐的报告明确显示未完成。首次完成往返的时间、路程和剩余燃料成为固定节点，再次驶离或返航不会覆盖。回顾卡此后仍保留；报告同时区分这个节点与打开报告时的最新累计读数。

「下载文字记录」保存 UTF-8 的中文 Markdown，包含本章问题、模型说明和实际记录；「下载 JSON 数据」带有版本、单位、局部坐标、当前状态、抵达顺序和笔记。部分航程也可以下载，内容不补齐未完成站点。下载文件用于阅读和分析，**不能导入恢复飞行**；没有新增永久游戏存档，网页退出或重新进入会清空本次航程。下载文件由用户自行保存。

本批不追加航行目标或物理精度要求，完成的是当前六站教学体验的可回顾收尾。验证见 [航程回顾与全程巡视检查](qa/exploration-report-2026-10-01/README.md)。

### 离开前会发生什么

六站航程中点击「返回全景」、按 Esc、进入启航故事或独立练习，以及接触／显示错误后点击重开，都先打开切换提示。运动和到站倒计时暂停，原状态尚未清空；背景按钮和驾驶键暂时不能操作。提示说明将进入哪里、何种状态会重新初始化，并显示实际抵达数、笔记数、时间与耗油。

可以从提示中下载此时的中文文字记录或 JSON，不需要先退出再补记。浏览器下载列表是文件是否保存的确认处；网页不会把点击下载标称为已经写入磁盘，也没有新增可恢复飞行存档。确认结束以后，才执行相应的切换或重开，六站的内存记录清空。

取消或在提示内按 Esc，会恢复打开提示前的运行／暂停状态；原先主动停留的站仍停留，自动巡游的余程不变，速度、推进剂、到达、笔记与讲解保留。发生接触或显示错误时，取消只回到原来的停止状态，不允许通过取消继续飞行。取消按钮默认获得焦点，Tab／Shift+Tab 留在提示中。

此处理覆盖六站航程内的四类切换。直接刷新、关闭浏览器和故事／独立练习内部的退出，仍不会永久保留进度；故事发射场和单站驾驶页的按钮已统一改为「返回探索（新航程）」，不会让人误以为恢复了旧六站航程。故事期间底层全景暂停绘制和交互。

验证见 [离开、取消与故事衔接检查](qa/exploration-transitions-2026-10-01/README.md)。

## 从哪里开始

刷新本地页面后进入全景顶部「飞船环境 · 3D」，默认进入连续探索，并自动开始六站巡游。主窗口中的飞船实际移动，不再完成一次接近就结束体验。

右侧点选地点只浏览介绍，自动驾驶仍沿原航线运行；再点「自动前往」才从当前状态改道。界面分别显示正在浏览的地点与实际航行目标，浏览不会改变位置、速度、燃料或剩余行程。也可以按驾驶键或「接管，自由驾驶」取消后续巡游，自己飞行。抵达后可以继续去别处，返回出发点也不会补油。

| 地点 | 场景中的内容 | 能观察什么 |
| --- | --- | --- |
| 教学卫星 | 独立三维卫星 | 太阳能板、载荷、天线，以及接近时的尺度变化 |
| 废弃级段 | 缓慢翻滚的合成级段 | 外壳、连接端与独立旋转，不等于卫星本体；金色连接段不是发动机点火 |
| 中继平台 | 原创舱段、桁架和太阳能板 | 多部件结构与空间尺度；并非实际空间站复刻 |
| 地球观景点 | 无实体的导航航点 | 拖动镜头向下观察地球云层和大气边缘 |
| 岩体演练区 | 合成不规则岩体 | 轮廓、自转、明暗与保守接触范围；是刻意放入的训练对象 |
| 出发航点 | 无实体的导航航点 | 返回起点附近，比较累计时间、路程和推进剂，之后仍可继续飞行 |

## 怎样看出它在飞

- **机外跟随**：镜头随飞船平移，船身转向、喷流与邻近物体的相对移动都来自同一状态。
- **座舱驾驶**：观察点位于实体驾驶舱内，拖动环顾；不是用照片替代窗外场景。
- **航区总览**：镜头固定观察整个航区，浅色线框标出飞船当前位置，能看清飞船从一处向另一处移动。可继续拖动与缩放。
- **到站观察**：默认平滑靠近本站目标，卫星、级段、平台与岩体有跟随实际网格转动的部件标注；观景点面向地球，出发点回看飞船。它只改变镜头，飞船仍在原先停稳的位置。右侧可关闭自动取景，也可在抵达后手动「近看并停留观察」。
- 蓝线表示已飞过的轨迹（最多保留最近 2,000 个采样点）；浅绿色虚线是当前规划航线，标签与导航航点都是辅助显示，可以关闭。
- 右侧俯视导航使用同一批地点和实时飞船位置；三角形随船头朝向旋转，远离后自动扩大范围。高度单独显示，是相对起点的局部坐标，不是海拔。

## 自动巡航与自由驾驶

自动巡航沿用原来的有限推力、推进剂消耗和接触检测，近距巡航上限为 8 m/s。先处理已有速度，再转向、点火、滑行、减速；目标附近停稳 3 个模拟秒才记录为抵达。全程巡游在抵达后自动恢复 1×，留出 12 秒观察，然后再前往下一站。

点击部件标注、右侧部件名称或「近看并停留观察」，会无限期停留并保留后续行程。「继续下一站」从当前状态继续原来的路线；也可以另选目的地并明确改道。停留不等于暂停：级段与岩体仍会旋转，航程时钟仍推进，飞船保持停稳；部件文字只解释当前模型，并不宣称已执行通信、拍照或发电任务。

1× 与 4× 通过增加固定计算步改变运行速度，不瞬移，不更换场景。只有姿态稳定的直线推进与滑行使用所选倍率；转向、减速、手动驾驶和到站观察自动使用 1×。暂停会冻结运动、燃料、停稳计时和下一站等待；网页隐藏也会暂停，返回后手动继续。暂停中依然可转动观察镜头；镜头模式切换通过约 1.15 秒插值过渡，不修改飞船状态。

### 船头怎样转，航迹怎样变

2026-09-30 修正了起转、停转时的突变以及 4× 播放造成的快速旋转。转向现在有角速度和有限角加速度：成对喷口建立转动，反向喷气制止转动，姿态稳定后自动驾驶才点主发动机。手动只转船头时，原有平移速度保持；施加推进以后速度向量才逐渐改变。当前路线在观察站和绕行航点先减速，再转向下一段，这是一种近距教学策略，不代表所有航天器机动都要先停稳。

姿态辅助默认开启，松开转向键会主动阻尼转速，并消耗推进剂；失去燃料后无法开始或制止转动。界面显示实际转速和起转／制转状态，喷流根据当步控制力矩选择对应喷口组，未工作的喷口不亮。B 的平移减速由简化的多方向 RCS（反作用控制系统）承担，喷流与所需反向推力对应，不把它描述为主发动机任意方向刹车。

转速上限 8°/s、角加速度上限 4°/s²、每轴满控制量 0.012 kg/s 为本教学构型的设定，不是 NASA 航天器实测参数。模型用简化的等轴转动响应，没有完整转动惯量张量、陀螺耦合、质量分布变化、喷口最小脉冲或真实阀门约束。

原理依据：[NASA 对 Orion 姿态与平移控制的介绍](https://www.nasa.gov/missions/artemis/how-to-fly-nasas-orion-spacecraft/)。对应实现与验证见 [转向修正记录](qa/spacecraft-turning-2026-09-30/README.md)。

对于已知的静止障碍物，系统在保守球面外构建候选航点，寻找可通行的折线路线；绕行航点依然由飞船实际飞过去。它不是完整导航系统，不预测任意移动碎片，也不保证危险初态下能避开所有接触。燃料不足、未找到可用路线或已有危险速度时给出具体原因；接触或到达 1.5 km 航区边界后暂停并提供重新开始。

所有站点共享位置、速度、姿态、时间与推进剂。航行记录只在真正到达并停稳后写入；改选目的地、镜头变化和浏览说明不会添加到访记录。当前没有存档，退出、重新开始或进入独立练习会结束这次航程。

## 本次串联的范围

本批串联的是近地背景中的一个连续教学航区。物体位置均为合成设定，岩体不是近地小行星群的真实分布。地球使用项目已有本地纹理、云层和大气效果；没有改变其资料来源。

当前局部动力学仍无引力，物体中心固定，未接入真实轨道、地月转移或太阳系航行。没有把月球和小行星带缩放到几百米内，并声称真实飞到了那里。原来近地、月球附近、小天体的三个独立练习仍从右侧「航区与真实太空的区别」进入，启航故事也可从「任务安排与启航前序」进入；这些入口会结束当前探索，界面已说明。

后续如果要串联地球、月球和小天体的大跨度航程，需要先明确采用真实尺度还是标明压缩距离的演示空间，再接入相应的长途推进、航段交接和导航；不把这部分算作本批完成。
