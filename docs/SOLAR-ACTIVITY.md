# 第七批：太阳活动与物质抛射

2026-09-24 · 本地待验收。前六批已随 `e3f9ef1` 推送并部署成功，本批尚未推送。

## 新增行为

从「阶段导览 → 07 → 只看这一批」、宏观页「太阳活动」或太阳近景「太阳活动」进入独立演示。日冕、太阳风、耀斑、日冕物质抛射（CME）分别开关；演示支持暂停、拖动进度、回到开始与重播，开关不重建镜头。

默认暂停在一个示意时刻，避免自动爆发动画。播放时约 20 个显示秒走完一个过程；这个长度是界面参数，不是天文时间。进度只影响本模块，保留主页日期、倍率和播放状态。主页原本在播放时会继续推进。

「接着看地球磁层」启用第五阶段并进入其原理图；「进入太阳观测近景」转入真实观测中的太阳。关闭第七阶段会退出并隐藏本批入口。

不是每次活动都朝向地球。影响还取决于方向、速度与磁场条件，因此没有由一次演示推导极光、地磁暴或抵达日期。

## 绘制与数据边界

太阳采用项目内已有静态纹理。日冕用透明光晕概括；持续太阳风用向外运动的点表示；耀斑用表面亮斑及短暂射线表示；CME 用可扩展的透明云团、线与点表示等离子体和磁场结构。这些外观不是实时观测、真实光谱或精确磁场几何。

进度函数决定示意亮度、位移和云团尺度；并未执行磁重联、等离子体或辐射输运计算。云团的球状外形是概括，不表示真实 CME 都是球体。画面不按真实比例摆放地球。点数不表示粒子数量，射线不是精确的光线路径，纹理与活动区方位不对应当前太阳经纬度。

没有新增动态历表对象或当日事件目录。项目仍是主观测 32 + 宏观额外 6 = 38 个不同动态目标，十体引力实验保持独立。

## 验收步骤

1. 阶段导览进入第七批，确认默认暂停，以及“原理演示、非实时、尺度与速度调整”的标识。
2. 分别开关四层，核对亮斑、云团和对应名称同步隐藏；镜头保持当前位置。
3. 播放后暂停，再拖动进度；回到开始时 CME 尚未出发，结束后可重播。
4. 先暂停主页日期，往返本模块与播放演示，核对日期不被示意进度修改。
5. 关闭第七阶段应退出模块；重新开启可从阶段导览或宏观入口进入。
6. 点击地球磁层、太阳近景的关联入口，检查进入对应内容。
7. 检查桌面和 700px 窄窗口、键盘焦点、来源链接与退出。
