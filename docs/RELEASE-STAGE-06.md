# 第六批发布说明：辐射带与等离子体层

2026-09-24 · 功能提交 `7bb6ef6`，本次按用户要求推送。

## 用户现在能做什么

从「阶段导览 → 06 → 只看这一批」进入内辐射带、外辐射带、等离子体层的三维结构图，独立开关三层，切换完整形态与四分之一剖示。可以与第五批的磁层、太阳风、极光组合观察；关闭其中一批不影响另一批，全部关闭后回到原观测。

新增概念比较、NASA 来源和显示边界说明；重复进入某阶段会回到对应取景，切换图层保持镜头，往返保留主观测的日期与播放设置。

## 科学依据与本次范围

依据 NASA 的辐射带、等离子体层说明绘制示意体积和静态点云，来源与实现详见 [近地粒子区域](NEAR-EARTH-POPULATIONS.md)。不是当天实测、不是等比例边界，也没有粒子通量、辐射剂量或航天安全计算。切口仅为教学剖示；图中的空隙不是安全通道。

动态目标仍是主观测 32 + 宏观额外 6 = 38 个不同对象；十体物理核心和历表数据没有修改。

## 验证结果

- 20 个测试文件、93 项检查通过，包含阶段筛选、三维体积分布、裁剪统一性与已有回归检查。
- 类型检查和生产构建通过；仍有原有的主脚本体积提示。
- 本地浏览器检查三层开关、剖示、两批组合、独立关闭、重复进入、日期保留、键盘焦点和 700px 窄窗口，未捕获运行异常。
