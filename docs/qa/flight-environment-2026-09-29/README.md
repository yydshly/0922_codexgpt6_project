# 可交互三维飞船环境 · 本地验证

日期：2026-09-29。入口：太阳系全景顶部「飞船环境 · 3D」。此批为本地新阶段预览，未发布到远端。

## 实际交付

Three.js WebGL 网格场景：可绕看和缩放的飞船、近地卫星与翻滚级段、月球背景、合成不规则小天体。支持机外跟随、舷窗与目标近景，独立图层开关。没有将概念图作为场景背景。

W/S 推进与反推、A/D 转向、上下键俯仰、Q/E 滚转、B 辅助减速；右侧按钮可按住操作。固定步长驱动实际局部位置、速度与推进剂变化。失焦或松开清除输入，切换练习场重置状态，保守接触与范围越界暂停。

**教学边界**：此版本不是正式轨道飞行。没有引力、转移航程、真实姿态动力学、完整设备模型、任务存档或真实碰撞解体。目标静止或按教学角速率旋转；地球/月球为静置背景。回到原全景恢复此前播放状态，原航天任务数据不被此练习写入。

## 浏览器检查

生产构建，本机独立 Chrome 无界面测试实例；1440×1000 与 390×844 视口。12 项检查通过，运行与控制台错误为空。记录：[checks.json](checks.json)。

- 有真实 WebGL canvas；推进确实改变目标距离、速率与燃料。
- 关机后滑行且燃料不再减少；辅助反推逐渐减速。
- 暂停冻结读数；镜头拖动不会改动飞船状态。
- 舷窗和机外切换，近看目标，跨环境重置均可用。
- 窄屏无横向溢出；返回全景后焦点回到原入口。
- 首轮画面检查发现目标挤在边缘与岩体三角面明显，已修正默认取景和共享顶点法线，复核后保存下列截图。
