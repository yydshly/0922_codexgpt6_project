## 怎样查看

1. 在地球基地左侧打开“任务总览与验收”。部署检查通过后，先显示本次部署后的结果，再折叠保留出发到部署的六步记录。
2. P5 无推进分支观察完成后，可以直接点击“查看本次任务结果”。总览打开时暂停任务，返回后由原操作面板继续。
3. 先看两个对象的卡片，再看路线：P1 是共同起点；二级为 P2 → P3，卫星为 P4 → P5。从 P1 直接进入卫星工作的任务，会把 P2/P3 标为“本次未执行”。
4. “下载本次结果摘要”导出此时的 Markdown 文字记录；需要恢复模拟，请另用“飞行存档”保存并导出 JSON。下载摘要不覆盖浏览器存档，不改变资源或计算状态。

## 结果如何判定

| 项目 | 判据与范围 |
|---|---|
| 出发与部署四项检查 | 原有离台、分级、绕地验证、部署检查；不代替后续任务成功 |
| P1 | 执行机动并完成 900 s 有限时段对照；只生成方案或点火不算完成 |
| P2 | 点火检查通过，重启锁定且 120 s 简化钝化完成；不能仅凭锁定标记完成 |
| P3 | 到达 20 km 时显示“到达模型边界”；不标成安全着陆、烧毁或处置完成 |
| P4 | 观测数据达到本任务目标并交付地面，待传队列为空；采集到机上不算下传完成 |
| P5 | 完成退役后观察才标记本无推进分支完成；“保留工作”与“刚退役”仍是检查点 |
| 停止 | 依据当前阶段与已有停止结果显示原因；保留此前通过的检查，不重新要求发射 |

状态由现有模型记录推导，不增加可点击勾选的“验收通过”，也不修改飞行存档版本。

## 二级历史位置与卫星当前位置

进入 P4 后，模型只继续推进卫星，二级记录停在进入时刻。总览显示两张卡片的任务时刻：二级明确为“历史记录”，卫星为“当前计算”。

例如，二级卡片的 20 km 来自 P3 的最后记录；它不是与当前卫星同步的二级位置。若本次跳过 P2/P3，则只说明没有执行二级处置，不推断二级后来在何处。

卫星发电、观测、维护和退役均沿用现有数据；退役后未完成空间处置的状态仍保留。两条任务线不能互相代替完成结论。

## 验收范围

- 完整路线：核对 P1/P2/P4/P5 的完成记录，P3 单独显示模型边界；两张对象卡的时刻与高度互不混用。
- 直接卫星路线：P1 → P4 时，P2/P3 显示“本次未执行”，无需为了补齐绿色状态重跑。
- 中途状态：点火结束、数据未下传、保留工作、刚退役等均保持相应检查点。
- 暂停、返回与恢复：打开总览暂停；返回操作不自动推进；从严格校验通过的原存档恢复后，汇总重新读取相同结果。
- 下载：摘要内容与屏幕相同，明确不能恢复飞行；下载不覆盖原存档。
