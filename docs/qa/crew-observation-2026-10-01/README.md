# 乘员卧姿、舷窗与着陆观察复核

状态：2026-10-01 本地完成检查，未提交、未发布；物理版本仍为 `crew-earth-3`。

## 本次解决的问题

- 返回任务复用普通坐姿驾驶舱，无法清楚解释乘员如何承受轴向座椅作用、看向哪里。载人任务改用有背板、头部侧垫、五点约束带和脚托的承力卧姿；自由探索保持原有坐姿。
- 舷窗镜头相对飞船滞后、转头时眼点没有随头部旋转。镜头现与同一个人物的眼睛、头部转动轴及朝向一致，画面上方使用头部坐标，不强行翻转成地球向上。
- 着陆时仍显示平台距离与偏角。舱内仪表按发射、在轨、返回切换，返回显示参考点高度、竖直速度、最低点净空、倾角、过载和着陆推进剂，使用中文标题和明确单位。
- 返回默认舷窗朝天空，缺少对地观察入口。增加固定舱底摄像头、舱内实时屏幕和放大视图；服务舱分离后启用，中心射线没有指向地球时明确说明。镜头装在支脚与喷口之间，不透过热盾观察。
- 舱内镜头沿用外部 10 米最短距离，拖动会退出驾驶舱。现以舱体局部坐标进行有限范围观察；重复的手套网格已去除。

## 如何查看

1. 在本地页面刷新后，从全景顶部进入「载人任务 · 地球出发」。
2. 「舱内看驾驶员」查看背板、头部侧垫、屈膝、脚托与约束带，可拖动在有限范围观察。
3. 「驾驶员视角」来自同一个人物的眼睛，可拖动转头；点击「看仪表」或「回正视线」。
4. 自动演示到服务舱分离后，舱内屏幕开始显示舱底摄像；「对地摄像」放大同一镜头。近地下降时对照参考点高度、支脚净空和下降速度，接地后净空趋近 0，但参考点仍在地面上方。
5. 右侧「驾驶员怎样观察与着陆？」说明默认视线、固定镜头、射线距离及各阶段读数。摄像头沿实际舱底方向，姿态不合适时不会人为把画面校正成看地面。

## 验证范围

本轮全项目回归通过：147 个文件、789 项测试。其后追加头部眼点、手套与舱内观察修正，最终专项回归通过：5 个文件、47 项测试。构建、TypeScript 与文档同步检查通过。日志保留于本目录；全部为本地检查。

专项测试覆盖承力背板朝向、约 90° 屈膝、脚托接触与舱底净空、头盔窗口、两种驾驶舱的实际遮挡射线、原始相机安装被支脚遮挡的反例、固定镜头的倾斜/滚转、近地至 400 km 的椭球射线交点、阶段仪表、实际推力读数与输入状态不可变性。

浏览器检查覆盖真实积分生成的二级入轨、高空滑行、再入、主伞、软着陆、首次接地、完成和倾角失败状态。检查驾驶员与固定摄像头方向、转头与眼点、阶段读数、存档恢复、暂停期间不改变状态与资源、近地持续运行至完成、重新开始及 680 像素宽布局。结果与逐项结论见 [browser-checks.json](browser-checks.json)。正常运行中未记录浏览器运行时/资源错误或渲染目标反馈错误。

浏览器检查使用独立的隐藏 Chrome 配置和本地生产构建，没有操作用户已有标签页。软件渲染截图用于几何与界面复核，不作为真实设备帧率或航天工程认证。

## 来源、模型与剩余边界

[NASA 猎户座乘员系统](https://www.nasa.gov/reference/crew-systems/)说明发射与再入的仰躺、屈膝、脚托、约束及前方仪表原则。本项目仅参考这些原则，座椅、返回舱、摄像头和陆地软着陆组合为原创教学模型，不称为真实型号复刻。

人物保持座椅约束，头部观察为有限转动；不求解人体响应、生命保障或健康结果。固定镜头只表现现有三维场景，不提供实时实拍影像、雷达测高或落区安全判定；镜头热防护、损伤与曝光也未模拟。地面仍是零海拔教学陆地、近景切为相同局部参考平面。本轮未提高轨道或气动精度，没有修改推进状态、飞船姿态、资源或存档版本。

主程序现有入口大包警告仍保留；本轮附加画面复用同一 WebGL 渲染器，只有舱内可见时才更新，最多 10 Hz。主视图按动画帧更新，暂停时不重复绘制未变化的附加画面。
