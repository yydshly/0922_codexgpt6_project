# R07：全景汇总与内部专题路线

## 本批做了什么

右侧观察操作区增加「专题路线」，自由目录同时增加入口。五条路线直接调用已有的场景定位、课程、图层和参数模块，始终复用同一主画布。六章十六节入门主线保留；专题用于按问题深入观察，没有再开一套孤立演示。

| 专题 | 顺序 | 步数 |
| --- | --- | --- |
| 整体与边界 | 整体 → 行星区域 → 日球层 → 奥尔特云 → 同屏对照 | 5 |
| 地球到月球 | 地球本体 → 地月系统 → 月相 → 同步自转 | 4 |
| 巨行星与卫星 | 木星家族 → 土星家族 → 土卫二 → 木卫一物质联系 | 4 |
| 区域与小天体 | 主带 → 爱神星形状 → 哈雷 → 柯伊伯带 → 塞德娜 | 5 |
| 太阳风与地球 | 日冕 → 太阳风来流 → 磁层 → 极光 | 4 |

爱神星是跨类别比较的近地案例，不把它摆进主带。卫星轨道、行星尘埃环与等离子体环也分别说明。路线文案复用现有模块已记录的科学边界，不新增天体、历表或事件计算。

## 操作约定

- 默认不选中任何专题。选择后显示第几步、观察任务、真实与示意的区别、下一步名称。
- 进入与切换暂停日期播放及现象示意，保留当前观测日期；运动课仍按原约定准备推荐倍率。不是保持实时连续摄影的导览。
- 「查看本步模块与来源」定位到已有侧栏模块，不更换主场景；右侧「专题路线」可随时回到引导。
- 手动查看其他目标、课程，或关闭所需图层后，不继续标称“本步画面已定位”。显示已离开或所缺阶段，允许重新定位。
- 阶段开关不会被路线偷偷打开；缺少阶段或资料时禁用依赖的跳转并显示原因。重新定位也遵守门控。
- 前进后退同时恢复专题步骤和既有镜头；沿用全局约定，不回退日期。退出暂停并恢复全景默认图层，保持日期及阶段开关。
- 引导、专题控制放在右栏滚动区；不增加画布上方的固定操作行。

## 修正的跨模块衔接

区域切换的旧清理效果会清掉同一次操作刚选中的近景对象。本批对专题发起的一次完整导航保护目标设置，待该次状态提交后恢复普通区域切换行为；继续复用既有历史记录，不修改天体位置来配合文字。入门主线另清除残留运动课程状态。

## 科学边界与接下来的工作

路线不是完整天体数据库，不改变现有距离压缩、球体放大、纹理、粒子点云和边界示意。每步都指出所用近似，详细来源由已有模块提供。五条路线接入不等于 R07 全部验收完成。

R07 续批已加入逐体目录及覆盖检查，结果见下文。最终用户验收仍待完成；清单覆盖与交互检查不代替数据精度、全天体收录或全版本性能验收。之后仍为 R08 真实星空与宇宙定位、R09 科学、性能与版本总验收。首版没有宣称收录所有太阳系天体或实现导航级预测。

### 修复的问题

1. 当前供数统计漏计卡戎与准卫星，已补入有效状态。总表改称“当前可定位”，按阶段、当前历表就绪情况计算；不能把可定位数当作当前可见数。
2. “运行关系与天象”大类入口此前仍滚到旧的行星速度比较，现在进入 14 节运动与天象课程目录。
3. 从隐藏环的运动课进入环系大类时，会恢复土星环的显示。
4. 只开启阶段 06、关闭阶段 05 时，近地环境大类改为进入辐射带；不再强行进入被关闭的磁层模块。
5. 尘埃入口恢复该组示意分项，避免此前分项全关后入口没有相应内容。

### 来源、加载与返回

目录每行区分等待、就绪、阶段关闭、读取失败。失败条目不能定位旧位置，提供对应数据类型的重试；其他已就绪成员不受无关资料失败影响。主历表异常仍在统一时间栏恢复。大类总表用于概念与区域，逐体目录用于已收录对象，两者不互相替代。

历史场景仍共用原三维画布、使用独立历史日期。进入时主页暂停，返回保留主页日期和原入口；历史读取失败时不显示编造参数，仍能退出并重新加载。
