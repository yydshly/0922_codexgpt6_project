# 综合全景中的冥王星—卡戎

## 入口与交互

综合全景 → 全景现象 → 定位冥王星—卡戎。也可从冥王星区域参数进入。七个家族 / 双体入口共用已有宏观画布，原专门近景继续保留。

远景保留双体定位标记，靠近后展示两颗球体。支持名称、球体和列表点选；参考轨道、质心标记分别开关。前后一天、播放和暂停使用主页日期，镜头跟随双体质心；返回恢复首次定位前视角。阶段 04 与已收录卫星图层控制此双体，关闭时退出定位。展开时隐藏原区域冥王星标记，避免画出两个冥王星。

## 科学依据与处理

- 复用 [现有 Horizons 月包清单](../public/data/dwarfs/manifest.json)，版本 horizons-dwarfs-2026-2027-v1。输入为同一时刻 SSB 原点、ECLIPJ2000 轴、TDB 秒、km 与 km/s 的无光行时修正几何状态。
- 只有主帧与双体帧时间、坐标、单位和成员齐全时才绘制；缺失或非有限值不产生伪造位置，面板可重试。
- 双体质心用已有 PLU060 引力参数 GM：冥王星 869.3、卡戎 106.1 km³/s²，对两中心位置作加权平均。这是双体近似质心，不是含另外四颗卫星的完整系统质心。
- 将此中心相对太阳的位置按原宏观函数压缩。局部向量和两个平均半径则使用同一线性比例：每 km 对应 0.13 / 冥王星半径个绘图单位。局部间距与半径比真实，局部与全局不能共用尺规。
- 位置随已有插值改变；不是依照 6.3872 天的资料周期绘制匀速圆。两条参考线由相对状态计算瞬时二体椭圆，再按 GM 比分配到两颗天体，每超过 30 分钟观测时间刷新。
- 质心距离超过冥王星平均半径时，面板据当期状态说明质心在球体外；不是额外导入的天体。卡戎相对高度以冥王星为原点，沿 J2000 黄道法线测量，不是距太阳的黄道高度。

[NASA 冥王星资料](https://science.nasa.gov/dwarf-planets/pluto/facts/)列出五颗已知卫星及卡戎的公转与潮汐锁定关系。本轮仅接入已有卡戎历表，未导入 Nix、Hydra、Kerberos 和 Styx 的状态。页面已明确说明不完整范围。NASA 页面更新于 2025-04-22，本轮核对于 2026-09-24。

球体颜色为示意，未重建精确地形、表面经度和同步锁定姿态；照明保留全景展示补光。新增的是已有数据的场景接入，项目不同动态目标仍为 38 个，十体物理模型不变。

## 验收

1. 定位双体，确认仍是同一全景画布；点选两者能看到半径、相对间距、速度和高度。
2. 前进一天，观察球体方位变化；近圆轨道下，取整后的距离、速度可能保持相同，不等于没有运动。
3. 暂停日期，等待后位置不再变化；质心和轨道线可分别隐藏。
4. 只看阶段 04 时双体仍可用；隐藏该阶段或卫星图层时同步退出定位。
5. 返回原视角；切换原六个行星家族与空间现象，保持日期和原入口功能。
6. 检查桌面和 700px 窄窗口的侧栏滚动与名称布局。

本轮先本地验收，未推送远端。生产构建保留原主包体积提示。
