# 太阳系观测站：科学验证报告

本报告直接汇总当前项目的 [物理验证结果](../public/data/validation-report.json) 与 [历表插值验证结果](../public/data/interpolation-report.json)。两项报告均通过现有验收门槛。数值结果仅描述本次初始条件、模型、采样时刻和数据版本，不能解释为真实天体位置的绝对精度保证。

- 数据版本：`horizons-2026-2027-v1`，展示覆盖 2026-01-01 至 2028-01-01 UTC。
- 物理推演起点：**2026-09-22 00:00:00 UTC**，对应 TDB J2000 秒数 `843307269.1823885`。
- 物理报告生成时间：2026-09-25T10:08:34.435Z（本轮重算）；插值报告生成时间：2026-09-22 08:40:11 UTC。
- 所有位置采用 ECLIPJ2000，原始坐标以太阳系质心为原点；单位为 km、km/s。内部时间采用 TDB，界面显示北京时间。

## 三种差异分别衡量什么

| 项目 | 比较方法 | 可得出的结论 |
| --- | --- | --- |
| 历表插值误差 | 6 小时采样的三次 Hermite 插值，对照未参与插值的 3 小时中点 Horizons 状态 | 检验浏览器中间时刻的位置与速度重建 |
| 数值积分差异 | 同一初始状态、同一十体牛顿模型，比较 300 秒与 37.5 秒步长 | 评估正式物理步长造成的数值差异 |
| 模型与历表差异 | 37.5 秒细步长模型，对照同目标、同时刻的 Horizons 插值历表 | 评估简化物理模型与权威历表之间的差异，仍包含参考积分和历表插值的余量 |

**约 78 米的插值结果不代表物理推演也具有 78 米精度。** JPL 历表自身的观测与建模不确定度，也不包含在这项插值测试中。

同一时刻，位置差异向量满足：

```text
正式推演 − 历表 = (正式推演 − 细步长参考) + (细步长参考 − 历表)
```

这不意味着三个差异的长度可以相加或相减。各列的最大值还可能出现在不同日期。例如水星的正式推演总差异小于细步长模型差异，是不同方向的差异部分抵消，不能据此认定粗步长更准确。

## 历表重建：独立中点检查

从真实 Horizons 数据中保留每 6 小时的位置与速度作为插值节点，逐一用每段的 3 小时中点作检查；这些中点的位置和速度都未参与插值。

- 检查 **17 个 NAIF 目标，共 49,657 个中点**；目标包含展示用天体中心及推演用系统质心，并非 17 个独立模拟天体。
- 最大位置差：**0.078369535 km，约 78.37 m**，出现在水星。
- 月球中心最大位置差：约 **19.76 m**；木星自身中心约 **34.70 m**。
- 位置验收门槛为 1 km，全部目标通过。速度差异也逐目标记录在原始 JSON 中。

这些是已检查中点的最大值，不是所有连续时刻的严格误差上界。月球相对地球的位置由两条几何状态相减，其误差不应直接等同于月球中心单独的插值误差。

## 一年推演与 JPL 对照

模型包含太阳、八颗行星与月球，太阳同样受到其他天体引力。采用双精度牛顿引力及 kick–drift–kick 形式的 Velocity Verlet。正式步长为 300 秒，另运行 150、75、37.5 秒版本进行数值核验。

下表为起点后 **365 天、逐日采样**的最大位置差，单位均为 **km**。行星相对太阳，月球相对地球；三个栏目独立计算，不做误差长度相减。

| 天体 | 正式推演与 JPL 总差异 | 数值差异：300 s 对 37.5 s | 细步长模型与 JPL 差异 |
| --- | ---: | ---: | ---: |
| 水星 | 146.856 | 29.859 | 164.234 |
| 金星 | 91.475 | 3.754 | 95.225 |
| 地球 | 53.576 | 1.215 | 54.619 |
| 月球 | 22.789 | 6.466 | 16.677 |
| 火星系统 | 33.200 | 0.213225 | 33.409 |
| 木星系统 | 0.233797 | 0.001462 | 0.234675 |
| 土星系统 | 0.237736 | 0.000262 | 0.237510 |
| 天王星系统 | 0.199982 | 0.000113 | 0.199979 |
| 海王星系统 | 0.244566 | 0.000174 | 0.244617 |

太阳另按相对太阳系质心的状态比较，一年最大总位置差为 **0.216794 km**。原始报告还提供 30 天及 365 天各天体的位置、速度最大差异和均方根差异；例如水星一年最大总速度差为约 **0.1331 m/s**，月球约 **0.06087 m/s**。

300 对 150 秒的最大位置差为 22.749354 km，150 对 75 秒为 5.687378 km，比值 **3.99997**，符合本次案例中的二阶收敛表现。37.5 秒参考也不是精确解：75 对 37.5 秒的一年最大位置差仍为水星 **1.421803 km**、月球 **0.308271 km**，已在报告中独立保留。外行星的亚米数值差异还可能受浮点舍入影响，不应解释为相同量级的真实轨道精度。

为避免把卫星引起的中心摆动误算成积分误差，展示和推演采用不同但明确对应的对象：

- 展示使用行星自身中心：`199、299、399、499、599、699、799、899`，以及太阳 `10`、月球 `301`。
- 推演使用太阳 `10`，水星 `1`、金星 `2`，地球 `399`、月球 `301`，火星至海王星系统质心 `4…8`，并配套使用对应的系统 GM。
- 对照两侧使用相同的 NAIF 目标。水星、金星没有天然卫星，其中心与系统质心等同；地球和月球分别计算。火星与外行星的系统质心不会与展示用行星中心直接相减。

## 十年稳定性及验收

从相同真实初值独立推进 **3,652.5 天（10 儒略年）**，以每日及末尾半日状态检查守恒量，同时比较 300 秒与 75 秒步长。该测试超出内置历表覆盖范围，只检验十体模型数值稳定性，不表示已经验证十年真实天文预测精度。

| 指标 | 本次结果 | 验收门槛 |
| --- | ---: | ---: |
| 总机械能相对偏差峰值 | 3.38068 × 10⁻¹¹ | < 10⁻⁸ |
| 总角动量向量相对偏差峰值 | 5.26726 × 10⁻¹⁴ | < 10⁻¹⁰ |
| 行星最大数值位置差：300 s 对 75 s | 292.337 km（水星） | < 500 km |
| 月球最大数值位置差：300 s 对 75 s | 61.542 km | < 150 km |

一年数值差异也通过行星 <100 km、月球 <30 km 的门槛；检查值全部有限。自动化测试另覆盖双体解析轨道周期、太阳运动、30/60/144 Hz 输入的一致固定步结果、二阶收敛、推进预算、快照隔离及重置。

## 来源、边界与复验

历表来自 [NASA/JPL Horizons](https://ssd.jpl.nasa.gov/horizons/manual.html)，请求及返回数据校验信息保存在 [manifest.json](../public/data/manifest.json)，原始压缩响应保存在 `data-sources/horizons/`。引力参数采用 [NAIF DE440 GM 常数](https://naif.jpl.nasa.gov/pub/naif/generic_kernels/pck/gm_de440.tpc)；物理参数参考 [JPL 行星参数](https://ssd.jpl.nasa.gov/planets/phys_par.html)。所有对照使用几何状态，不采用光行时或恒星光行差修正。

十体模型省略相对论、非球形引力、小天体摄动和未展开的卫星内部结构。模型对 JPL 的差异没有“必须为零”的验收门槛，也没有将每项差异直接归因于某一种遗漏效应。小行星带、柯伊伯带和纹理属于科普显示，不参与本次引力求解。UTC 与 TDB 转换使用项目中的 NAIF 近似；2027 年暂按无新增闰秒处理，若 IERS 公告变化须更新数据。

在项目根目录执行：

```bash
npm ci
npm test
npm run validate:physics
npm run build
```

`validate:physics` 使用本地历表，重新计算并覆盖 `public/data/validation-report.json`。若要从已缓存的 Horizons 原始数据重建历表及独立插值检查，可运行：

```bash
python scripts/prepare-data.py
```

缓存齐全时无需网络；重新下载缺失的 JPL 数据时，脚本要求提供真实维护者联系方式。重建数据或修改积分实现后，应再次执行物理验证，并依据新 JSON 更新本报告。
