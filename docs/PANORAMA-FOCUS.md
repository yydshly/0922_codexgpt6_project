# 综合全景：专注行星

## 入口与效果

「综合全景 → 全景现象 → 行星如何绕太阳运行 → 专注行星」。当前定位其他对象时先点「总览行星轨道」。可从全景、行星区域或太阳 / 行星本体定位开启。

开启时临时隐藏卫星及家族标注、区域点群与代表成员、彗星、双体和现象层，保留太阳、八大行星、已开启的环、地球外观与参考线；背景示意星空保留。开关不改变当前镜头、行星跟随或观测时间。侧视、俯视及行星高度示意仍可使用。

侧栏顶部始终显示「恢复其他内容」。原有阶段、图层与现象勾选不被覆盖；退出后恢复这些选择，原先关闭的内容保持关闭。临时隐藏单独标注，避免误以为已取消勾选。专注期间修改某个勾选，退出时使用最新选择。

主动定位彗星、区域成员、卫星家族、冥王星—卡戎或其他现象时自动退出；进入其他区域、天体家族、宇宙尺度或选择顶部预设也自动退出。定位太阳或八大行星本体保持专注。退出只解除过滤，不重置用户后来主动调整的视角。

## 实现与科学边界

`macroFocus.ts` 在阶段过滤之后计算临时可见性，不改写原始状态。双体的渲染和家族标注同步受过滤控制；侧栏定位操作保持可用，可直接切换目标。两种状态都复用同一画布和历表。

没有新增科学对象或供数，项目仍为 38 个动态目标。球体大小与空间距离沿用全景展示缩放；专注不是改为真实统一比例。轨道、尺度圆环与方向箭头的来源和边界见 [轨道说明](PANORAMA-ORBITS.md)，静态云图见 [地球外观](PANORAMA-EARTH.md)。

## 验收

1. 总览行星轨道，开启专注：其他内容暂时隐藏，日期与镜头保持不变。
2. 在图层面板确认勾选保留，显示「专注中隐藏」；点顶部恢复检查原先关闭的奥尔特云仍关闭。
3. 定位水星后开启 / 退出专注，检查继续跟随水星且镜头不跳动。
4. 专注中定位哈雷或冥王星—卡戎，确认自动退出并可观察目标。
5. 专注中侧看轨道倾角，确认过滤保留；700px 窗口可使用恢复按钮。

33 个测试文件、143 项检查通过，覆盖临时掩码、保留关闭项、阶段门控与现象选择恢复。浏览器验证以上交互，无运行时异常；桌面和 700px 窄窗口截图留在本地验收缓存。生产构建通过，现有主包体积提示仍保留。本轮仅本地提交，等待验收，未推送。
