# 综合全景：行星参考轨道、尺度环与运动方向

## 解决的混淆

全景原有的八条平面圆环只是距离参照，不能代表行星的倾斜和偏心轨道。本轮默认显示由当前历表状态计算的八颗行星参考曲线，原有尺度圆环改为单独可选显示；不把圆环改名成真实轨迹。

「综合全景 → 全景现象 → 行星如何绕太阳运行」分别控制参考轨道、距离参照圆环及运动方向箭头，提供总览和侧看轨道倾角入口。定位某颗行星时只显示它的参考轨道与方向；定位其他种类对象时隐藏行星曲线，减少干扰。这些开关不控制彗星或区域成员的独立参考轨道。

## 来源与计算

数据来自现有 [JPL 主历表月包清单](../public/data/manifest.json)，沿用 ECLIPJ2000、TDB、km、km/s；先减去同刻太阳中心的位置和速度。参考二体引力参数为太阳 GM 加行星中心 GM，来自 [已有物理目录](../src/data/catalog.ts)。不改变历表供数和十体模拟。

参考曲线复用已有二体轨道构造函数，由日心位置、速度推算瞬时椭圆；每 6 小时观测时间刷新，重新开启或高度模式变化时检查是否需要重建。共 361 个角度采样点，最后一点闭合。它不是经过历表验证的未来轨迹，也不预报未纳入扰动后的精确位置；行星当前位置继续独立读取历表。

画面采用既有径向对数压缩，曲线不保持真实空间中的椭圆外形。教学高度 ×10 同时作用于行星和参考曲线的垂直分量，不改变平面位置或科学参数。默认侧视仍为高度 ×1。

浅绿箭头由当期日心速度决定。其方向使用压缩坐标映射对速度的导数，并应用同一高度因子，因此与画面运动方向一致；箭头绘图长度固定，不表示速度大小。实际速度和参考公转周期仍在行星参数中查看。

灰蓝圆环沿用八颗行星参考公转距离作为尺度参照，统一放在黄道面；没有逐日运行含义。行星周围的实体环属于另一类物质结构。

## 验收

1. 总览行星轨道，确认默认参考曲线开启、尺度圆环和箭头关闭。
2. 侧看轨道倾角，再开启高度 ×10，观察球体和曲线一起变化。
3. 独立开关轨道、尺度圆环及方向箭头，检查时间不变。
4. 定位水星、地球或木星，查看当前方向并前进一天；曲线与日期供数不冲突。
5. 定位彗星或其他成员，行星曲线退出近景；返回可恢复显示。
6. 桌面与 700px 窄窗口核对控制和解释。

没有增加天体或新观测数据，动态目标仍为 38 个。本轮与上轮地球外观均保留本地验收，未推送。

## 验证结果

32 个测试文件、139 项检查通过，涵盖解析圆轨道、倾角与高度映射、方向箭头与实际显示映射的数值微分一致性，以及绘图对象的独立可见性和缺失数据处理。浏览器验证独立开关、侧视、高度 ×10、日期保持、行星跟随及桌面 / 700px 窄窗口；九个本体的定位、参数、家族、图层与暂停回归通过，无运行时异常。生产构建通过，保留现有主包体积提示。
