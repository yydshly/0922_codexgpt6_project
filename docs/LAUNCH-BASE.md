## 发射基地视觉修订

首轮问题：进入后以高位俯视展示大面积纯色地面，箭体很小，塔架和建筑缺少近景细节，天空、海岸及材质层次不足。默认镜头还限制仰视，不能从地面感受设施高度。

本轮调整：

- 默认进入发射台近景，保留独立「基地全貌」；「地面仰望」把相机放在约 2.2 m 高度。相机可拖动与缩放，不改变箭体尺寸或物理位置。窄屏使用独立取景，避免相机落到任务中心后方。
- 塔架补充逐层平台、栏杆、楼梯、升降通道、连接臂及管线；箭体补充曲面整流罩、级间环、发动机喷口与固定支架，保持 60 m 尺寸样机。
- 平台改为架在导流通道两侧的结构，补充储罐、供水塔、道路标线、围栏、厂房外墙和屋面设备。设施类型参考 [NASA LC-39B 介绍](https://www.nasa.gov/reference/launch-complex-39b/)；位置、结构尺寸和外观为教学设计，不是该发射场复原，也不是经过工程认证的发射系统。
- 地面加入按米制铺设的混凝土与道路材质，海岸使用沙滩、水面、低矮灌丛、远景雾化；地球大气中的云为程序生成的静态背景，非实时天气。天空反射随教学/历元光照切换，资源随窗口关闭释放。
- 合并设施内同材质静态网格，灌丛使用实例绘制，避免把每根栏杆作为独立绘制对象。真实设备帧率仍待用户实测。

本次未接入燃料、点火、烟焰或起飞。画面持续显示「静置展示 · 未点火」。

## 本轮可用能力

- 太阳系全景右上角「地球出发」进入基地；「整体规划 → 产品方向 → 进入地球基地」及精细观测的地球入口也可进入。需要真实历表模式及已就绪的日期，不能把物理实验状态当作真实基地初值。
- 「基地全貌 / 发射台 / 组装厂房 / 任务中心」定位三维设施；可拖动、滚轮缩放、方向键旋转、加减键缩放，点击设施或名称靠近。
- 「基地现场 / 地球定位 / 近地视角」显示同一基地；画面始终说明镜头高度不等于飞行高度，金色定位符不是实际设施尺寸。切换视角只改变表示和镜头，不修改实体位置。
- 「任务目标 / 载具方案 / 来源与边界」解释首个任务、教学参数与科学依据。组装入口不可用，并明确说明第 2 步接入。
- 进入时复制主观测的最后有效状态并暂停。三个视角共用基准日期；返回保留主观测原日期、选择、镜头和播放/暂停状态；从规划进入则返回原规划页。
- 默认「教学日光」便于查看设施，不修改基准日期；切到「该时刻太阳」按历表与参考地球朝向计算光向。地球视角采用该时刻光向及已声明的暗面辅助补光，静态云图不是天气实况。
- 三维连接中断可重建，保留日期和当前设施/视角；地球贴图失败可单独重试。后台观测的宏观绘制暂停，关闭后释放基地资源。

## 坐标、设施与来源

教学选址为北纬 28.5°、西经 80.6°、WGS84 椭球高度 0 m，位于佛罗里达沿海区域。选址与建筑布局是本项目的教学设定，不声称对应某个真实发射台；海岸、树林、道路与设施是程序生成的局部场景，未导入测绘地形。

地理位置采用 WGS84 椭球：长半轴 6,378,137 m，扁率倒数 298.257223563，引力参数 3.986004418 × 10¹⁴ m³/s²；来源 [NGA WGS84 定义](https://earth-info.nga.mil/?action=wgs84&dir=wgs84)。局部坐标为东、上、南，单位米；全球表示和局部表示通过同一个 ECEF 基地锚点转换。显示用地球半径单位不改变物理米制位置。

地球朝向沿用已有 IAU 线性参考模型。未接入 UT1、极移与完整岁差章动，不将这一姿态近似称为高精度 ITRF/GCRF 转换或导航模型。地球贴图沿用已入库资产及[署名清单](../public/textures/sources.json)，近地像素和简化大气存在分辨率限制。

## 验证与有限验收

此前 E1 功能轮全量检查：363 项通过（87 个文件），包含新增 WGS84 赤道/本初子午线/极点基准、地理坐标往返、局部基正交与长度保持、同一基地随历元变换与逆变换、非法坐标拒绝。本次视觉修订重跑坐标回归 5 项通过，未重复运行无关的全量物理检查。验证精度与模型现实误差分别记录。

浏览器已核对桌面与窄屏、三维拖动、三种视角、设施定位、载具参数和来源、两种地面照明、全景及规划入口、返回时原日期和播放状态保持；三维连接丢失后可重建。修正窄屏取景与标签遮挡后复验通过。正常流程无脚本或着色器错误。生产构建与文档同步检查通过，仍有原主页包体较大的提示。

视觉修订复核：在桌面 1600×1000 与窄屏 390×844 新拍画面，逐一查看发射台近景、地面仰望、全貌、厂房、任务中心与窄屏。消除重叠地面/水面造成的深度闪烁，修正厂房镜头被任务中心屋面遮挡；新增仰望入口的镜头高度约 2.2 m，箭体仍静置。上述状态与恢复检查在本轮再次通过。证据来自本地独立 Chromium；内置浏览器控制通道不可用，未声称已在用户的实际窗口或设备完成性能验收。键盘焦点和窄屏布局已检查，未做完整屏幕阅读器审计。

本轮只验收四项：

1. 从全景进入基地，能识别发射台、组装厂房与任务中心，点名称可以靠近，拖动能改变三维角度。
2. 查看地球定位和近地视角，能找到同一个基地并返回地面；日期与基地位置不变。
3. 能区分教学设施、WGS84 坐标、载具参数设定、镜头高度与尚未开始的飞行。
4. 返回原观测或规划页，原状态保留；确认后进入 E2 的有限部件组装，不新增本轮范围。
