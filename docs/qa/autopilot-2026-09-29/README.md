# 局部自动驾驶验证

日期：2026-09-29。状态：本地完成，未提交或发布。入口：太阳系全景 → 飞船环境 · 3D → 开启自动驾驶；启航故事的驾驶页也可直接开启。

## 本次变化

- 自动驾驶通过同一套转向、推力和反向减速输入运行，依次消除已有滑行、对准、加速、滑行、减速、停稳；不直接改写位置、速度或姿态。状态提示、喷流、操控件和读数共用实际输入。
- 环顾和观察镜头不接管；驾驶键、屏幕操控按钮或接管按钮会退出自动控制。恢复时继承位置、速度、燃料和任务进度。暂停及隐藏页面沿用原有冻结机制。
- 停稳任务沿用原有距离、速度、朝向和 5 秒保持规则。结果暂停；新环境和重置清空本次控制记录。路线受阻会中止并减速，未加入自主绕障。
- 故事可直接自动巡视，报告分别记录自动控制、手动输入、接管次数和实际完成的手动检查；跳过发射或手动检查不生成通过记录。

## 验证结果

- 构建通过；保留原有主包体积提示。
- 8 个相关测试文件 / 60 项通过，其中自动驾驶 14 项。覆盖三个环境、渐进转向且不修改物理状态、接管后恢复、暂停、受阻路线、燃料不足、高速危险初态、过近状态、反向姿态与横向漂移、不同帧分组及报告证据。
- 本地生产预览 `http://127.0.0.1:4180/`：27 项浏览器检查通过，运行异常与控制台错误为 0，结果见 [checks.json](checks.json)。通过实际界面操作完成三个场景及自动故事，不修改运行中的物理状态以制造成功。
- 浏览器首次切入懒加载故事页面时，检查脚本等待不足，提前查找按钮导致脚本中断；增加页面就绪等待后继续完成剩余检查。不是飞行中断，不计作产品通过项。
- 浏览器还验证了按下屏幕按钮的 Enter 键能够接管，释放后停止继续施加推力；暂停冻结距离、速度、燃料和自动计时，切换镜头和环顾不退出自动驾驶。

## 边界

这是无引力、目标中心固定的局部教学控制器，速度上限 3 m/s、约 25 m 停止余量等都是练习设定。没有真实轨道交会、自动对接、绕障路径规划或从发射连续交接的载人轨道。危险的初始速度、过近位置和推进剂不足不会承诺自动获救。当前结果不存档，浏览器验证不是所有硬件与浏览器的覆盖保证。
