# 全景：统一比例双球比较

## 入口与用途

综合全景 → 全景现象 → 内容目录 → 天体大小 · 统一比例比较 → 打开天体大小比较。

主观测已有分组大小陈列。本轮为宏观观察补双球配对工具，可保留全景镜头与图层，在太阳、八大行星、月球之间任意选两颗，查看共同尺度下的本体直径。提供地月、木星—地球、太阳—木星、太阳—地球快捷组合与交换左右；同一天体配对显示 1 倍。

选择目录仍只滚动说明，点击按钮才打开比较窗口。关闭或 Escape 返回原全景并恢复入口焦点。比较不读取或改变观测时刻：原日期若在播放会继续推进，已暂停则保持暂停。

## 数据及来源（核对于 2026-09-24）

全部使用 `src/data/catalog.ts` 已保存的半径，不新增目标或历表。

- 八大行星：[JPL Planetary Physical Parameters](https://ssd.jpl.nasa.gov/planets/phys_par.html) 的 Mean Radius 列，使用体积等效平均半径，不混用赤道半径。
- 月球：[JPL Planetary Satellite Physical Parameters](https://ssd.jpl.nasa.gov/sats/phys_par/) 的平均半径 1,737.4 km。
- 太阳：现有参考半径 695,700 km，与 [IAU 2015 B3](https://www.iau.org/static/resolutions/IAU2015_English.pdf) 名义半径 6.957 × 10⁸ m 一致；名义量是换算常数，不是当日测量结果。
- 表面贴图沿用本地素材，来源与许可见 [贴图清单](../public/textures/sources.json)。

直径 = 半径 × 2；显示的倍数 = 左球半径 ÷ 右球半径。UI 保留参考值和适当舍入，不把比例当成带不确定度的测量报告。

## 画面如何保持比例

两颗球体半径除以同一较大半径得到场景半径，不使用全景的距离对数压缩或各天体独立放大。正交相机与共同显示平面保持投影视直径比例，画布变化时统一适配取景。

球体没有最小可见尺寸补偿：太阳旁的月球可能只有不足一个像素，名称和数值继续存在。球体间留白只是排版，不表示实际距离；统一使用理想球面，不重建扁率。这里比较本体，不绘制环、日冕、大气光晕。朝向和光照固定，不代表当天状态，也不播放自转公转。

比较窗口按需创建独立 WebGL 画布，仅在尺寸变化与纹理加载时重绘，不持续运行额外动画循环。切换配对 / 关闭时释放几何、材质、纹理、观察器和 WebGL 上下文；异步贴图回来后检查是否已销毁。贴图失败显示单色球体并明确提示，半径比例继续有效；WebGL 不可用时仍可阅读数字。

## 验收与验证

1. 地球与月球、木星与地球、太阳与地球：球体比例和数字一致，太阳旁小球不被补大。
2. 交换左右后倍数取倒数；选择相同天体得到两颗等大球，比例 1。
3. Escape 只关闭比较窗口，全景仍在；焦点回到打开按钮，暂停日期不改变。
4. 700px 窄窗口无横向溢出，关闭入口和内容可滚动访问。
5. 阻止某张贴图加载时提示降级，继续显示正确比例和数值。

34 个测试文件、146 项检查通过。新增投影测试遍历 100 组配对与三个画幅比例，验证视直径比例及完整取景；另检验极端尺寸无最小值增强和交换后布局对称。上述浏览器验证通过，无运行时异常，桌面和窄窗口截图复核完成。生产构建通过，保留主包体积提示。本轮仅本地提交，未推送。
