# 统一主页与已有内容整合

2026-09-24 · 本地待用户验收，未推送。该批先解决已有内容分散的问题，之后的 R02 已继续实现。

## 问题与决定

原来的默认主页只有 32 个动态目标；另一个“综合全景”承载另外 10 个目标、区域与空间现象。独立详解又有自己的镜头与控制。“模块已实现”不能等同“统一主页可见”。

本轮复用已有综合场景作为默认的太阳系全景，不把同一效果重新复制到第二个渲染器。旧场景明确定位为精细观测，用于真实比例、独立天体近景和十体物理验证。统一主页具有本地返回状态：选择、相机、图层与介绍保留；跨日期后天体仍使用共享的当前日期，不恢复过期状态。浏览器刷新会重新初始化，不承诺跨刷新保存镜头。

## 交互与控制

- 默认打开统一主页，直接显示原综合全景内容；右侧内容总表可逐项进入。
- 主页底部共用北京时间、暂停/播放、日期应用、倍率和返回现在。日期范围校验不允许越界；实测运动时间与空间现象演示进度保持区分。
- 远景优先区域，靠近展开名称和局部现象；不把全部标签与效果同时铺满屏幕。阶段导览优先于局部图层开关。
- 更多工具连接图鉴、整体规划、建设记录、数据实现、物理验证和已有独立解释。
- 精细观测与主页往返保留主页状态；旧行星视图称为“行星观测总览”，不再使用同一个“太阳系全景”名称冒充全部内容。
- 主页时不创建旧观测画布；下钻时保留但暂停主页绘制。宇宙视图也暂停后台绘制。旧观测界面在主页下不接收焦点。
