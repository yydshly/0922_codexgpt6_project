# 驾驶导航与刹停参考

日期：2026-09-29；本地阶段补充，未提交发布。

## 本轮范围

- 目标离开画面后继续用边缘箭头指示；目标在镜头背后时明确标注。
- 座舱分别显示船头方向和实际速度方向，转头、转动飞船、改变速度各自对应状态。
- 使用实际辅助减速参数估算停止距离、时间与燃料；燃料不足时不承诺可以停住。
- 沿滑行方向检查练习场内所有已建模对象的保守接触范围，并以小图解释停止位置与接触位置关系。未接真实轨道、对接或自动制动。

## 验证

局部飞行与座舱几何原有 10 项测试，加上本轮 8 项导航测试：直接运行 B 的结果与预测一致、直线碰撞、横向掠过、燃料不足、多个障碍物取最近者、船体转向提示、后方目标和头部环顾投影。生产构建和浏览器实际运行结果随本目录保存。

浏览器检查覆盖零速标记、推进后滑行、改变朝向但保留惯性、后方目标指引、逐步减速、刹停图、导航图层开关、风险提示、重置、环境切换和小屏。结果见 [检查记录](checks.json)。
