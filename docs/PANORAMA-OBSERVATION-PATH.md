# 第三批 · 观察路径串联

本轮解决连续观察后只能直接返回初始全景、难以回到上一颗天体或上一个区域的问题。没有新增天体、数据源、内容阶段或科学模型：动态目标仍为 38，阶段仍为九批，内容目录仍为 17 项。

## 使用与范围

综合全景顶部增加：

- 上一步 / 下一步：逐个恢复访问过的目的地，按钮提示中给出目的地名称。
- 当前位置与一句观察提示：区分区域、本体、卫星关系、成员及现象示意。
- 推荐观察顺序：整体结构 → 行星区域 → 地球本体 → 地月系统，可逐步点击。动态对象等待真实历表，地月需要阶段 04。

支持同一个太阳系宏观画布内的区域、视角预设、成员类别、太阳与行星本体、卫星家族及选择、彗星、区域成员、冥王星双体和现象定位。镜头拖动 / 缩放、目录滚动、打开比较窗口、阅读资料和推进日期不会单独生成历史条目；离开时会记住最新镜头。

本次全景会话内最多保存 12 个过去位置。后退可再前进；后退后选择新目的地，会清空旧前进分支。关闭全景或转入其他星系视图时清空。独立课程、主观测页和宇宙邻域使用自己的原有返回机制，本轮没有创建跨页面或持久化历史。

原有“返回原视角”保留，作为直接退出当前定位的入口；逐步返回使用新按钮。

## 保存什么，保留什么

保存：相机位置、目标点、朝上方向、最小缩放距离、跟随对象当时的锚点；区域 / 类别 / 目标 / 侧栏、所选卫星或双体成员、基础图层与现象选择、专注模式、参考平面、高度增强状态。

不回退：日期、播放状态、阶段开关、数据和物理实验；云层 / 环等细节偏好沿用当前设置。关闭的阶段不会被历史操作自动重新开启；需要对应阶段或历表的目的地不可用时说明原因。

对于正在移动的天体，返回时计算当前锚点与原锚点的差，将保存的相机与目标点同时平移。这样恢复的是原相对视角，而不是看向天体曾经所在的空位置。区域镜头没有动态锚点，按原坐标恢复。该平移属于观察镜头，不改变历表和物理状态。

## 实现说明

`observationHistory.ts` 管理有界的过去 / 前进栈与锚点平移；`ObservationPath` 只负责操作和说明。宏观场景通过内部镜头接口提供快照并处理恢复，没有暴露浏览器全局变量。

在导航手势之前捕获状态；路由状态及其清理操作稳定后，记录实际离开的目的地，避免“选择区域又清空近景”产生两个历史步骤。实体点选的捕获发生在指针按下，避免 Three.js 原生回调先更改目标而丢失历史。恢复期间抑制普通区域切换的清理动作，保留原有跟随调度。尚未绘制的恢复请求绑定目的地；连续快速导航使用待恢复的快照，避免旧镜头覆盖新目标。

窄窗口给主区域增加纵向滚动，确保加入观察路径后，底部说明和控制仍能完整访问。路径说明默认收起。

## 验收

38 个测试文件、161 项检查通过。新增历史测试检查前后顺序、分支清理、12 项上限、当前锚点平移和输入快照不被修改。

本地浏览器已验证：

1. 初次进入两个历史按钮不可用，没有假记录；推荐路径可进入区域、本体和家族。
2. 手动旋转区域镜头后离开，后退准确恢复相机坐标、目标点和朝上方向；连续后退 / 前进无多余清理条目。
3. 改日期后返回地球，相对镜头保持、绝对位置随新日期移动，日期没有倒退，画布没有重建。
4. 实际鼠标点名称可创建正确记录；卫星选择与参数一起恢复。
5. 关闭阶段 04 后，相关历史按钮不可用且解释原因；重新开启可继续返回。没有自动重开阶段。
6. 谷神星 → 哈雷 → 冥王星—卡戎 → 柯伊伯带，再逐步返回，各目的地和镜头一致。
7. 目录跳转与大小比较不增历史；新目的地清空旧前进分支；切到星系再回来，旧历史清空。
8. 暂停画面帧调度，连续后退 / 后退 / 前进，恢复绘制后目的地和相机仍正确。
9. 700px 窄窗口导航无横向溢出，可纵向滚动访问完整侧栏；桌面和窄窗口截图复核。无运行时异常。

生产构建通过，仍保留原主包体积提示。本批已本地提交，待用户验收后推送。
