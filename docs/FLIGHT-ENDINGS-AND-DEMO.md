# 全程自动演示与两条路线的结尾

日期：2026-09-28。本次是 `earth-launch-2026.09.28` 归档后的独立补充；原标签与归档记录保留不变。本批独立交付，待体验验收；线上发布以对应提交的部署工作流成功为准。

## 从哪里开始

打开「地球出发」，点击顶部 **▶ 从头到尾演示**。无需逐段点击任务按钮。

七章依次为：准备与点火 → 上升与分级 → 入轨与验证 → 部署与分离 → 二级离轨与再入 → 卫星开始工作 → 退役与最终结果。

- 演示使用基准两级火箭和 500 kg 的无推进 E01 卫星，自动执行已有阶段命令与结果检查。
- 「讲解节奏 / 快速演示」调节播放节奏；倒计时和点火保持正常节奏，长滑行自动增加计算步数。性能不足时实际推进会变慢。
- 检查点短暂停留后自动继续；失败会停止并给出原因，不跳过失败状态。
- 可以暂停、继续，旋转与缩放三维画面，打开沿途参数；打开任务总览会暂停演示。
- 演示为临时独立任务，原手动任务在内存中暂停保留，浏览器存档不会被覆盖。点击「退出演示，返回原任务」恢复原任务并保持暂停。
- 刷新网页会丢失未保存的内存任务；既有浏览器存档仍保留。演示本身不自动保存，结束可查看、下载结果摘要。

演示是顺序讲解两条任务线，并不表示现实中卫星必须等二级下降结束才开始工作。进入卫星工作段后，二级转为独立标时的历史记录。

## 二级：20 km 后继续到哪里

保留旧版 20 km 检查点及旧存档的精确恢复。手动模式可选择「继续到地表 · 等效物体参考」，自动演示会衔接这一段。

新增段延用已有质量、阻力系数、参考面积、无升力假设及本地标准大气。使用 0.25 秒步长的 RK4，检测下降穿过 WGS84 椭球面并细分最后一步，停止在 **0 m**，记录参考接触时刻与相对空气速度。积分试算点若越过地表，只在此次边界搜索中按 0 m 取大气参数，不保留地下状态。

20 km 以下将完整箭体换成琥珀色的**计算质点标记**。近地显示 0 m 椭球切面网格，帮助辨认终点；网格不是真实地形，标记不是完整存活的火箭、碎片形状、着陆器或真实残骸。该段没有加入材料烧蚀、热结构破坏、质量损失、风场、真实地形或落区风险模型；0 m 是固定等效参数的参考终点，**不表示安全着陆、真实撞击位置或处置成功**。

真实再入中物体可能在更高处解体，部分材料可能烧蚀、部分可能存活。仅凭高度或热流不能判断材料命运，也不能为所有箭体指定相同的“烧毁高度”。

## 卫星：退役如何处理

当前 E01 没有推进系统，沿用已实现的无推进分支：

1. 交付观测数据并检查任务结束条件。
2. 在通信窗口接收结束指令，关闭业务并隔离充电。
3. 消耗电能至教学设定的 5% 残余，保留对象，再观察 10 分钟在轨运动。

所以结果是 **业务已结束、仍在轨、尚未完成空间处置**。5% 只是模型设定，不是工程钝化认证。低轨物体可能随大气阻力逐渐下降，但当前没有计算长期寿命或再入日期。

主动减轨需要任务本来具备推进器、燃料与指向能力，或预装减轨装置；外部移除需要另外的航天任务。不会给现有 E01 临时添加发动机，也不会用动画把它删除。航天器操控仍在 [后期能力记录](SPACECRAFT-CONTROL-BACKLOG.md)，本次未开发。

## 验证与验收

新增计算验证覆盖：七章实际命令走通、两对象结果分别保留、暂停不推进、退出保留原任务与配置、失败不跳过、旧版 20 km 存档恢复、新命令版本校验、完整新路线精确恢复。0.25 秒与 0.125 秒参考下降比较要求终点位置差 <2 m、时间差 <0.02 s；该检查验证数值收敛，不验证真实材料落点。

已完成：108 个测试文件、516 项检查通过；最终结束锁定与摘要调整另跑 18 项通过。生产构建及规划文档同步检查通过，保留已有主包体积提示。

本地 Chrome 实际从顶部一键走完七章，检查暂停、结束说明、390 px 窄屏无横向溢出和退出恢复原手动任务。另从旧 P3 存档继续至 0 m，核对地表参考面、新存档保存恢复、提前退出演示后原时刻与存档不变；均无浏览器异常。基准案例参考地表时刻 T+9810.5 s、接触前相对空气速度约 51.1 m/s；这是该等效模型的输出，不是实际火箭预报。

待用户体验验收：从顶部一键播放到结束；中途暂停并继续；结束查看二级 0 m 参考记录和退役在轨卫星；退出后核对原任务不变。自动检查不代替用户体验确认。
