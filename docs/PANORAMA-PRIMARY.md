# 综合全景：太阳与八大行星本体

## 补齐的入口

此前太阳和八大行星球体参与显示和遮挡，但点击没有连接到资料回调。水星和金星没有卫星家族入口，因此也缺少同场景定位。本轮补齐九个本体的球体、名称和面板定位，在现有宏观画布观察，并持续跟随日期。

「综合全景 → 全景现象 → 太阳与八大行星」显示说明、质量、参考半径、恒星自转周期、绕太阳公转周期、自转轴倾角，以及当前距离、速度与黄道高度。前后一天、播放暂停共用主页时间轴。可从地球、火星及四大巨行星转到既有卫星家族；本体定位时保留已开启的环，卫星另由家族入口观察。

基础行星不依赖阶段 04，关闭该阶段只关闭卫星 / 环和对应家族入口。关闭行星图层退出行星定位；太阳仍为画面空间原点。重新定位行星会恢复行星图层。所有定位共用已有恢复机制，连续观察不同对象后可回到首次定位前视角。

## 数据与边界

继续使用 [JPL 主历表清单](../public/data/manifest.json) 及 [已有物理参数目录](../src/data/catalog.ts)，没有增加目标。参数来源沿用目录内 NASA/JPL 链接，在面板中可打开。当前项目仍是 38 个不同动态对象；本体列表的 9 个对象并非新导入。

行星的动态参数由同一时刻行星状态减太阳中心状态得到，单位为 km、km/s，距离和高度换算为 AU。太阳参数直接取相对太阳系质心 SSB 的状态，不能用太阳减自身得到的零速度来描述太阳运动。黄道高度使用 ECLIPJ2000 z 分量，不从缩放后的画面反推。太阳在宏观画布中仍固定为坐标原点，没有额外绘制质心摆动。

相机跟随渲染球体的位置，因此兼容既有距离压缩和可选行星高度增强。物理参数不受画面缩放影响；球体尺寸不按同一真实比例呈现。表面使用静态贴图，不是实时影像或精确云层 / 日面活动。恒星自转周期是参考值，不能据此把太阳和巨行星解释为整个表面统一转速的刚体。太阳绕太阳公转周期显示不适用。

## 验收路径

1. 分别定位太阳及八大行星，确认名称和参数，仍为同一画布。
2. 前后一天，对比距离、速度和高度；暂停后日期停止，镜头持续跟随。
3. 直接点击球体和名称，再从地球进入卫星家族，返回首次定位前视角。
4. 关闭阶段 04，确认水星、金星及其他本体仍可定位，家族入口禁用。
5. 关闭行星图层后退出行星定位，重新定位恢复；侧视和复位采用原有镜头规则。
6. 桌面和 700px 窄窗口检查标签、参数滚动和控制按钮。

本轮新增先本地验收，线上版本截至 8dc8eee。

## 本轮验证结果

29 个测试文件、129 项检查和生产构建通过。浏览器逐一检查太阳与八大行星的定位、名称、日期参数变化和相机跟随；实际球体点击、播放暂停、地球转入家族、阶段 04 关闭时本体仍可用、行星图层隐藏和重新开启通过。桌面与 700px 截图复核完成；成员 / 彗星 / 双体返回流程及彗星功能回归通过，无运行时异常。修复新增名称与旧定位标记跨帧避让造成的位置漂移。仍保留现有主包体积提示。
