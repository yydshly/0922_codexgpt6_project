# 飞船结构、材质与近看检查

日期：2026-09-29。范围：本地三维飞船练习场的外形、材质、局部阴影和观察镜头。尚未提交远端。

## 本次变化

- 用收口舱体、服务舱、对接环和钟形喷口替换原来的圆柱主体与简单锥形喷口。
- 增加隔热毯褶皱、管线、紧固件、散热表面、舷窗与舱门；太阳能板具有厚度、框架、支架和独立电池片。
- 区分金属、玻璃、隔热层和电池表面；使用随飞船移动的局部阴影和仅作用于飞船的辅助反射。
- 新增「近看飞船」，与「近看目标」「舷窗」「机外跟随」分别标明当前观察对象。近看后仍可拖动和缩放。

该飞船是原创教学构型，不声称复刻真实型号或通过工程结构验证。补光与材质反射用于细节观察；推进、接触范围、燃料及练习边界没有因外观更改而升级成真实航天任务模型。
