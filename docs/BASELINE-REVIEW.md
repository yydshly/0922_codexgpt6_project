# 当前版本整理与集中验收

2026-09-24 · 对应 M0.1 / M1.1 · 本批按用户要求提交推送，待用户验收；实际部署结果见 GitHub Actions。

## 本批范围

- 整体规划：七个里程碑、21 个工作包、20 类主题与后续分支。
- 全景空间：顶部紧凑两行，辅助入口浮动展开；太阳活动白色半球替换为表面亮斑。
- 学习主线：六章十六节，整体→恒星与行星→卫星家族→小天体→外围→宇宙；不等于六条专题路线已经完成。
- 流程修复：近景角度与复位保持目标、课程卡不被参数推走、退出恢复全景现象设置。
- 本轮整理：20 类内容分别绑定现有模块、数据包、入口、验证范围与缺口；新增五步用户检查记录和导出。

没有新增天体、修改历表或扩大十体物理积分范围。

## 如何验收

主页 → 整体规划 → 总规划 → 当前版本验收。

按全景与操作空间、太阳辨识、顺序学习、近景与资料、退出和恢复五项依次检查。打开场景后，右上角“返回整体规划”回到原规划页签。元素覆盖中可进入区域、家族或宇宙概念视图；未实现对象不会出现虚假观察入口。

结果由用户选择“待检查 / 符合预期 / 发现问题”，可写备注。记录版本为 baseline-2026-09-24-review-v1，保存在当前浏览器 localStorage，可导出 JSON。旧版本或损坏记录不会继承为本版通过。记录不是提交授权、发布状态或科学总验收；没有上传服务。

关闭相关阶段时覆盖入口停用并说明原因；普通检查场景保留阶段开关，用户可在场景内查看阶段说明。入口不会强制开启阶段，不改变日期或播放倍率。物理模式下不会静默切换为真实历表，相关真实定位仍遵循现有可用性提示。
