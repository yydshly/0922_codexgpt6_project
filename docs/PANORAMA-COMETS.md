# 综合全景中的彗星定位与跟随

## 本轮范围

已有哈雷与 67P 历表之前能显示彗核和轨迹，但缺少统一的全景点选、参数定位与相机跟随。本轮不新增数据目标，而是在「综合全景 → 全景现象 → 让彗星随日期运行」补齐两颗彗星的定位；天体与物质 → 彗星 → 认识这里也保留相同控制。

支持点击彗核、场景名称和面板定位，查看日心距离、相对太阳速度及日心黄道高度。镜头随当前历表位置移动，首次定位前的相机可恢复；前后 30 天、时间轴和播放暂停共用主页时间。阶段 02、彗星图层关闭时退出定位，重新开启沿用路径选择。

## 三种内容分开解释

| 内容 | 显示与控制 | 含义 |
| --- | --- | --- |
| 两年历表路径 | 亮线，独立开关 | 2026—2027 年逐日样本连线，来自预置历表；不是实时观测曝光轨迹 |
| 瞬时参考椭圆 | 淡线，独立开关 | 按当期位置和速度构成的二体参考轨道；不是未来历表或全部扰动计算 |
| 彗发与双尾 | 固定近太阳原理示例，明确定位入口 | 沿用原教学几何，不在当前彗核上伪造当天的亮度、活动或尾长 |

可选金色箭头只表示当前彗核背离太阳的方向，绘图长度固定。不开启逐粒子尘埃动力学、尾长预测或事件数据。彗核球体是放大位置标记，颜色不代表精确表面；尚未绘制哈雷的不规则形状或 67P 双叶地形。

彗尾原理按钮会在同一画布定位到固定教学示例。标题与画面持续注明非当日活动，关闭示例会退出该定位；示例与观测日期没有一一对应关系。

## 数据与实现

复用 [原彗星数据说明](COMET-EPHEMERIS.md) 和 [月包清单](../public/data/comets/manifest.json)，版本 horizons-comets-2026-2027-v1，来源 NASA/JPL Horizons。统一 SSB 原点、ECLIPJ2000 轴、TDB 秒、km 与 km/s，无光行时修正。渲染和相机都先减去同一时刻太阳中心，再采用现有宏观距离映射；未加载新月份时不使用旧状态定位。

macroCometAnchor 复用同一日心状态管线，拒绝缺失、时间不匹配、原点不符或不可用的坐标。背日箭头将日心位置归一化并按既有轴约定转换为画面方向，不依赖观察相机。

点选复用原场景射线和成员回调，彗星 ID 转到统一全景焦点。参考路径和椭圆仅改变可见性，不改变科学状态。近景标签布局加入球体投影半径，避免球体放大后自己的名称无处放置。取景参考轨道角动量与太阳方向，减少背日箭头沿视线被遮住的情况。

项目仍为 38 个不同动态对象；十体引力模型不变。本轮先本地验收，未推送。

## 验收步骤

1. 在全景现象分别定位哈雷与 67P，名称可见，仍为同一画布。
2. 前进 30 天，参数更新且镜头继续跟随。播放后暂停，日期停止。
3. 分别关闭亮线与淡线，只保留彗核；打开背日箭头，对照说明。
4. 定位彗尾示例，确认标题说明非当日活动；隐藏示例时退出定位。
5. 关闭阶段 02 或彗星图层，彗星与标注同步隐藏；只看阶段 02 仍能定位。
6. 返回原视角，检查既有卫星家族、冥王星双体与空间现象入口。
7. 桌面与 700px 窄窗口检查侧栏滚动和名称布局。

## 本轮验证结果

27 个测试文件、121 项检查和生产构建通过。浏览器检查覆盖两颗彗星定位、名称与真实鼠标点选、前进 30 天及跨月后的状态和镜头跟随、两类轨迹独立开关、背日箭头、播放暂停、彗尾示例定位和隐藏返回，以及阶段 / 图层门控。桌面与 700px 窄窗口截图复核完成；冥王星双体和五类全景现象回归通过，无运行时异常。保留现有主包体积提示，尚未完成资源拆包优化。
