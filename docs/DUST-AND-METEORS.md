# 第八批：行星际尘埃与流星

## 为什么补这一部分

宏观页已有尘埃点云，但不能仅凭点云理解尘埃是什么、为何不全在一个平面，以及它与流星的关系。本批通过两个独立缩放的三维镜头，将分布、运行关系和进入大气后的现象串起来。

入口：阶段导览 → 08 → 前往本阶段 / 只看这一批；宏观结构 → 尘埃与流星；宏观结构 → 天体与物质 → 尘埃介绍中的展开入口。关闭第八批同步退出演示并隐藏新增入口，不会移除第一批已有的宏观尘埃。

## 已实现

- 行星际镜头：太阳、放大的地球、静态尘埃点云、倾斜碎屑流、地球参考路径；支持旋转、缩放、侧视和复位。地球绕日运动仅为示意。
- 大气镜头：静态地球纹理、增厚的大气层、流星体进入与消融示例；发光只在示意大气内部出现，本例消融后消失，没有绘制陨石落地。
- 当前镜头的图层分别开关，切换镜头保留图层设置、暂停并回到该演示起点。隐藏大气图形不等于移除大气作用。
- 默认暂停；支持播放、暂停、拖动、回到开始与结束重播。完整演示用 18 个显示秒，不对应天体周期或真实入射时长。
- 关联真实彗星的宏观观测入口；进入会启用彗星阶段并切换真实历表模式。关闭原理图只返回原观测，不更改主页日期。

## 来源与处理

核对日期：2026-09-24。以下资料支持概念及示意方向，没有从中导入新的逐体位置或事件数据。

| 来源 | 在产品中的使用 |
| --- | --- |
| [NASA NTRS：Dust in the Solar System — Properties and Origins](https://ntrs.nasa.gov/citations/20140002866) | 说明彗星释放、小行星碰撞与行星际尘埃；不分配来源占比 |
| [NASA：Juno 与黄道光研究](https://www.nasa.gov/missions/serendipitous-juno-spacecraft-detections-shatter-ideas-about-origin-of-zodiacal-light/) | 黄道光是尘埃散射太阳光，具体尘埃来源仍有研究；不把金色点说成自发光 |
| [NASA：流星与陨石事实](https://science.nasa.gov/solar-system/meteors-meteorites/facts/) | 区分流星体、流星、陨石；大气发光和是否有落地残余 |
| [NASA：流星雨](https://science.nasa.gov/solar-system/meteors-meteorites/meteor-showers/) | 解释地球与碎屑分布区域交会；不是某次流星雨日历 |

`src/data/dust.ts` 提供归一化进度、教学几何和来源；`DustExplorer` 将这些状态绘制成 Three.js 场景。使用现有地球静态纹理；点数、大小、厚度、倾角、颜色、均匀推进节奏均为可读性选择，不是实测值。碎屑流有上下高度，但不暗示全部尘埃都在这种轨道上。

## 科学边界

两个镜头之间没有逐颗追踪关系，也没有统一真实尺度。黄道光在文字中解释，没有绘制地面天空的光锥；流星雨成因有说明，没有新增真实流星雨事件。点云保持静态，不求解颗粒引力、辐射力、散射、热力学、消融或气体动力学，不输出密度、通量、高度、温度、落点或风险。

动态天体目录仍为 38 个不同目标，十体引力模型保持独立。演示不是实时太阳系状态，不能用于导航、流星雨或撞击预报。

## 验收

1. 阶段导览进入 08，默认暂停；只看这一批不启动太阳活动、近地空间或其他新增阶段。
2. 逐层隐藏尘埃、碎屑流、参考路径；侧视观察上下厚度，复位镜头；开关不重建画布。
3. 播放 / 暂停 / 拖动后切换进入大气，进度归零并暂停；接近结尾出现光迹，结束后碎块消失，可重播。
4. 单独关闭光迹或大气，核对图形含义；切回分布视角应保留原图层选择。
5. 暂停主页日期后操作演示，返回原观测日期不变；真实彗星链接进入对应宏观成员。
6. 关闭第八阶段时退出；检查桌面、700px 窄窗口、来源、键盘焦点与 Escape 退出。

自动检查验证展示逻辑和几何边界，不是科学模型精度验证。浏览器与构建结果见本次交付记录。
