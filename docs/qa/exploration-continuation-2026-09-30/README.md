# 讲解回看与接回巡视路线

验证日期：2026-10-01。目录沿用开发时创建的日期。状态：本地更新，未提交发布。

## 本次完成

- 「暂停读讲解」保留点击前画面中的原文，再冻结运动、推进剂与到站倒计时；原文不会被暂停说明覆盖。
- 回看带有当时目标和时间的阶段文字。目标切换、暂停、恢复与手动状态可形成新记录；持续倒计时与转姿微文案不会逐帧刷屏。最近 60 条之外的记录移出列表；正在阅读的文字仍保留。
- 「继续未完成巡视」以实际到达记录重建余程，从当前位置、速度和燃料继续。已到达的其它站跳过，终点为出发航点；独立浏览的目标与阅读笔记保留。
- 下一站介绍从实际余程获取，修正跳过已到达站后还在介绍旧顺序的问题。
- 离站失败不提前移除待去站；燃料耗尽时给出明确中止提示，停止零秒倒计时重试。直接调用恢复失败仍保持原状态。
- 单站报告保留一个明确的新航程主按钮，并在按钮旁说明初态重给与报告不自动保存。

## 验证结果

- 13 个相关测试文件、111 项通过：连续航行和余程恢复、记录无副作用、容量与快照、危险提示、耗尽后自动离站，以及跳过站点的介绍回归。
- 浏览器主流程 16 项通过：[checks.json](checks.json)。
- 重新打开阅读区的复查 6 项通过：[reopen-verified.json](reopen-verified.json)。两次有效检查均未捕获运行异常或控制台错误。
- 生产构建通过。桌面 1440 × 1000、窄窗口 390 × 844 已检查。

主流程实际飞行至卫星并保存一份笔记；手动推进后接回剩余路线，实际抵达级段；在级段回看卫星的文字，核对当前目的地和运动状态未被回退；再通过单站训练报告进入新航程，检查旧历史已清空。未通过修改应用内部状态跳过飞行。

复查另外验证：先选过历史条目、收起阅读区并恢复运行，再点击「暂停读讲解」会捕获此刻原文；隐藏导航以后，该按钮也能恢复导航并打开正确的阅读区。

恢复后的整段六站实际飞行、驶离完成点后返航、无法离站后退开重试，由物理状态测试覆盖。本次未重新运行整个发射段，相关行为沿用已有验证。

## 重复检查

启动本地 4180 生产预览和供检查使用的独立 Chrome 调试实例（9333 端口），依次运行 `browser-check.mjs`、`reopen-browser-check.mjs`。脚本只使用界面输入；会写入本目录记录和截图，重跑前请另存现有证据。

这些记录针对局部教学航区。文字回看不是视频回放，恢复巡视不代表真实轨道导航；航程、笔记和讲解均没有永久存档。主观画面体验仍由用户验收。
