# 综合全景：地球云层与薄层大气

## 本轮补齐

主观测已经提供独立云层和大气，而综合全景此前只给地球球体贴表面图。本轮复用同一套视觉效果，挂在全景既有地球之下，在本体、地月家族及近地空间视角共用；没有新增地球副本或独立画布。

「综合全景 → 全景现象 → 地球 · 表面、云层与大气」可靠近地球，分别开关云层和大气。地球本体默认取景更近，便于看见薄层差异。定位后侧栏留在这些控制处；开关不会改变日期、相机、历表或物理状态。云图提供加载、成功、失败状态，失败仍保留表面和大气，可单独重试云图。

## 数据与视觉含义

- 地球位置和参考姿态继续由已有历表与姿态模型驱动；云层附着地球，随其参考自转一起运动，没有额外随机自转或风场。
- 云图为本地 `earth-clouds.jpg`，来源和校验见 [贴图清单](../public/textures/sources.json)。提供者 Solar System Scope / INOVE，CC BY 4.0，基于 NASA 资料；不是观测日期对应的实时天气。
- 大气使用与主观测相同的薄球壳、日照和视线长度近似。太阳方向随地球相对位置更新，夜侧不会生成与白昼等亮的蓝环。这不是完整光谱散射或辐射传输计算。
- 云壳半径系数 1.002、大气壳系数 1.018 是原有显示参数，用于辨识视觉层次，不作为实测云高或大气终点。大气没有硬质外壳。
- 综合全景表面保持原静态贴图和材质，本轮没有接入云影、实时天气、海洋流动或精确地形；关闭云层只关闭独立叠加壳层。
- 球体仍放大、空间距离仍压缩；云层和大气不属于新增天体，也不改变地球物理半径。项目动态对象仍为 38 个。

## 工程处理

`macroEarth.ts` 将两个单位球壳缩放到现有地球半径，继承母球的位置与姿态；按太阳方向更新材质。开关只改变可见性。离开宏观画布时主动清理几何、材质和云纹理；关闭后到达的异步云图会释放，不回写已销毁界面。重试先清理旧云壳，再加载新图，不重复叠加。

主观测的效果函数只增加可选加载状态回调，原调用不受影响。效果不依赖卫星家族阶段；隐藏行星图层时云层和大气随地球一起隐藏。

## 验收

1. 靠近地球，分别关闭云层与大气，比较白色云图、地表和薄蓝边缘。
2. 暂停日期后反复开关，时间保持不变；换日期、拖动环绕，检查日照与表面同步。
3. 切换本体、地月家族、其他行星后再返回，选项保持；隐藏地球时不残留独立球壳。
4. 云图请求失败时显示失败说明；重试成功后恢复云图，无需重开全景。
5. 桌面与 700px 窄窗口检查控制、介绍和来源；地球球体仍可直接点击。

本轮新增仅本地验收，线上版本截至 40437e4。

## 本轮验证结果

30 个测试文件、133 项检查通过，覆盖独立开关、太阳方向变化、加载失败重试、重复加载清理及关闭后的异步回调。浏览器检查云图加载、云层 / 大气分别开关、时钟不变、选择保持、换日期后跟随、地月家族入口、失败提示与恢复；桌面和 700px 截图复核完成。
