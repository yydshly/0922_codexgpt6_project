# 太阳系认知版 · 固定验收清单

范围冻结：当前 20 类主题与 5 项必补的代表体验；不是全部已知天体目录，不是导航或实时空间天气模型。最终确认前的本版状态为“待用户验收”。

## 只走这五步

1. **整体**：进入主页，拖动、缩放，切换侧视，找到行星区域、小行星带与奥尔特云。确认能区分真实位置、压缩距离、区域点云和推断结构。
2. **主体到卫星**：定位地球本体，再进入地月系统。确认近景对象、名称与说明对应；月球相对地球的参数可读，不把金星误当作地球卫星。
3. **运动与日期**：暂停，前进一天，播放公转或自转课程；关闭课程返回全景。确认日历变化、天体运动和教学演示各有明确含义。
4. **解释与返回**：打开一个空间环境或小天体说明，再打开“建设记录 / 数据与实现”；关闭后继续观察。确认按钮能到达对应内容，后退/前进和返回不会迷路。
5. **实际体验**：在你常用的电脑连续操作约 10 分钟，确认没有打不开、黑屏、卡死、严重遮挡或明显错误的对象对应。记录版本、操作路径和问题；不用评判每一个天文学细节。

## 通过与未通过

上述体验可正常完成、没有影响理解或使用的关键问题，由用户明确确认后冻结此版。实际屏幕体验和用户批准不会由自动脚本代勾。

轻微视觉偏好、小幅等待、更多成员、实时天气、更高精度、飞船和游戏能力进入后续清单；它们不自动成为本版的新任务。若遇关键问题，仅修该问题并复验受影响路径，不重新开启一轮无边界优化。
