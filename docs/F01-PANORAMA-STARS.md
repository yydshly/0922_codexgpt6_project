# F01 · 主全景星表背景接入与验证

版本 2026.09.26-r09.10。F01 实现差距已关闭，用户验收待确认；F02 资源预算、F03 实际设备体验、F04 用户总验收保持未关闭。

## 1. 从资料到主全景

主全景原有 750 个随机背景点改为本地 Hipparcos-2 子集的 2,936 个亮星方向，复用独立恒星页的数据包与导入校验，不增加太阳系动态目标。每个绘制点保留 HIP 编号；读取失败时背景留空并提供重试，不生成假星位。

目录为 van Leeuwen 2007 新归算、CDS 2008-09-16 修正版；原始文件校验、筛选和获取时间保存在 `public/data/stars/provenance.json`。选用单星五参数解、位置误差和拟合质量通过筛选、Hp ≤ 6 的子集，不是完整星空。点大小按 Hp 分档作显示增强，统一颜色，不宣称温度、光度或真实半径。

[ESA 星表参考系和历元说明](https://www.cosmos.esa.int/web/esdc/esasky-catalogues)明确区分 ICRS 坐标与 J1991.25 观测历元。本轮不推进自行，不做当前视位置计算。

## 2. 坐标与空间含义

太阳系历表使用 ECLIPJ2000。按 [JPL Horizons 手册](https://ssd.jpl.nasa.gov/horizons/manual.html)规定的固定黄赤交角 84381.448 角秒，将 ICRS 赤道方向绕 X 轴转换到黄道坐标，再映射到已有画面轴 (X,Z,-Y)。这是方向旋转，不把 J1991.25 的恒星位置传播到 2026 年。

背景中心随镜头平移，方向不随镜头一起旋转；绘图半径仅为渲染辅助，不是恒星距离。背景深度置于远平面内，前景天体可遮住星点。运动课、场与粒子独立原理图和历史窗口暂隐背景，避免在不同参考系中误用方向。其他精细观测与星系概念镜头的装饰点未在此范围内替换，图例已分别说明。

## 3. 可操作的出处与失败恢复

画面底部“星表背景”进入来源及显隐开关；点击背景点读取 HIP、ICRS 赤经/赤纬与 Hp，并可进入恒星视图查看同一对象。读取状态、失败原因和重试在同一位置提供，不改变太阳系日期、镜头或天体参数。

## 4. 验证范围与结果

- 2,936 个 HIP 编号与原子集一一对应；每条方向为单位向量。赤道基轴、黄道北极和旋转符号检查通过。
- 沿用已归档并核验 SHA-256 的 ESA 1997 版 5 个同历元样本，用独立球面公式计算黄道方向，与产品笛卡尔转换交叉核对。最大差异约 **1.986203 毫角秒**，低于 20 毫角秒的粗误差检查阈值。其中包含邻星样本，非全部都在亮星背景中。两版来自同一观测任务的不同归算，不是独立望远镜精度认证。
- 实际浏览器从预测屏幕方向点中 **HIP 48356**，主全景读数与独立恒星视图编号一致。显隐、课程暂隐与返回恢复、日期保留、强制加载失败及重试通过。
- 单元测试覆盖镜头平移方向不变、关闭后不可选、空数据无随机回退及缓冲资源复用/释放。336 项自动测试、生产构建与规划文档同步通过。

逐星输出：`public/data/stars/panorama-validation.json`。复算：`npm run validate:panorama-stars`。浏览器回归：`scripts/qa/panorama-stars.mjs`。

未验收：全设备呈现帧率、屏幕阅读器、所有遮挡/拖动组合以及用户视觉认可。固定星表不提供地面所在地、当前星位、自行、视差、光行差、地平遮挡或全天普查保证。关闭 F01 不等于首版完成。
