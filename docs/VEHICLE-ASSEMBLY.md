## 如何查看

太阳系全景 → 地球出发 → 底部「02 组装载具」（或侧栏「开始组装」）。

1. 选择一级、二级发动机，调整各级推进剂加注量，选择 250 / 500 kg 卫星载荷。
2. 查看整箭或展开结构；点击「一级喷口 / 二级 / 卫星载荷」靠近观察。一级发动机组对应四/双喷口，二级高比冲方案有更大的喷口及识别色带，载荷外形为教学设计。青色条显示加注比例；减少推进剂不会缩短油箱或箭体。
3. 质量、推重比、理想真空速度增量随配置计算。一级满载使用轻型发动机组时推重比小于 1，不能应用；任一级推进剂为空也不能应用。可减少加注或换发动机，但静态条件通过不代表任务能入轨。
4. 「保存草稿」写入此浏览器；「读取保存」恢复草稿与已应用方案；「恢复基准」只修改草稿，不覆盖已保存或发射台方案。
5. 「应用配置并查看发射台」先检查，再更新发射台模型和参数，同时保存。可以关闭窗口或刷新后恢复。没有启动推力、推进剂消耗或飞行。

## 计算边界

质量包含两级干质量、所选发动机干质量差、推进剂、载荷与整流罩。起飞推重比使用一级海平面推力除以整箭重量；地表重力按既有地球参数 μ/R² 近似，未包含自转或纬度修正。比冲换算使用标准重力 9.80665 m/s²，二者用途分别说明。

理想速度增量分级计算：一级燃尽后弃置一级干质量，再计算二级；两段均保留整流罩，使用真空比冲。不计空气阻力、重力与转向损失；本值不是当下速度或已验证入轨能力。燃烧时长按一级海平面、二级真空的额定推力/比冲估算。参考 [NASA 理想火箭方程](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/ideal-rocket-equation/)与 [NASA 推重比](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/thrust-to-weight-ratio/)。

本轮仅做静态配置筛查。未来 E3–E5 仍须验证推力随环境变化、推进剂消耗、气动、分级、引导和轨道判定。没有把理想速度预算与圆轨道速度简单比较后宣布成功。

## 保存与异常处理

- 存储键 `orbit.earth-launch.vehicle.v1`；包含格式版本、任务版本、保存时间、草稿与已应用配置。只保存配置，不是飞行存档；与主观测日期独立。
- 读取会验证发动机所属级段、加注档位、载荷选项及已应用配置的可用性。未知版本、损坏数据或不兼容对象不能替换当前配置。
- 可保存暂不可用的草稿，以便继续调整；已应用配置必须通过静态筛查。保存失败时保留内存中的工作并提示，不能显示保存成功；手动读取失败不重置当前草稿。
- 同一浏览器、同一网站来源内持久化。开发地址与 GitHub Pages 的浏览器存储相互独立，不声称云同步。
- 切换组装、设施、地球视角与返回观测不改变基准日期；关闭未保存的草稿后，以最近成功保存内容为准，界面显示未保存状态。
