## 当前能做什么

从地球教学基地出发，选择并应用两级载具配置，完成检查、倒计时、点火和离台。随后上升转弯、分离一级、启动二级，按轨道参数辅助加速与关机。实际绕地一圈验证后，打开教学载荷舱并释放卫星；观察两个独立对象，保存或导出本次飞行，刷新后恢复。

阶段检查点会停下来等待操作。底部六步按钮表示阶段入口与解锁条件，不会跳过动力学计算。左侧「任务总览与验收」显示模型实际达到的节点；前三段完成与部署检查共同构成四段飞行检查。基地就绪与配置已应用分别展示，不冒充用户操作验收。

完整路径：**全景「地球出发」→ 组装并应用 → 检查点火 → 上升分级 → 入轨关机与滑行 → 部署卫星**。

已有任务请从当前步骤继续。快速入口「04 上升与分级」会先用相同配置计算离台结果再进入，不会凭空补充燃料或设定速度。

## 三组验收操作

| 核对组 | 怎么操作 | 应看到什么 |
| --- | --- | --- |
| 过程是否清楚 | 组装应用 → 检查 → 倒计时 → 离台 → 上升 → 分离 → 二级 → 入轨 → 滑行 | 推力、耗油、质量和位置共同变化；一级燃尽等待分离，关机后推力为零且燃料不再减少；完整绕地后才通过入轨检查 |
| 对象与画面是否对应 | 开舱 → 释放 → 卫星近景 → 两者同景 → 轨道全景 → 沉浸观察 | 开舱时卫星仍连接，释放后卫星与二级分别运动；翼板按任务时间展开；相同任务在不同机位中保持时间和实体状态 |
| 离开后是否可恢复 | 保存 → 返回太阳系 → E01 任务入口；再保存 → 刷新 → 飞行存档 → 恢复 | 返回保留暂停任务；重开网页需要读取存档；恢复配置、时间、燃料、阶段和事件，通过校验后先暂停 |

验收要实际操作，阅读或打开总览不会自动标记通过。发现问题时请记录所在步骤、按钮、任务 T 时间，以及画面或参数哪里不对应；不要为了复查而覆盖仍有价值的旧存档。

## 阅读画面与数据

- 真实太阳系继续读取已入库历表；E01 是本次教学模拟生成的人造卫星，不是真实任务遥测。
- 任务有独立时钟。全景的 E01 标记锚定地球，是返回任务的入口，不代表该观测日期的实测卫星坐标。
- 近景按米计算距离；地球尺度的轨道全景中两条预测线可能重叠，使用两者的参数和近景比较，不人为拉开轨道。
- 白色打开的两瓣是保留在二级上的教学舱盖，不是天体；没有新增被抛弃的舱盖碎片。
- 云图、烟羽、蓝色大气边缘和示例空间物体是带说明的展示效果；不表示实时天气、真实密度或碰撞预测。
