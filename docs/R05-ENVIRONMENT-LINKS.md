## 依据与边界

- [NASA：太阳风](https://science.nasa.gov/sun/what-is-the-solar-wind/)：太阳风持续从日冕向外流出；不能把太阳风、耀斑和 CME 当成同一种现象。
- [NASA：磁层与电离层](https://science.nasa.gov/heliophysics/focus-areas/magnetosphere-ionosphere/)：太阳风压缩向阳侧、拉长背日磁尾；磁层是环境结构，场线不是粒子轨道。
- [NASA：极光](https://science.nasa.gov/sun/auroras/)：高能粒子与上层大气相互作用产生发光；太阳—磁层—极光是物理联系，不表示某次爆发必定造成极光。

资料于 2026-09-25 核对。叙述使用上述来源，几何和动画为本项目教学绘制，没有引入当天太阳活动、太阳风速度/密度、磁场观测或极光预报。

黄色点在短段内循环，终点位于示意磁层边界外；不是贯穿整个太阳系的粒子轨迹，消失和再出现只是循环绘图。点数、亮度、速度、时间倍率、磁层大小与极光形态不提供实测数值。四步不模拟传播延迟、磁重联、能量沉积和大气发光计算；地球磁轴及极光环仍采用参考形态。全景中的历表日期与教学进度分开。

## 第二部分：木星环境对照（本地未发布）

主全景「太阳与行星环境」在原有四步后新增三步：木星磁层 → 木卫一供给 → 木星极光。三个效果分别控制，复用同一画布、日期、历史和阶段开关；空间环境属于阶段 05，木卫一定位另外依赖阶段 04 卫星历表。目录、全景标记及现象控制均提供入口。

- 木星本体位置来自原有当日历表，磁尾方向沿日心位置的背日方向；形状、尺寸与磁尾截断是教学选值。
- 木卫一复用已有同日相对状态和家族本体比例。紫色粒子云以当日轨道面及局部压缩距离为摆放参考；这不是实际磁赤道几何、密度或通量模型，也不展示同一批火山粒子的输运轨迹。

## 第四部分：看不见的空间（本地未发布）

主全景 → 全景现象 →「看不见的空间：场、光与粒子」。按场结构→电流片→光→带电粒子→中性原子的顺序阅读；自由目录同时补齐环境联系、物质联系、本模块三个入口。

| 原理图 | 画面表达 | 边界 |
|---|---|---|
| 帕克参考场 | 青色螺旋线，有高于/低于参考平面的方向 | 不是粒子轨道或当日磁场；线间也有磁场，疏密不编码强度 |
| 电流片 | 紫色起伏曲面及参考网线 | 磁极性分界示意，不是薄膜、行星盘面或真实厚度 |
| 电磁辐射 | 从太阳向三维方向散出的黄色箭头 | 光不是太阳风物质流；无光谱、强度或时间延迟计算 |
| 带电粒子 | 局部平行参考场与粉色螺旋路径 | 仅单独定位显示；不叠加全景，不模拟高能粒子通量与剂量 |
| 中性原子 | 绿色原子符号及简化直线方向 | 不是光子；没有电荷交换、引力、辐射压力、电离计算 |

绘图常数和长度无物理单位。五个图层默认关闭，可独立开关；只有当前设置完全匹配时才显示步骤选中，混合层不冒充单步骤。受阶段 09 控制，历史能恢复解释状态；关闭解释清除五层并恢复全景。静态原理图不随观测日期变化，不受现象播放进度驱动，天体历表仍沿用原有日期。
