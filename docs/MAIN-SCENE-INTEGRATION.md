# 主全景整合与验收

2026-09-24 · 本地待用户验收，未发布。

## 产品约定

综合全景承载已实现的太阳系对象、区域与环境。定位在同一画布移动镜头，其他成员保留；文字、数据、剖面和过程演示是辅助解释。不同年代的历表通过明确的历史模式切换，不能把旧访客与当前行星状态拼接。

本次整合不增加天体数量，不把 45 个当前对象、1 个历史案例或 20 项场景展示组标为太阳系所有成员与现象已完成。已有科普模型仍不等于实时科学观测。

## 本次修正

1. 去掉定位行星、卫星系统、小天体、彗星时对其他成员的自动排除。其他轨道可淡化，场景对象继续保留。用户主动关闭图层、选择专注模式或跟随筛选式学习路线仍会隐藏部分内容，有对应状态说明。
2. “场景清单”读取真实三维对象的显隐、材质和镜头范围，不从复选框推断“已经展示”。区分视野内、视野外、近景待展开、已关闭、阶段隐藏、缺少资料等状态。镜头范围相交不保证像素上完全可辨认，遮挡和尺寸仍影响观看。
3. 在主全景补 14 个现象分项开关：日冕/耀斑/CME、磁层/磁场线/极光、三类近地粒子区域、碎屑流/流星、日鞘/外部介质/中性原子。切换影响实际几何效果；基础图层仍独立控制。流星辉光改为小光斑，减少误读为额外球体；极光与周边背景适当减弱。
4. 2I/Borisov 历史模式复用主画布与渲染器；隔离历史场景和当前场景的数据。进入保存相机、暂停当前日期；历史日期与观察方向独立；返回还原相机、当前日期和控制。历史模式只有有资料的太阳、地球与访客，不补造其他历史位置。
5. 修复彗星轨迹载入器硬编码两颗的问题：按当前彗星注册表核对身份和数量，检查坐标参照与采样时间递增；三颗彗星的两年路径均可载入。网络失败可原位重试，不要求关闭保留中的主页。

## 验收顺序

1. 综合全景 → 场景清单：从太阳、行星到区域与环境逐项定位。确认状态随镜头、日期和开关更新。
2. 定位地球、小天体、彗星，打开清单检查其他成员仍在场景中；返回整体后原有空间分布保留。
3. 主全景定位五组现象，切换各分项；检查视觉改变与显隐状态一致。
4. 切换历史：同一画布播放和转动轨迹，返回后日期、镜头、选择不丢失，当前时间控制不会串入历史画面。
5. 切换阶段、加载失败重试、窄窗、键盘返回；逐项记录，而非仅检查入口数量。

## 仍保留的边界

球体放大、宏观距离压缩；部分细节按距离收起。种群、空间现象和背景星点是示意，奥尔特云为推断。当前不补入无可靠资料的卫星、精确表面或当日空间天气。独立辅助图保留局部剖切和教学排版，不以完整复制这些排版作为主全景目标。

这是一轮已有能力的整合；后续 R03–R09 的新增内容与总验收仍保留。用户验收与远端发布分别记录。

## 本地验证结果

43 个测试文件 / 180 项检查通过，构建通过。浏览器逐项检查 14 个本体/区域定位、五组现象关闭与恢复（读取实际绘制数量）、阶段优先级、同一画布历史切换、返回焦点与日期、390 px 窄窗，未出现运行异常。验收结果不代替用户确认；现有大包体提示保留，性能总验收仍未完成。
