# 六站航程回顾与收尾

验证日期：2026-10-01。状态：本地实现和生产预览，未提交或发布。

## 本次完成

- 飞船页右上角「航程回顾」可随时打开，隐藏导航时也能恢复阅读区；打开会暂停实际运动和倒计时。
- 六站按理解顺序列出，实际抵达顺序另列。抵达、打开部件介绍、主动保存笔记分别记录，不把阅读当作拍照、维修或通信成果。
- 完整往返要求到齐地点后返回出发航点。提前访问过出发点不会提前完成；首次完成节点在此后飞行中保留。
- 回顾是打开时的独立快照。关闭面板不自行开船，明确继续才恢复，保留原驾驶方式和停留状态。
- 下载中文 UTF-8 Markdown 或带版本和单位的 JSON；部分航程同样可以下载，并明确未完成。文件不能导入恢复飞行。
- 下载按钮放在六站列表之前；键盘打开回顾时焦点进入阅读区，继续运行时焦点回到三维画面。主动停留的说明不再暗示即将自动离开。

## 验证结果

- 15 个相关测试文件、121 项通过，覆盖飞行动力学和接近、讲解与笔记，以及报告的首次完成判定、实际顺序、区间读数、独立快照和导出。
- 生产构建通过，规划文档同步检查通过。既有打包体积警告仍存在，没有将其当作构建失败。
- 主流程 [checks.json](checks.json)：22 项通过，未捕获运行异常或控制台错误。
- 最终界面复查 [final-verified.json](final-verified.json)：10 项通过，未捕获运行异常或控制台错误。
- 共 32 项有效浏览器检查；桌面 1440 × 1000、窄窗口 390 × 844 已查看截图。

主流程使用同一艘飞船实际接近、停稳并抵达卫星、级段、平台、地球观景点、岩体和出发点。在卫星打开三个部件说明、保存一份笔记，然后通过继续下一站提前结束观察停留。各段运动仍由自动驾驶实际计算；没有修改应用内部状态或直接传送到目的地。

[完整航程记录](completed-report.json) 中首次完成往返为 T+540.3 s、累计约 2545.1 m、已用推进剂约 33.244 kg。六站确有抵达记录，只有一份主动笔记，返航没有补油。随后再次前往卫星，核对首次完成节点不改写，最新累计时间继续增加；退出重进则清空这次航程。

主流程运行于回顾初版。之后仅调整下载位置、主动停留文案和键盘焦点，最终构建另做 10 项复查：原生回车、Tab、键盘下载、恢复驾驶焦点、窄屏及实际卫星停留后的 JSON。未再次运行整个发射段；本批没有修改发射物理或飞船动力学。

### 保留的检查尝试

首次键盘复查在焦点尚未稳定时断言失败，保留 [final-checks.json](final-checks.json) 和 [focused-failure.txt](focused-failure.txt)。后续等待焦点到位，但不完整的合成回车事件未触发浏览器原生 summary 开合，保留 [keyboard-event-attempt.json](keyboard-event-attempt.json) 和 [final-rerun-failure.txt](final-rerun-failure.txt)。

直接检查确认焦点随后位于 summary；带有原生键码及回车文本的事件可以收起面板、运行仍保持暂停。修正检查脚本、关闭其它检查页后，另存最终通过的 `final-verified.json`，没有覆盖上述失败证据。

## 复查方式

在项目根目录启动 4180 生产预览和用于检查的独立 Chrome 调试实例（9333），运行 `browser-check.mjs`、`final-browser-check.mjs`。Node.js 22 以上可直接运行；脚本只使用网页按钮、键盘及读取界面，不改应用内部状态。运行会写入本目录；重跑前另存整个证据目录，并清空下载子目录，避免混入旧下载文件。

这些记录描述合成局部航区，不是实际轨道任务、真实驻留或载人操作认证。视觉体验与验收由用户查看本地预览确认。
