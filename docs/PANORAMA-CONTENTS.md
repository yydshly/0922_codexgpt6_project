# 全景内容目录

## 为什么增加

综合全景已经在同一个画布内接入多个观察模块，但侧栏内容变长，用户需要大量滚动才能找到彗星、卫星或日球层。目录提供稳定的阅读入口，继续使用原来的定位与控制。

## 使用

主页 → 综合全景 → 全景现象 → 内容目录。

目录固定在侧栏滚动区上方，含 16 个模块，并提供「回到全景介绍」：

- 天体与运动：行星运动比较、天体大小比较、行星轨道、太阳与八大行星、地球外观、区域成员、彗星、卫星与环系、冥王星—卡戎。
- 空间现象：太阳活动、地球磁层与极光、辐射带与等离子体层、碎屑流与流星示例、日鞘与星际介质。
- 演示与阅读：现象示意进度、独立详解与来源。

选择目录只跳转说明与控制。需要改变镜头时，再按对应模块的「定位」按钮。没有强制开启阶段或图层，不改变观测日期，不退出专注行星。目录项不保持选中外观，以免手动滚动后误以为该模块仍是当前画面。

阶段关闭时目录后缀显示「阶段未开启」，仍可跳到模块了解原因；区域成员全部关闭时补上说明及阶段导览入口。跳到来源时自动展开阅读区，打开独立课程仍须点击相应按钮。

## 实现与边界

`MacroContentsNav.tsx` 使用侧栏专用滚动容器，仅滚动该容器。目标元素接收键盘焦点，Tab 可继续进入模块控件；不移动整个页面，不重建三维画布。五类现象名称复用已有 `INTEGRATED_ITEMS`，阶段状态使用既有 `StageFlags`。

本轮整理访问路径，没有新增天体、数据或科学模型。已有来源、历表与示意边界继续由各模块说明。目录数量表示控制模块数量，不表示太阳系成员数量。

## 验收

1. 逐一选择 16 个目录项，确认对应内容滚到可见区域，键盘焦点移入模块。
2. 从下部目录回到全景介绍；目录始终可见。
3. 暂停日期，记录镜头及图层，遍历目录后检查没有变化；点击模块内定位才移动镜头。
4. 开启专注行星后阅读日球层，过滤保持；原恢复入口继续可用。
5. 只开启彗星阶段，目录标记其他阶段未开启，区域成员和卫星模块仍提供关闭原因。
6. 700px 窄窗口目录不横向溢出，恢复栏与内容滚动区可用。
