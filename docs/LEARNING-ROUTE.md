# 层级学习主线

2026-09-24，本地待用户验收，未发布。对应总规划 M5.3 / M2.3 的部分交付：一条完整入门主线，不代表规划中的六条专题路线全部完成。

## 引导逻辑

学习路径遵循“先整体后细节、先主体后成员、先区域后代表”，最后再放回更大的宇宙背景。空间现象和其他参数模块保留为延伸阅读，不与主线下一节混排。

| 章 | 顺序 | 理解目的 |
| --- | --- | --- |
| 1 整体结构 | 太阳系全景 | 先建立区域地图 |
| 2 太阳与行星 | 太阳 → 行星区域 → 地球 | 先恒星、再轨道关系、再一颗行星 |
| 3 卫星家族 | 地月 → 木星家族 | 先母星与一颗卫星，再比较多卫星家族 |
| 4 小天体 | 主带 → 灶神星 → 哈雷 → 柯伊伯带 → 冥王星—卡戎 | 区域与成员配对，对比不同类型及家族 |
| 5 外围边界 | 日球层 → 奥尔特云 | 区分环境边界与遥远推断结构 |
| 6 宇宙位置 | 恒星邻域 → 银河系 → 邻近星系 | 从太阳系向更大尺度逐级定位 |

共 6 章 16 节。每节给出所属层级、为什么看、观察任务、显示与数据边界；提供上一节、下一节、资料直达、回到本节和退出。最后一节显示“结束主线”，不因点击结束宣称理解或科学验收完成。

## 与自由浏览的关系

- 顶部“后退 / 前进”只表示浏览历史；“上一节 / 下一节”表示固定课程顺序。
- 学习路线位于浮动目录中，不再增加顶部高度。右侧卡片指引当前节，“查看本节资料”只移动说明面板；顶部“本节引导”回到卡片。
- 自由点击另一个天体、区域或宇宙层级时，保留课程位置并提示自由浏览；可回到该节。旋转镜头、改日期、阅读资料不会被当成学习完成。
- 开始一节会应用适合该节的取景和显示图层，收起干扰主体的现象；不更改观测日期、倍率、物理参数或阶段开关。“退出并恢复全景”恢复默认全景显示；最后一节“结束主线 · 自由探索”保留宇宙位置。
- 日期无数据、成员尚未加载或阶段关闭时，显示原因并禁用相关入口，不自动开启或跳过。课程不会将未加载对象标为已观察。
- 当前课程位置仅在本次全景会话保留；关闭全景后不保存学习进度。

## 数据与范围

复用已有 JPL 位置、家族与区域数据，不增加天体。各节的证据边界引用已有模块：真实状态、参考轨道、显示缩放、结构示意和模型推断分别说明。邻近恒星与星系仍是已有概念图，不因成为课程就升级为实测星表。

主线定义：`src/data/learningRoute.ts`。展示与课程状态：`LearningRoute`、`MacroStructure`；原 `observationHistory` 继续独立管理自由浏览记录。

## 验收

1. 综合全景 → 学习路线：六章十六节，章节顺序明确；选择某节会进入对应画面。
2. 从整体开始逐节走到邻近星系，每节画面、层级、任务与下一步一致；查看资料再返回本节，不丢失学习位置。
3. 在地球与地月之间对照，二者不会混为同一节。自由选其他区域后显示保留进度，回到本节恢复正确对象。
4. 关闭阶段 04，地月与木星家族入口禁用并说明原因；地球节的下一节停下，不跳至下一类。
5. 1024 / 700 / 390 px 窗口检查工具栏；1440 px 桌面仍为两行，顶部高 98 px。
