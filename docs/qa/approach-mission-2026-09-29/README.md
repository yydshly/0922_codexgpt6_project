# 接近与停稳任务检查

日期：2026-09-29。本地生产预览：`http://127.0.0.1:4180/`。本批未提交或发布。

## 如何验收

1. 全景顶部进入「飞船环境 · 3D」，点击「开始接近任务」。飞船回到当前环境的起点，进入实体座舱，船头初始略偏离目标。
2. 手动转向，或点击「辅助对准目标」。保持对准后短按 W，将速率增加到约 2–3 m/s，松开滑行。
3. 观察停止余量；进入 15–30 m 附近时，按住 B 减速。以实际读数和提示为准，不按固定时长盲目推进。
4. 余量 15–30 m、总速率 ≤ 0.15 m/s、船头偏角 ≤ 8°，松开推进保持 5 秒。成功后暂停，可查看结果、重试或回到自由练习。

青绿色线圈表示保守接触余量的观察区边界，是辅助线而非真实实体；目标、飞船外形与球形接触范围不同。仍是无引力、目标中心静止的局部惯性练习，不能称作实际轨道交会或对接。
