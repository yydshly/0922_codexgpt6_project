# 沉浸观景试版 · 2026-09-27

入口：太阳系全景右上角 **沉浸观景**。这次增加的是有科学依据的特殊角度与画面呈现，仍使用现有太阳系资料，不代表飞船任务已经实现。

## 四个取景

| 入口 | 要观察的内容 | 取景方式 |
| --- | --- | --- |
| 环上掠影 | 土星球面、环面遮挡、卡西尼分界与球体投影 | 相对赤道面约 24°，斜向构图 |
| 贴近环面 | 同一组环从侧面怎样变薄 | 相对赤道面约 4°，镜头仍在主环外 |
| 蓝色地平线 | 地球曲率、静态云层与薄蓝色大气 | 昼夜交界方向的大幅近景，能自由拖动缩放 |
| 恒星之缘 | 太阳轮廓、表面与外层辉光 | 虚拟近景；日珥与日冕为增强示意 |

拖动旋转、滚轮缩放；画面获得焦点后方向键可旋转，加减键可缩放。缓慢环绕只移动镜头，手动操作会停止环绕。复位恢复当前预设。纯画面收起说明和底部选择，只保留返回与显示界面；Escape 先恢复界面、再关闭说明、最后返回全景。

## 数据、尺度和外观的边界

- 进入时复制主页最后有效历表状态，并暂停主页时间。返回后保留原日期、镜头、选择与图层，恢复进入前的播放状态。
- 局部坐标以目标平均半径为单位；使用同一时刻的太阳减目标向量，并按 ECLIPJ2000 → 场景轴转换计算光照。自转姿态复用现有 IAU 参考模型，定格期间不额外旋转天体。
- 取景位置是为观察设计的虚拟位置，详情中的镜头距天体中心由局部半径换算。不同目标独立取景，视大小不能用于比较真实大小。这不是任何航天器的实测位置，也没有连续跨行星飞行。
- 土星主环复用 C/B/A 三段边界和静态环图；球体遮挡环、环对球面投影采用简化几何。球体为平均半径球，未重建扁率、环厚度、颗粒和细小结构；分界区域简化为空隙，不代表完全真空。
- 地球云层使用已入库静态云图；大气散射、海面反光与云影为显示近似，不是实时天气。
- 太阳橙色表面、日珥与日冕为增强示意，不代表肉眼颜色或实时活动。没有把普通化学火焰或未知云海添加到真空。
- 背景星点是可关闭的氛围示意，未接入全景实测星表；暗面辅助补光可关闭。亮天体与背景星点同屏不是相机曝光模拟。
- 科学内容来源：[NASA 土星环](https://science.nasa.gov/mission/cassini/science/rings/)、[卡西尼环外影像参考](https://science.nasa.gov/resource/saturn-bright-through-rings/)、[NASA 地球](https://science.nasa.gov/earth/facts/)、[NASA 太阳](https://science.nasa.gov/sun/facts/)。位置与速度沿用 [JPL Horizons](https://ssd.jpl.nasa.gov/horizons/)。贴图署名和授权沿用 `public/textures/sources.json`，没有引入外部实时图像服务。

## 实现与验证

- 按需加载独立观景组件；主全景在后台暂停绘制，保留观察状态。相同天体切角平滑过渡，不同天体独立取景。尊重减少动态效果的系统设置，环绕默认关闭。
- 表面与土星环材质从原精细观测组件抽出复用，未改变原材质行为。纹理加载复用原有超时、取消与失败重试机制。卸载释放镜头控制器、纹理、几何体、材质与渲染器。
- 自动检查覆盖真实光向的坐标转换、平移不变性、镜头不进入球体/主环、两个土星视角的环面仰角、历表数据不被修改。现有与新增测试合计 342 项通过。
- 本地浏览器检查：四个视角与贴图加载、三维拖动、缩放中断环绕、纯画面及 Escape 恢复、说明/来源、返回全景与日期保持。1600×960 与 390×844 检查，未发现脚本或着色器错误。
- 故障注入检查：主动阻断地球云图请求后出现失败与重试入口，解除阻断后原地恢复；另验证进入时实际冻结主页日期，返回后恢复进入前的播放状态。
- 生产构建通过；原有主页包大小提示仍存在。远端此前的历表读取失败根因不属于本次改动范围，不能由本次结果推定已经解决。

## 本轮验收

先在全景点“沉浸观景”，依次查看四个取景；重点比较两个土星视角，拖动地球寻找蓝色边缘，再试“纯画面”和返回。此试版待用户验收，不能把技术检查等同于视觉体验已被接受。
