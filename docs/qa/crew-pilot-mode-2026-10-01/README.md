# 载人自主任务复核

状态：2026-10-01 本地增量，未提交、未发布。

## 范围

完整自动演示继续保留。新增自主任务路线，让用户决定点火、约束释放、一级分离、二级点火、入轨飞船分离、离轨、服务舱分离、两种开伞、软着陆授权及回收。飞控辅助与任务授权分开；恢复辅助不接管故事进度。

直接驾驶按当前设备开放姿态、RCS 平移或正向发动机油门。任意转姿不清除原有速度；直接驾驶为 1×。自主关键检查点暂停模拟，操作后继续原状态。新增控制状态进入可恢复存档。

## 操作方法

从全景顶部「载人任务 · 地球出发」进入，确认三项检查，选择「自主任务 · 我来操作」。右侧任务操控卡显示当前可执行操作、未满足条件和辅助／接管状态；不需要使用隐藏入口。所有镜头仍可独立切换。

完整按键与阶段说明见[自主任务说明](../../CREWED-PILOT-MODE.md)。

全项目回归在最后的载具首触修复前通过：148 个文件、810 项测试，见 [全项目回归输出](full-regression.txt)。修复后重新运行相关回归：6 个文件、54 项测试通过，覆盖自主控制、载具首触、原有任务、安全、方向与载具模型。新增自主控制专项包含 19 项，覆盖守卫、等待点冻结、全飞行阶段接管、有限推力、跨阶段再入、存档往返、旧 v3 兼容和失控着陆，见 [控制专项输出](control-regression.txt)。最终 TypeScript 与生产构建通过，见 [构建输出](build.txt)。未将两次不同范围的回归相加。

最终生产网页 65 项操作检查通过，未记录浏览器运行时／资源错误或渲染目标反馈错误。覆盖从正常入口选择自主任务、真实倒计时临近 T=0 后等待释放、油门归零再增大、九项后续检查点的恢复与实际执行、返回舱姿态输入、恢复辅助仍保留自主路线、平台观察记录、失控载具首触停止及 680 像素布局。逐项记录见 [browser-checks.json](browser-checks.json)，运行输出见 [browser-output.txt](browser-output.txt)。

## 模型边界

本轮改变控制来源与任务时序，沿用既有教学轨道、气动、伞与接地模型。没有提高计算精度或提供实飞飞控。气动阻力系数和热流估算未完整依赖热盾误指向，人体响应、材料损伤、落区天气与真实地形未计算。直接手动驾驶不能由此推断任意姿态都安全。

最后复核还覆盖手动发射失控的实体首触边界：使用当前连接载具的旋转外包络和步内接触时间，在参考点距地面约 62.429 m、一级底部首次触地时停止并保留失败状态，见 [carrier-contact-failure.json](carrier-contact-failure.json)。发射台甲板与塔架等障碍物碰撞仍未计算；不把这一判据称为完整网格碰撞或损坏仿真。

已有无自主控制字段的 `crew-earth-3` 存档保留原路线；带自主状态的存档需校验路线、油门、发动机授权和等待点。旧卫星存档与太阳系观测不受影响。
