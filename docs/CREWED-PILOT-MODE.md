# 载人自主任务：从点火到回收

当前阶段版本 `2026.10.01-crewed-r1`，按用户要求提交归档；完整范围、最终验证与后续项见[阶段归档](CREWED-STAGE-ARCHIVE.md)。发布以对应提交的 GitHub Pages 工作流成功为准，原复核记录保留其当时的本地状态。

本页说明载人案例的两条路线。自动演示继续用于完整观看；自主任务让驾驶员决定关键操作，并可在飞行阶段接管姿态与推力。两条路线使用同一个物理核心、时间、轨道与资源账本。

## 两层操作

**任务路线**决定谁批准点火、释放约束、分离、返回、开伞及回收。自主任务不会自动替你完成这些节点；到关键窗口会暂停模拟时钟，等待授权。这是教学检查点，并非飞船在真实空间中停住。

**飞行控制**决定谁操纵当前载具。默认飞控辅助根据现有制导模型转姿、推进；接管后，由你输入姿态和对应设备的推力。恢复飞控辅助沿用当前状态，不重置运动或补充燃料，也不把自主路线改回完整自动演示。

## 如何开始

1. 刷新本地页面，进入「载人任务 · 地球出发」。
2. 完成三个地面检查，选择「自主任务 · 我来操作」。
3. 从右侧任务操作卡点火。倒计时到 T=0 时，核对条件并释放发射台约束。
4. 后续按当前阶段显示的操作按钮推进。按钮不可用时，先阅读同一行的条件说明。
5. 需要自己驾驶时，点击「接管驾驶」，再点击主画面。需要系统帮助时，恢复飞控辅助。

## 画面与操作反馈

右侧顶部显示当前目标、下一步操作与本阶段的关键读数，区分任务运行、普通暂停、等待授权、失败与完成。下一步使用同一物理核心给出的操作条件；已经执行的二级点火不再提示重复点火。发射显示火箭总剩余推进剂和实际推力，在轨显示平台距离、相对速率与船头偏角，返回显示参考点高度与竖直速度。

接管并继续模拟后，可以点击主画面，或在右侧点击「启用键盘」。画面提示键盘是否已接入；按住按键时，对应按钮与输入提示一起亮起，松键、离开画面、暂停或切换阶段会清除暂时的姿态／推进输入。持续油门仍保持设定，松键不等于停推。屏幕上的驾驶按钮也支持聚焦后按住 Enter 或空格。

操作按钮依据当前设备和资源开放。火箭无实际推力时，推力矢量转姿不可用；有点火授权和推进剂时仍可增加油门重新建立推力。服务舱平移与转姿共用它的推进剂；返回舱姿态喷口与软着陆喷口使用各自的储备。推进剂耗尽不会移除独立的气动或伞恢复力矩。

失败或完成后，结果操作放在右侧上方。失败时可以下载记录、恢复自己已保存的任务，或者经结束提示后从地面重新开始；不会自动回退位置或补充燃料。浏览器只保存用户主动保存的任务，没有隐藏的自动复活点。

## 点火、滑行与播放倍率

阶段说明中的推进状态读取实际推力。倒计时前段没有推力时显示等待建立推力，建压后仍由发射台约束。二级的点火授权与产生推力分别显示；本人油门为零时会说明正在无主推力滑行，并提示增加油门或恢复辅助。离轨辅助先转姿，实际满足条件后才建立主推力；手动模式下推力沿自己的真实朝向，不保证自动逆向。

右侧「辅助播放倍率」下面显示所选倍率与当前采用倍率。本人驾驶、观察准备、显著转姿和近地操作可能使用 1×，辅助接近或离轨推力段最多 10×；暂停与教学检查点显示模拟时钟暂停。恢复辅助保留原选择。这是计算推进设置，设备性能不足时实际播放还会更慢，不是帧率测试结果。

平台观察条件满足而模拟暂停时，可以直接点击「记录平台结构观察」，不必先继续。该按钮与记录器使用同一套距离、相对速率、朝向和阶段条件；切换镜头不会改变这些条件。离轨、再入和着陆的期望姿态与实际姿态分别说明，手动错误朝向不会被讲解文字假定为已经对齐。

## 操作顺序与判断依据

| 阶段 | 驾驶员操作 | 飞控辅助与物理判断 |
| --- | --- | --- |
| 地面 | 点火、释放约束 | 建压和倒计时；推力与重量检查 |
| 一级 | 姿态／油门接管、一级分离 | 燃尽后等待分离；分离保留位置、速度与角速度 |
| 二级与入轨 | 二级点火、飞船分离 | 级间滑行；根据实际近、远地点判断目标轨道 |
| 在轨 | 接近、转姿、减速、记录平台观察 | 距离、相对速率与船头偏角满足观察条件 |
| 返回准备与离轨 | 开始离轨、分离服务舱 | 辅助逆向点火；近地点降低后关机、等待分离 |
| 高空滑行与再入 | 可接管返回舱姿态、授权减速伞 | 气动恢复力矩仍参与；开伞检查高度、空气相对速度与动压 |
| 伞降 | 授权主伞、准备软着陆 | 伞面积逐渐建立；飞控辅助保持吊挂及近地姿态 |
| 近地 | 可接管着陆姿态与正向油门 | 辅助控制下降速度；检测实际支脚／舱体首次接地 |
| 接地 | 核对结果、发送回收信号 | 缓冲停稳、姿态、支撑和观察记录全部满足后完成任务 |

自主任务的等待点停止计算；批准后继续同一状态。暂停期间切换镜头和查看仪表不会耗油或推进时间。操作条件来自物理核心，界面不另造一套分离或开伞判据。

## 按键与设备区别

| 操作 | 火箭／离轨发动机／软着陆发动机 | 在轨接近与观察 | 返回舱高空滑行／再入／伞降 |
| --- | --- | --- | --- |
| W / S | 增大／减小持续油门，范围 0–100% | 沿船头正向／反向 RCS 推进 | 没有平移主发动机，不能用此键推进 |
| A / D | 偏航 | 偏航 | 偏航 |
| ↑ / ↓ | 俯仰 | 俯仰 | 俯仰 |
| Q / E | 滚转 | 滚转 | 滚转 |
| B | 不使用平台相对制动 | 有限推力逐渐降低相对平台速度 | 不使用平台相对制动 |

直接驾驶固定 1× 时间。松开姿态键后，喷口或推力矢量控制以有限力矩减小转动；不能瞬间转向或清除速度。油门是持续设定，松开 W/S 不会自动归零；使用右侧油门滑块或停推按钮调整。发动机停推后，火箭不能凭空利用推力矢量改变姿态。

## 模型与边界

载具、平台、推力和操作阈值沿用本项目原创教学设定，不是某一真实型号的飞控复刻。地球引力、空气阻力、持续推力、角运动、伞拉力和接地缓冲来自已有模型；本轮改变控制来源和操作时序，没有提高轨道或空气动力精度。

姿态与平移分开控制，参考 [NASA 航天器操作介绍](https://www.nasa.gov/missions/artemis/how-to-fly-nasas-orion-spacecraft/)。返回舱由独立姿态喷口控制，服务舱分离后不能再使用它的主发动机；相关来源和参数见[载人任务说明](CREWED-EARTH-MISSION.md)。

再入阻力系数、迎风热流估算没有随热盾错误朝向完整重算；也没有材料烧蚀、人体健康、生命保障、天气和地形模型。任意手动姿态不能据此判为实飞安全。当前接地速度、倾角与角速率超出教学范围会失败；分离或开伞条件不足会拒绝操作并说明原因。

手动发射的失控接地按当前连接载具的实体外包络与零海拔参考地面判断；火箭参考点仍在高处时，下面的一级、二级或倾斜侧壁也可能先触地。此检查不包括发射台甲板、塔架和工作平台等障碍物碰撞，也不提供碰撞损坏模型。

存档保存当前路线、辅助／手动状态、油门与等待动作，恢复后统一暂停。已有 `crew-earth-3` 存档可恢复为原路线；新增控制状态存在时会核对其有效性，不能把损坏存档当成已完成任务。
