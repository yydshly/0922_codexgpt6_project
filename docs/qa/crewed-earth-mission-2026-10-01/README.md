## 体验验收建议

1. 刷新本地页面 → 载人任务 · 地球出发 → 三项检查 → 完整自动演示，看清为什么出发、平台观察和返回结尾。
2. 在轨暂停并接管，试 A/D 与 W/S，确认转船头与改变航迹不同，随后恢复自动驾驶。
3. 在轨保存、离开后重进并恢复，核对时间、阶段、姿态和燃料，点击继续。
4. 在主伞/着陆段暂停，看受力、下降速度与接地记录；查看三维驾驶员和舷窗镜头。

以上不承诺所有设备帧率、长时间后台运行或完整航天工程模型均已验证。地面建筑、人物和返回场地为简化程序网格；光照方向固定，天空随高度淡出，用于教学辨认，不对应实时昼夜或当地天气。
