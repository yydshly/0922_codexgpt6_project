# 载人返回段：结构、受力与接地复核

2026-10-01，本地 `http://127.0.0.1:4180/`，本批未提交推送或发布。对应用户对回落方向、受力及船头/尾部的疑问。

## 修正范围

- 船头/伞吊点、底部热盾、独立软着陆喷口、支脚直接连接三维部位标注。服务舱的 64 个紧固件随服务舱一起隐藏，保留返回舱的 56 个；不再有悬空圆环。
- 阻力与伞力仍反向于共转空气相对运动。再入热盾领先，着陆船头朝上；这两者不可统一成“船头永远沿速度”。下降时向上受力可以表示减速。依据 [NASA 的阻力说明](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/drag/)与 [ESA 的返回过程](https://www.esa.int/Science_Exploration/Human_and_Robotic_Exploration/The_return_home)。
- 减速伞和主伞用不同网格，半径按有效投影面积换算，展开和交接面积与阻力模型共用参数；伞置于实际拉力方向一侧，绳索连接船头附近吊点。名义完全展开面积分别为 24 / 1,000 m²，半径约 2.76 / 17.84 m。
- 四个软着陆喷口固定在返回舱热盾周边，喷焰从出口排出，排气与推力反向；缩放不移动喷焰起点，近地喷焰长度截到地面。
- 支脚底部与 2 m 接地参考点匹配，接地后随原 0.8 秒缓冲压缩，底部保持在零海拔平面上；参考点最终约 1.59 m，不是假装整个舱体位置变为 0 m。近地显示米数，地面网格只作为 1 km 内的着陆参考，避免高空出现有限平面边缘。
- 接地瞬间清掉已关机的软着陆推力，卸载阻力/伞拉力并切换为支撑/缓冲力；伞的短暂淡出表示解脱，不求解布料回收。
- 返回段默认隐藏含地球自转的地心速度箭头，单独可开；浅蓝始终是空气相对速度。停止后低于 0.05 m/s 的方位夹角显示“—”，不展示浮点噪声。
- 受力分列显示 kN 标签，避免阻力、伞力与支撑力重叠/裁切；长度为显示缩放，不标记实际施力点。右侧合力与下降速度变化率分别显示，后者考虑共转空气及局部竖直方向变化。

## 查看与边界

刷新本地预览 →「载人任务 · 地球出发」→ 完整演示 → 第 10–14 阶段。外部跟随可拖动观察；暂停后查看部位、方向和受力。下降段右侧可额外显示地心速度，并阅读“为什么向下走，却向上受力？”；近地参考点高度和脚底接地是不同读数。

这是原创载人教学载具；没有复刻 Soyuz/Dragon 的型号参数。理想再入指向、无风参考大气、无升力、有限接地缓冲等原边界保留；未计算伞绳弹性、布料、六自由度气动力矩、实际着陆地形和天气，也未完成多设备帧率覆盖。自动检查不代替用户体验验收或航天工程认证。
