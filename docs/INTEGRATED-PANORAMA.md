# 综合全景整合：从独立课程到同场景观察

## 本轮解决什么

此前第 05–09 批主要是独立教学镜头，宏观全景只接入简化轮廓或入口。用户明确要求先在一个空间中看到整体，再靠近理解细节。本轮不增加第十个独立阶段，而是将五组代表现象绘入现有 `MacroCanvas`。

主页入口改为“综合全景”，默认侧栏为“全景现象”。顶部太阳活动、近地空间和尘埃按钮现在执行同场景定位；独立课程放到明确命名的进一步阅读入口。场景内可点击绿色定位标记，也可从右侧选择。

## 实际接入范围

| 空间位置 | 本轮绘入同一画布的内容 | 位置和外观的依据 |
| --- | --- | --- |
| 太阳 | 日冕增强、耀斑亮斑、CME 云团 | 太阳为宏观坐标原点；活动方位、大小、进度为示意 |
| 地球周围 | 弓形激波、磁层顶与磁尾、磁力线、极光、大气轮廓 | 锚点为当前 JPL 地球相对太阳位置；磁尾指向背日侧，其他局部几何与磁轴为示意 |
| 地球周围 | 内外辐射带、等离子体层点云 | 复用第六批粒子区域绘图函数，局部尺寸放大，无通量数据 |
| 行星际与地球旁 | 倾斜碎屑流、进入大气后的流星示例 | 碎屑流为第八批教学几何，流星锚定地球；两者没有逐颗追踪或实际事件关系 |
| 原日球层轮廓处 | 日鞘体积分布、外部星际介质、中性原子 | 沿用原概念轮廓与压缩坐标；增加区域点云及进入示例，不是当日边界 |

原有行星、彗星、区域成员及带区仍在同一宏观场景。行星参考轨道与尺度圆环现已独立控制，见 [轨道与方向说明](PANORAMA-ORBITS.md)。太阳与八大行星已补本体点选、跟随和参数，见 [本体观察说明](PANORAMA-PRIMARY.md)。地球已补独立云层与薄层大气，见 [地球外观说明](PANORAMA-EARTH.md)。六个区域成员现已补全景侧栏入口与持续日期跟随，见 [区域成员说明](PANORAMA-MEMBERS.md)。哈雷与 67P 已补点选、日期跟随、路径开关和彗尾示例定位，见 [全景彗星说明](PANORAMA-COMETS.md)。后续整合已将月球与 19 颗扩展卫星、四大巨行星环绘入同一全景，见 [卫星与环系整合](PANORAMA-FAMILIES.md)；冥王星—卡戎也已补入同场景双体观察，见 [双体说明](PANORAMA-BINARY.md)。主观测的真实比例画布和综合宏观画布也仍各有用途。本轮没有把全项目所有镜头替换成一个等比例宇宙，也没有新增天体或物理模型。

## 操作与状态

- 远景保留现象位置标记，靠近锚点后展开代表细节；主动定位时突出当前区域，其他位置保留定位入口。
- 五组开关与阶段 05–09 联动。阶段关闭优先于全景开关；读取不到真实地球位置时不在原点伪造近地环境。
- 地球日期变化时，局部几何位置、背日磁尾与当前跟随镜头一起更新。定位不写入时间、历表或物理状态。
- “返回定位前视角”恢复首次定位前的相机位置、目标与朝向；关闭当前目标的全部可见组也会退出定位。选择区域或角度预设则采用新的区域取景。
- 现象进度默认暂停，控制代表性的太阳活动、流星短迹和中性原子示例；各现象没有因果关联。真实观测时间和既有太阳风动画继续独立控制。
- 近景降低远处点云及参考线亮度，限制背景点尺寸，避免放大后遮住局部现象。返回全景恢复显示；太阳与地球近景使用既有本地静态纹理。

## 来源与科学边界

天体锚点来自现有 JPL 供数，见 [数据处理流程](DATA-PIPELINE.md)。现象概念、来源链接和模型限制沿用 [近地空间](SPACE-ENVIRONMENT.md)、[粒子区域](NEAR-EARTH-POPULATIONS.md)、[太阳活动](SOLAR-ACTIVITY.md)、[尘埃与流星](DUST-AND-METEORS.md)、[日球层](HELIOSPHERE-EXPLORER.md)。

`macroIntegrated.ts` 把几何组挂到已有场景；`integratedScene.ts` 处理阶段门控和按锚点距离展开。镜头定位与地球跟随由同一个宏观相机完成，独立课程往返不会替换全景画布。

全景距离使用现有对数压缩，现象尺寸另外放大；两者不能当成统一真实尺规。局部几何方向、厚度、数量和速度都是科普选择，外观不是当前太阳或地球空间天气。不计算磁流体、辐射输运、粒子通量、气动消融或风险。38 个真实动态目标与十体引力模型不变。

## 验收

1. 主页 → 综合全景，远景可见现象标记，右侧有五组开关及科学边界。
2. 定位太阳、近地空间和日球层，仍为同一画布，不出现独立教学页；可返回首次定位前视角。
3. 定位地球并切换观测日期，近地效果随地球移动；背日磁尾不沿屏幕固定方向。
4. 开关组或阶段，核对位置标记和效果同步；关闭所有地球组且阶段 04 家族不可见后退出该定位。
5. 暂停主页日期，播放或拖动现象进度，主页日期保持不变。
6. 明确进入独立详解，再返回，应保留全景相机与图层。
7. 桌面和 700px 窄窗口查看定位、头部入口、侧栏滚动与图层；独立课程与全景的意义不混淆。

## 本轮验证结果

- 24 个测试文件、108 项检查通过；覆盖阶段和全景开关优先级、缺少地球历表时不显示近地效果、按锚点距离展开。类型检查与生产构建通过，保留现有主包体积提示。
- 浏览器验证五组内容使用同一画布，太阳 / 地球 / 日球层定位不打开独立页面；返回视角、现象暂停、日期不变、阶段关闭和独立课程往返通过，无运行时异常。
- 另将观测日期跳转一个月，地球跟随保持，近地空间屏幕锚点仍位于原取景位置。
- 完成桌面及 700px 窄窗口截图复核；修复近景背景点过大和窄窗口头部按钮被固定高度裁切的问题。
- 本轮保留本地验收，远端仍为第八批 `0b3d801`；第九批与本次整合尚未推送。
